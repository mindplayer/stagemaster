# 已实现接口：设备连接诊断子集

依据 [ADR-014](../development/decisions/PRODUCT-ADR-014-device-link-probe.md)。此接口只验证传输及保活，不是执行包或场景控制协议。

## 模块调用

```rust,ignore
// 每次建立底层连接产生新随机非零标识；断开就销毁 session。
let mut session = stagemaster_device_link::Session::new(nonce, monotonic_ms)?;
let response = session.receive(&received_bytes, monotonic_ms).encode();
// 适配器发送 response，不能据此操作播放器。
if session.poll(monotonic_ms)? { transport.disconnect(); }
```

`Session` 是不分配内存的纯状态机，不读取时钟、不主动断开、不引用播放模块。GATT 只是一个消息适配器；未来 USB／局域网可调用相同接口，但跨连接身份、控制去重和文件安装须走后续业务协议，不把诊断会话当作授权。

本轮共享播放器使用 `no_std + alloc`；宿主注入单调时间与分配器。正常 `advance` 不分配；非法调用返回的字符串错误仍可能分配。设备初始化有界计划后再进入运行；当前内核全局上限不是此设备已验证的容量。

## 20 字节探针消息

全部整数为小端。字段：版本 u8、类型 u8、结果 u8、保留 u8、会话 u64、序号 u32、值 u32。

- 版本 1；请求结果／保留／值必须为 0。
- 类型 1 为握手：会话 0、序号 0，只能在新连接成功一次。
- 类型 2 为心跳：使用回复中的会话标识，序号从 1 开始严格递增，溢出前必须重新连接。
- 回复类型为请求类型按位或 `0x80`；返回设备会话、原序号及建议心跳周期 2000 毫秒。
- 无法解码的包（长度、版本或保留位非法）返回类型 `0x80`、序号 0，不假定能解释未知版本的字段。
- 结果 0 成功；1 格式错误；2 不支持版本；3 会话错误；4 重复或乱序；5 过期；6 不支持操作；7 时钟倒退。
- 建连后 6000 毫秒内须握手；此后每次新的合法消息刷新期限，到边界即失效。读取、订阅通知、错误消息及重复消息均不续期。过期会话不能被迟到握手复活，必须重连。

本适配器固定一个活动连接，20 字节消息可放入最小 ATT MTU 的有效载荷。只使用带响应写入；先保存应用结果再发送 ATT 回复，之后通知。主机同时核对应用结果，通知丢失时可读取最后回复；当前只有一个在途请求，后续文件流控不复用这个单格回复缓存。

## GATT 映射

| 项目 | UUID | 操作 |
| --- | --- | --- |
| 诊断服务 | `f889ed60-0100-4e83-968e-799ab99558fa` | 广播与发现 |
| 请求 | `f889ed61-0100-4e83-968e-799ab99558fa` | 写入，必须恰好 20 字节 |
| 回复 | `f889ed62-0100-4e83-968e-799ab99558fa` | 读取与通知 |
| 诊断状态 | `f889ed63-0100-4e83-968e-799ab99558fa` | 只读 20 字节 |

诊断状态：版本 u8、标志 u8（位 0 自检通过；位 1 RS485 禁止发送）、两个零保留字节、启动毫秒 u32、内核推进计数 u32、已用堆 u32、剩余堆 u32。时间／计数可回绕，仅用于诊断；不是持久节目时钟或设备身份。堆指标针对配置的 128 KiB 内部堆，不是芯片全部 RAM 或 PSRAM。

设备名称 `StageMaster`；每次启动产生随机静态 BLE 地址。地址、名称和会话 nonce 均不是认证，当前不提供真实播放控制或文件写入。正式产品需要稳定设备身份、绑定／控制权、恢复与授权，不能因为手机能连接就视为拥有控制权。

参考 [TrouBLE](https://github.com/embassy-rs/trouble) 的控制器／主机栈和 GATT。实测发现 0.8.0 `ReadEvent::accept_unprocessed` 在本用法下返回空值，已改用正常属性表读取；`WriteEvent::validate` 只检查容量，不保证等长，本适配器显式限制 20 字节。两点均通过实际协议验收验证，不修改第三方缓存源码。
