# 列表属性贡献

MIX-002／[ADR-105](../development/decisions/PRODUCT-ADR-105-sequence-contribution-boundaries.md)，接续[现场属性贡献](live-contributions.md)。本接口供可信宿主组合列表、场景和手动层，桌面／独立进程及物理驱动仍待接线。

## 准备与调用

`Document::compile_live_sequence(sequence_id, now_ms)` 准备 `LiveSequencePlayer`。同一工程完整快照指纹绑定属性布局、列表和 `prepare_output()` 返回的编码器；外部不传任意默认向量伪装来源。准备复用现有 `compile_sequence` 的目标、效果、预算和输出映射，另存有界的逐步所有权和明确赋值掩码。

`apply(Command, now_ms, mixer, handle)` 推进／控制真实 Player，采用同布局的当前合成快照供新取得／重新接回属性的渐变起点使用。句柄用于验证来源及读取当前胜出状态和电平，准备时先注册来源。`Command` 包含 Advance、Execute(index)、Next、Pause、Resume、Stop；步骤索引属于准备后的列表，`steps` 保留实际步骤身份／名称／剧本。选择仍在界面，不自动执行。`status`、`index`、`elapsed_ms` 和 `can_next` 是只读运行信息。

随后 `publish(mixer, handle, serial)` 原子发布该来源完整稀疏状态及待重申集合。宿主将每个运行实例绑定唯一来源句柄，统一分配严格递增序号；同一实例的 apply／publish 使用同一句柄，失败发布保留声明至下一成功批次；未发布的停止不是已完成释放。宿主必须处理错误并维持来源生命周期，不能把本接口当身份认证或输出许可。

## 已采用的基础语义

- 继承模式：本步未写入的静态属性继续由列表控制，但不因普通推进重申。独立模式：缺省属性在步骤生效时释放。显式默认值和明确零仍是有效贡献，不能用与默认值相等来判断未控制。
- 效果仍属于本步骤。启用效果控制其属性，离开后返回静态跟踪值或释放；没有新加效果跟踪模式。
- 延时内维持旧贡献，延时结束后新属性／本步明确赋值才取得顺序。直接 Execute 表示跳转／重执行，会重申目标步骤全部控制属性；Next／自动推进只重申本步编排及新取得属性。暂停／恢复和普通帧采样不抢占。
- 目标渐变与离散切换仍由 Player 求值。取得原本未控制、或明确接回已被其他来源覆盖的属性时，使用当前合成值作为起点；亮度先按本来源电平反算并限幅，避免再次缩放造成下跳。零电平仍为零输出；目标超过本来源可达范围、优先级变化和离散切换不保证平滑连续。释放直接归还下层当前值，独立于目标渐变；不会先把位置／颜色渐变到档案默认值再释放。可配置释放包络后续另定。
- 最后一步自然结束保持贡献；Stop 撤掉全部贡献。亮度推子和零电平保持 MIX-001 的规则，来源关闭仍由混合器明确处理。

一次调用可能跨过许多步骤、回到原下标或跳过完整循环。播放器在权威边界同步通知，适配器折叠所有权和待声明集合；跳过整圈时只处理一次完整圈的元数据，不逐圈补帧。无来源输出时才回落档案默认值。

## 播放器转换接口

`Player::apply_observed(Command, now_ms, &mut impl Observer)` 为新增的可信进程内入口。原 advance／execute／next／pause／resume／stop 使用同一路径及空观察者，原数值行为不变；无 Plan／设备包格式修改，也无队列、线程或额外时钟。

Observer 的 `activated(step,reassert,from)` 在延时结束且尚未渲染目标渐变时调用一次；允许修改固定长度的起点切片。`cycles_skipped()` 表示已省略至少一个完整自动循环，`stopped()` 表示明确停止。观察者不得阻塞、I/O 或在正常周期分配；其状态须始终属于同一播放器，不能中途换上一个不知道历史的新观察者。非法索引和倒退时间在回调前拒绝。

来源的所有权不进入通用 Player，Player 不依赖 mixer、工程、设备或 UI；旧单列表与设备运行仍可以完全不使用观察者。跨来源合成后才做 16 位粗细通道编码。

## 适用范围

当前源的调度和发布由单一宿主串行协调，LTP 顺序是核心实际接纳顺序；调用时的合成快照不是历史时刻／物理灯具反馈。多个独立时钟的事件排序、断连来源策略、专业跟踪模式、释放渐变、总控及可见来源诊断仍为后续增量。固定来源及列表预算沿用 MIX-001／Player；准备阶段允许分配，正常控制／采样／发布路径使用固定缓冲，错误字符串可能分配。未宣称 MCU 适配、硬实时或完整专业控台已经交付。
