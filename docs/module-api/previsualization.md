# 本机三维预演接口（PREVIS-001）

依据 [ADR-018](../development/decisions/PRODUCT-ADR-018-local-preview-bridge.md) 与 [ADR-019](../development/decisions/PRODUCT-ADR-019-embedded-previsualization.md)。Rust 投影／桌面 HTTP 桥、UE 消费端、进程管理及应用内视窗已接通并在 Mac 实测。三维灯位修改的草稿保护／历史同步、完整执行联动和客户独立打包尚待验收，不能据此宣称整个预演目标完成。

## 模块归属

- `stagemaster-spatial`：安装变换、固定射线、静态双轴指向与轮廓三角化，无 UI／网络依赖。
- `stagemaster-previs`：从 `Document` 派生 `Scene` 与 `LightRig`；不修改文件，不持有播放时钟。`scene(&document)` 生成房间构件及既有灯位；`LightRig::new(&document)` 缓存同版本灯具与场景，`editing(scene_id)` 解析场景／预设，`playback(&output)` 读取现有播放器的归一化灯值。
- `apps/desktop/src/session/previs.rs`：权威工程版本、预演来源、灯位编辑与统一撤销的衔接。
- `apps/desktop/src/previs/`：本机监听、凭据、协议、请求界限、缓存及连接状态；不解析第二套节目逻辑。
- `apps/previs-unreal`：消费中立几何／灯值、导航与拾取，提供受限的安装请求；不得私自计算节目时间、复杂档案或真实设备输出。
- `apps/desktop/src/previs/renderer.rs`：拥有 UE 离屏子进程和本机信令服务，退出／禁用时回收；开发环境与分发组件路径分离。
- `tools/previs/signalling.mjs` 与 `PrevisViewport.tsx`：复用 Epic 官方信令／前端库传输视频及查看输入，独立于工程 HTTP 协议。

## 通信

工程桥仅 `127.0.0.1` 随机端口。每次启用生成新 `bridgeId` 和独立随机 Bearer 凭据；凭据不通过前端返回、不写工程／日志，由宿主进程环境传给 UE。拒绝 `Origin`、缺失／重复／错误 Authorization；无 CORS。禁用撤销身份并关闭监听。端口启用不等于 UE 已连接；最近 2 秒收到有效帧读取才显示连接活动。

桌面 `previs_request` 支持 `status/enable/disable/source`，状态新增可空 `viewerUrl`。它只带当前观看会话的独立凭据，允许 Tauri 前端连接本机视频服务，不能访问工程桥或渲染器信令入口。信令绑定本机动态端口、校验 Tauri Origin、限制一个观看者和 256 KiB 消息，不配置外部 STUN／TURN。正常关闭回收两个子进程；轮询发现任一子进程退出时关闭整个预演连接，保留工程与播放器。画面连接状态与工程桥连接状态分别显示。

查看动作经官方数据通道传输，`UIInteraction` 只接受单字段 `{ "action": "top" }`，当前允许 `perspective/top/all/selected/workLight/cancel`。任意控制台命令入口关闭。渲染器以 5 Hz 返回中文查看状态、所选灯具描述和工作照明状态；这些是临时查看状态，不写工程。键盘转发仅在视窗获得焦点时启用，离开或卸载立即关闭；未开启麦克风、摄像头或真实硬件控制。

所有成功响应包含：

```json
{ "protocol": 1, "bridgeId": "每次连接的新身份", "generation": 17, "version": "12" }
```

`generation` 用于所有工程编辑的乐观并发检查；保存也可能改变它。`version` 为内容版本的十进制字符串，仅内容变化才增长；UE 按完整字符串比较，不转成浮点数。撤销也产生新版本，不能复活旧编辑凭据。

| 接口 | 结果／限制 |
| --- | --- |
| `GET /v1/scene` | `scene` 包含项目身份、空间、三角网格、固定灯最终射线和原始安装参数；米制右手坐标，光束原始轴为局部 −Z。最多 100000 三角面、32 MiB JSON。 |
| `GET /v1/frame` | 同版本 `source`、`status`、`canEdit`、`lights`。缓存缺失或内容变化返回 409，消费端重新读取场地。每灯为 `fixtureId`、0–1 `intensity`、独立 RGB `color`。 |
| `POST /v1/placement` | 提交下述单灯安装请求；只支持既有灯位，不能创建／删除灯具、改变空间归属或控制播放。成功返回新版本并发出桌面 `project-updated` 通知。 |

```json
{
  "bridgeId": "连接身份",
  "generation": 17,
  "version": "12",
  "placement": {
    "fixtureId": "既有灯具标识",
    "spaceId": null,
    "positionMeters": { "x": "2.1", "y": "3", "z": "5.2" },
    "rotationDegreesXYZ": { "x": "25", "y": "0", "z": "0" }
  }
}
```

源为 `defaults`、`scene`（附 `sceneId`）或 `playback`。它只由桌面宿主命令设置，无 HTTP 修改来源／执行节目接口。`editing` 为孤立场景／默认值预演，不隐式继承场景列表的跟踪。播放器 `idle/running/paused/finished` 直接来自共享 Rust 执行器；`unloaded/stalePlayback/missingScene` 明确无可用灯值，不能回退到上一次画面并显示为正常。消费端必须显示对应中文状态、清除旧灯光，并禁止过期状态下提交编辑。

400／422 表示格式、投影能力或尺寸错误；403 表示连接无效；409 表示版本／操作前提冲突；503 表示宿主忙。错误体为 `{"message":"中文说明"}`。请求体上限 8192 字节，HTTP 等待上限 3 秒，最多两个实际计算任务；超时／断开不提前归还仍在执行任务的容量。无网络请求队列，宿主被文件对话框占用时立即返回忙。

## 消费端必须实现的交互约束

1. 最多一个在途帧请求，目标约 30 Hz；慢响应略过采样，不补播历史。几何与灯值必须匹配 bridgeId／version，未知 protocol 拒绝；更换工程清空旧画面。
2. 位置变换仅在 UE 边界转厘米、反转 Y；本协议经反射后的顶点顺序已经匹配 UE 正面约定，不能再次交换三角索引。法线与 UE 自带盒网格核对；射线沿同样基变换，不再实现灯光语义或指向求解。
3. 相机、选择与拖动草稿属于渲染器查看状态。拖动中就地反馈，松手只提交一次；Esc 取消，版本变化／断线撤销草稿。禁止每帧写入工程。
4. 原生编辑资格默认关闭。桌面确认无待应用草稿后按当前 generation 开启；内容修改、保存、撤销和每次三维提交都会撤销资格。桌面收到通知后刷新权威快照，再确认下一次编辑资格。接入时须处理通知与待应用草稿竞态，不能静默覆盖任一窗口的编辑。
5. 禁用、断线、过期计划和渲染器退出都不改变工程或播放器；播放源仍由原 Instant 时钟推进。真实 DMX 输出权限不属于此接口。

## 已有验证与剩余验收

投影测试覆盖凹轮廓正反绕序体积、极薄／短墙、真实固定灯安装射线、场景和播放器灯值一致、未布置灯不凭空出现在原点、未支持属性及网格超预算的原子拒绝。真实回环 HTTP 测试覆盖身份／来源拒绝、连接过期、更换凭据、既有灯位限制、一次撤销／重做、重放拒绝、过期场地／计划、已删除场景、锁竞争和计算背压。独立时间测试证明轮询与无渲染器轮询得到相同播放结果。

Mac 原生 Tauri 内嵌画面已验证真实保存的房间／舞台／两灯、场景来源、蓝光、透视／俯视、选灯／聚焦、工作照明、平面往返与渲染器退出隔离。3 项 UE 测试验证响应原子拒绝、坐标边界和官方库实际加载；3 项信令测试验证角色／来源隔离、日志路径脱敏与真实 WebSocket 握手。

帧率／延迟、光学色彩精度、三维拖动取消与草稿冲突、完整执行画面联动仍须继续验收。当前只开放查看输入；Rust 的安装编辑资格默认关闭，不因内嵌画面自动开启。通用视效不等于实际灯具光学／照度；完整摇头灯档案与共同指向另按 ADR-016 扩展。
