# 设备运行消息 SMRT v1

DEVICE-003 第三增量，依据 [ADR-129](../development/decisions/PRODUCT-ADR-129-runtime-wire-protocol.md)。实现为 `stagemaster-runtime-protocol`；原 `install-worker::operations` 重导出共享类型，执行仍属于原工作器。复用已有 minicbor 与安全 Message 承载，不新增加密／无线分片库，不改变安装 SMAP v1。

## 承载与协商

每条明文消息最多 1,280 字节。前缀固定 8 字节：ASCII `SMRT`、引导版本 `1`、消息类型、两个零保留字节；随后为一个 CBOR 定长数组。消息类型：0 协商请求、1 就绪、2 运行请求、3 运行回复。拒绝未知版本／类型、非零保留字节、无界数组、字段类型／长度错误、未知枚举、尾随和截断。CBOR 数值按所列无符号范围检查，不依赖 Rust 结构体布局。

安全握手确认后，客户端发协商请求，工作器确认该连接的实际访问范围再发就绪。尚未协商、重复协商、协商失败均不能处理运行消息。即使就绪编码成功，承载发送失败／取消仍须关闭连接；编码就绪不是送达证据。共享 Channel 已通过 [RuntimeClient](device-runtime-client.md) 接入新握手；生产固件无线任务与原生设备服务仍待接线。

| 消息 | CBOR 数组（按顺序） |
| --- | --- |
| 协商请求 | `[最小版本:u16, 最大版本:u16, 消息预算:u16]` |
| 就绪 | `[device:id, boot:id, connection:u64, session:id, principal:id, permission_revision:u64, 选定版本:u16, 消息字节:u16, 范围:u8, 剩余开发许可毫秒:u32, 安全保活期限毫秒:u32]` |

`id` 是非零 16 字节二进制标识。连接代次与许可修订也非零；协议选择 v1，要求其位于报价范围，消息预算为 1,280，当前保活期限为 6,000 毫秒。剩余开发许可为 1～600,000 毫秒，客户端按已发送确认消息的起点保守计算本地截止，不能用后续消息延长期限。范围位：1 安装、2 观察、4 控制；未知位拒绝，纯安装不能公告运行就绪。这里的范围是设备声明数据，**不是可反序列化的授权凭据**。

客户端 `Ready::correlate(offer, expected)` 必须在当前确认的加密通道内解码后调用。expected 来自可信配置与本次握手，完整匹配 device／boot／connection／session／主体／许可修订和范围，设备剩余期限不得超过预期。实际业务继续由原 Session 与 Runtime 校验；当前开发期限不是商业使用限时。

## 请求与操作号

运行请求为 `[session:id, 请求序号:u64, 期望业务修订:u64, 操作数组]`。请求序号非零且连接内连续；语义重试必须相同完整请求，以新加密记录承载，不能重放旧密文。时长数值由原 Runtime 产生业务拒绝，不因通过语法解码而获得控制权。

| 操作号 | 操作数组 | 意义 |
| --- | --- | --- |
| 0 | `[0]` | 读取状态 |
| 1、2 | `[号, 索引:u16]` | 读取一条节目／步骤 |
| 3 | `[3, 时长:u64, 显式接管:bool]` | 取得控制权 |
| 4 | `[4, 时长:u64]` | 续期当前控制权 |
| 5、6 | `[号]` | 归还控制权／结束维护 |
| 7 | `[7, 节目标识]` | 选择节目 |
| 8 | `[8]` | 载入所选节目 |
| 9 | `[9, 步骤:id]` | 执行步骤 |
| 10、11、12、13 | `[号]` | 暂停／继续／下一步／停止 |
| 14、15 | `[号]` | 请求维护／取消维护 |

节目标识为 `[种类:u8, id]`；种类 0 场景、1 场景列表。请求没有客户端租约字段，也没有“确认已静默”操作。安装、观察、控制、实际控制权和播放许可的区别沿原[应用契约](device-runtime-application.md)。

## 回复与历史观测

回复为 `[完整原请求, 观测, 内容]`。观测为 `[boot:id, 业务修订:u64, 设备单调时间:u64, 节目数量:u16, 步骤数量:u16]`。客户端须用 `Response::correlate(request, boot)` 核对当前请求与启动；重发旧请求取得的仍是原历史结果，需要新状态则发送新序号 Status。

| 内容 | 数组结构 |
| --- | --- |
| 状态／控制成功 | `[0, 完整状态]` |
| 业务失败 | `[1, 完整状态, 错误号:u8]` |
| 节目页 | `[2, null 或 [节目标识, 名称:text, 装载峰值字节:u32]]` |
| 步骤页 | `[3, null 或 [步骤:id, 名称:text, 编号:text]]` |

节目／步骤页只回应对应请求；成功页的修订须等于请求修订。有内容时索引小于数量；null 仅表示索引恰好等于数量的结束标记。越界或过期修订走业务失败，并保留当时完整状态。文本每项最多 512 个 UTF-8 字节，完整保存，不截断；最长步骤页及最大计数／序号共 **1,142 字节**，无需新增分片或扩大安全消息。

完整状态数组为 `[模式, 已绑定提交或null, 所选节目或null, 已载入节目或null, 播放状态或null, 运行实例号或null, 当前步骤或null, 已播放毫秒, 控制者或null]`：

- 模式：0 正常运行、1 等待静默、2 维护；播放状态：0 待执行、1 执行中、2 暂停、3 已结束。
- 已绑定提交：`[槽:u8, 代数:u64, 包字节:u32, SHA-256:32字节]`；槽 0／1，代数非零，包范围沿安装规范验证。
- 控制者：`[租约代次:u64, 主体:id, 来源:u8, 到期设备时间:u64, 最后请求号:u64]`；来源 0 本地面板、1 远端。租约与实例的 boot 由外层观测恢复，不允许不同启动混入；租约代次和实例号非零。

错误号固定映射原 Runtime Code：0 身份、1 时钟、2 占用、3 租约、4 请求顺序、5 修订、6 计数耗尽、7 模式、8 无包、9 节目选择、10 未载入、11 步骤、12 播放状态、13 预算、14 读取、15 完整性、16 包格式、17 分配、18 播放核心；19～22 分别为许可缺失／过期／时间不确定／限制。100 存储恢复失败、101 回复容量超限。未知错误号拒绝，不能转为成功。

## 工作器接线

```rust,ignore
// 已在当前安全 Session 中解密；始终运行在唯一存储／运行所有者内。
let ready = connection.negotiate(&mut worker, offer_bytes, now(), |t| session.grant(t).ok())?;
// 发送失败／取消须 close；无线保活与撤销仍由独立平台任务负责。
let response = connection.process_message(
    &mut worker, request_bytes, &mut now, |t| session.grant(t).ok(),
)?;
```

慢载入不进入无线回调；未来队列必须有界并按安全会话代次路由。运行入口处理前后仍检查真实权限，平台空闲时仍轮询撤销并独立推进 Runtime。格式错误关闭本连接输入；错误会话的误投请求不驱逐现有控制者；断线不停止自主节目。

第三增量的 13 项协议专项与 3 项真实加密工作器专项，加上原有相关回归，合计 74 项通过。包含最长文本、全操作／错误、独立字节向量、截断／尾随、错误 UTF-8／超长／无界字段、逐位变异和加密重试／断线场景。第四增量已补真实 TCP／GATT 软件分片的[客户端验证](device-runtime-client.md)；生产固件、桌面入口或物理发送尚未验收，不能显示设备已经出光。
