# 设备身份与能力描述

DEVICE-002A；依据 [ADR-035](../development/decisions/PRODUCT-ADR-035-device-capabilities.md)。`stagemaster-device-info` 为独立 no_std、无堆、无 I/O 模块；固件负责取硬件元数据，宿主负责读取／期限／生命周期，界面只展示 Rust DTO。

## 调用与归属

```rust
let description = Description::decode(&bytes)?;
description.check_session(diagnostic_client.session_id().ok_or(Error::Session)?)?;
// 仅匹配本次连接。description 的任何字段均不能创建 AuthorizedLink。
```

固件 `Identity::capture()` 每次启动只调用一次，读取出厂 MAC 并产生公开启动标识；`describe(session)` 为每条连接生成不可变值。稳定设备标识为 10 字节 `SMESP32S3\0` 加 6 字节出厂 MAC，不使用随机广播地址／macOS 外设 UUID。启动标识与会话随机数只用于关联，不是密钥或认证证据。

同一诊断服务 `f889ed60-0100-4e83-968e-799ab99558fa` 内，新增只读特征 `f889ed64-0100-4e83-968e-799ab99558fa`。握手成功后，主机在现有 I/O 期限内读取完整描述并核对会话，全部通过后发布已连接状态。ATT 分段长读期间值不变；保活不重复读取。断开／取消／超时／会话过期清除描述。没有特征返回 `None`，保留旧诊断兼容；有特征但无法读取或内容无效则明确报错，不能静默降级。

## 第 1 版字节格式

固定 96 字节，整数均为小端。偏移从零开始；数组为原始字节。独立黄金用例见 `crates/stagemaster-device-info/tests/wire.rs`。

| 偏移 | 长度 | 内容 |
| --- | --- | --- |
| 0 | 4 | `SMDC` |
| 4 | 1 | 主版本，1 |
| 5 | 1 | 保留，零 |
| 6 | 2 | 总长，96 |
| 8 | 16 | 稳定设备标识，非零 |
| 24 | 16 | 本次启动标识，非零 |
| 40 | 8 | 当前诊断会话，非零且与握手相同 |
| 48 | 2 | 型号，1 为微雪 ESP32-S3-RS485-CAN |
| 50 / 52 / 54 | 各 2 | 固件主／次／修订版本 |
| 56 | 4 | 能力位 |
| 60 / 62 | 各 2 | 播放包／传输协议版本 |
| 64 | 4 | 包最大字节数 |
| 68 / 70 | 各 2 | 最大节目数／线路数 |
| 72 / 74 | 各 2 | 消息／分块最大字节数 |
| 76 / 80 / 84 | 各 4 | 槽字节数／装载预算字节数／帧间隔毫秒 |
| 88 | 2 | 认证机制编号；零表示未接入 |
| 90 | 6 | 保留，全零 |

能力位 0–4 依次为诊断、目录、安装、播放、DMX 输出。诊断必须存在；安装／播放依赖目录，DMX 依赖播放；安装还须声明非零认证机制。未知位、型号和认证编号保留用于显示差异，绝不自动授予未知功能权限。未知主版本、长度错误、非零保留字节、零标识、会话不匹配、矛盾能力或预算拒绝。

目录要求非零包版本／容量／节目数；安装要求非零传输版本、消息 >8 字节、分块 >0 且不超过消息减 8、槽不小于包；播放要求非零线路／装载预算／帧间隔。未声明相应能力时，所属预算必须全零。真实安装入口还须另做本地协议兼容、资源和已认证权限检查；描述自身不保证接收端具有这些能力。

当前 0.2.0 固件仅声明诊断（位值 1），认证与全部预算均为零；`storage-readiness`／`runtime-readiness` 构建不会改变声明。生产授权、24 小时期限、安装结果和实时剩余空间均不属于此只读描述。

## 验证入口

Rust 黄金字节／坏包／未知位测试，以及 host 生命周期中的旧固件、错误描述、取消／过期／重连测试；UI 隔离页核验新描述、旧固件和宿主通信故障。实板使用项目 Python 环境执行 `tools/hardware/device_description_probe.py --output data/DEVICE-002/identity-before.json`；随后显式重启设备，再以 `--previous` 比较稳定身份与启动身份。工具只做诊断握手／保活／读取，不安装或输出。
