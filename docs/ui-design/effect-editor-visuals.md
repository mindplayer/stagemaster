## 生成与检查

使用内置 Image Gen，三个独立请求；每次附上已查看的旧舞台画布时间线图，完整内容见[提示词](effect-editor-prompts.md)。请求目标 1440×1024，三张实际输出均为 1487×1058 PNG，未拉伸、裁剪或加工。项目内副本与工具返回原文件逐字节一致。

三张均已逐张查看：主要区域完整，中文标题、八灯范围、离线预览、参数和片段可辨；没有现场执行大按钮或虚构在线状态。它们用于比较信息层级，不能直接当作像素和工程语义的准确实现标准。

实施前须修正的生成瑕疵：

- 三张都过度保留旧参考图的舞台装饰与近似等亮光束，未准确表达各灯 0.25 秒错开的瞬时亮度；将改用真实状态驱动的可辨对象视图。
- 图 1 的染色轨图标被生成成音符，不符合对象类型；局部数字与周期曲线不是精确数学绘制。
- 图 2 部分时间单位仍为英文 s，片段边界与题设 4–14 秒不精确；顶部离线预览被画成可切换外观，正式产品不可借此隐式改变输出权限。
- 图 3 亮度曲线的周期、边界和把手与数值未严格对齐；界面设计确定后必须由同一权威数据绘制，不能仿照图片手写近似结果。
- 选择、焦点、快捷键、拖动、错误、字体缩放和窄屏尚未实际实现或验收。图片生成不能证明帧率、灯具校准、DMX 或 UE 渲染能力。
