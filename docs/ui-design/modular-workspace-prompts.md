## 任务工作区

```text
Use case: ui-mockup. Create a realistic, production-quality redesigned desktop interface for 舞台大师, a professional Chinese stage-lighting and audiovisual show authoring application used by a working lighting designer on a MacBook. Current date 2026-09-24; no dates need be printed. Target canvas exactly 1440 x 1024, app content only, flat edge-to-edge viewport with NO browser chrome, device frame or presentation border.
Input image is the user's previously chosen visual style reference, NOT an exact layout to copy. Preserve the navy-gray and cyan identity but reorganize the information architecture so the software can scale: venue/stage/audience arrangement, fixture definitions and patching, scene/effect/timeline creation, external audiovisual monitoring, live operation, device delivery. They must NOT all appear as panels at once. Full Chinese business UI. Never use Cue, GO, LIVE, EDIT, Save or other English business labels. DMX, RGB and numeric identifiers allowed.
Use design tokens: background #0d1720, surfaces #182530, subtle dividers #2b3e4e, body text #e9eff7, secondary #9bafc5, accent #31d8e6. Premium restrained workstation aesthetic, matte surfaces, crisp 1px boundaries only as necessary, 6px control radii, no gradients in app chrome, no oversized branding, no decorative cards. A realistic technical 3D stage viewport may have lighting gradients. PingFang SC / system sans, readable 14-16px body text and 20px important title at target resolution, tabular time digits. Muted hierarchy with cyan reserved for selection / focused editing. Avoid a wall of features; spacing, grouping and typography before borders, no cards within cards, no dashboard metrics, no educational text.
Hero task: editing a selected timeline clip named 汇聚开场, affecting 逆光组 · 8 台. The 3D stage occupies the dominant area, with stage platform, truss-mounted fixtures, subtle audience blocks and eight cyan-blue beams aiming at a single movable target on the stage. Small visible transform target with a clear cyan selection ring. Stage graphic is a preview, never a photograph of a live feed; small label 离线预览. Support a compact inspector and a readable 4-track timeline: 面光, 逆光, 染色, 音乐参考. Audio waveform is a reference only. No video editing / mixing controls. Selected clip cyan outline, other tracks subdued teal/violet. A single playhead at 00:08.4. A single set of preview transport controls, no duplicate bottom live execution bar. No cue triggering while editing.
Inspector must say 汇聚开场 then 当前片段 and 逆光组 · 8 台, with short controls e.g. 亮度 65%, 颜色 冷蓝, 指向 中心目标, 渐入 2.0 秒. Do NOT confuse group selection with changing clip membership. Layout should suggest deeper capability without printing a big explanation. Main file header 工程 夏夜现场 and 已保存. Device state 未连接 is modest, never fabricated operational green. No tutorial banners, simulated-data warnings, version badges, dev notes, roadmaps, arbitrary feature placeholders or explanatory marketing copy in the screen.
Render a single cohesive screen, never a collage or multiple option panels. Fill all allocated layout carefully with plausible short Chinese labels, generous useful stage space, aligned columns and unclipped readable text. Do not include design-direction title in the screenshot. The rest of the app exists off-screen.
Design direction name: 任务工作区.
Information hierarchy: a slim global header (height 56) with small 舞台大师 brand left, project name, saved state, compact undo/redo; center task tabs 布置 / 灯具 / 编排 / 现场, 编排 selected with cyan underline. Right global button 设备 and search icon; device configuration and cloud version history live behind those utility entries, not in the left resource list.
Beneath header a quiet document strip shows 主节目 and current scene 汇聚开场, then flexible workspace. Left resource column 196px wide, categorized 灯组 / 场景 / 资源. 灯组 active, list 面光组 8 / 逆光组 8 selected / 染色组 12, plus two small saved target/preset entries lower down. Left stays a dense list, no cards.
Main middle: toolbar 选择 / 指向 (selected) / 俯视 / 三维, scene preview taking almost all upper central area, orthographic-inspired perspective and a clearly draggable shared target, NOT an illustration filling the entire app. Right inspector 280px wide, tabs 参数 / 曲线 / 顺序 with 参数 active. Selected clip context is prominent at top, then just 4-5 important controls. Footer of inspector has a quiet collapsed section 更多属性.
Bottom timeline approximately 285px tall across the ENTIRE width beneath the left/middle/right top panes, restoring enough horizontal time space. Timeline header 时间线 / 场景列表, a modest preview-play icon, time and zoom. Four compact tracks with labels ~170px wide; tick marks from 00:00 to 00:20 and main clip 00:04 to 00:14. A slim final status line shows 8 台已选 and 离线预览, no large live strip.
Strong visual structure and clear four task tabs show room for sophisticated workflows without cramming more buttons into the editing view. This is a refinement of the attached reference into a calmer scalable modular workstation.
```
