## 舞台画布

```text
Create a realistic, production-quality UI design for StageMaster / 舞台大师, a professional desktop lighting programming and live show control application. This is a new conceptual visual prototype based on a researched design brief, NOT an implemented app. Target dimensions 1440 x 1024, natural desktop screenshot aspect ratio, full app content edge-to-edge, no laptop/device bezel/browser chrome/mockup framing. Crisp legible Simplified Chinese UI, use Noto Sans SC or equivalent clean Chinese sans-serif, 14-16px body baseline, clear hierarchy and exact numerals. One coherent primary screen, not a feature inventory. Use spacing, alignment, row separators and restrained flat surfaces; no card-in-card dashboard, no glossy skeuomorphic knobs, no excessive shadows, no promotional hero section. This is a tool a working lighting designer uses, grounded and calm, not a sci-fi control room. Do not imitate proprietary logos or exact layouts.

Shared fictional scenario for all alternatives: project title “夏夜现场”; one main cue sequence. Current live playback cue is “12 主歌”; next GO will execute “13 副歌”; the operator is separately editing “14 桥段” in isolated preview. These three states MUST remain unmistakably distinct everywhere. Selected fixture group “逆光组 · 8 台”; show only eight fixtures when depicting selection. Editing intensity “65%”, color “冷蓝”, fade “2.0 s”; these are editable PREVIEW values, do not imply they are currently sent live. Primary editing action “保存到 Cue 14” with small explicit nearby text “仅保存，不触发播放”. A persistent live status strip must show “正在播放 12 主歌”, “下一条 13 副歌”, “GO → 13”. Use “离线预览 · 不改变现场” as a clearly legible label near the editing content. The application mock itself has a small quiet label “概念原型 · 模拟数据”. Any stage depiction says “预演画面”, never claims actual device feedback or connection. Do not add account avatars, cloud sync controls, charts, fake device-online green lights, analytics metrics, AI copilots, or internal technology terms. Color used for creative lighting content must be separate from small status markers; do not make whole rows neon. Chosen but not running = outlined/selected treatment, running = a small icon plus text, next = labeled cue pointer. Keep the UI spacious enough to read yet useful for real work. Dates not needed; current date anchor if any date is shown is 2026-09-21. No decorative filler or invented functionality.

Design direction name: “舞台画布”.
A sophisticated canvas-first editing workspace. Quiet slate-dark application chrome with a large lighter graphite central stage canvas; teal/cyan accents confined to selection and primary editing action. Main composition: small top project bar, left compact fixture/group navigation about 190px wide, a dominant center stage canvas about 870px wide, right properties inspector about 310px wide. The canvas occupies most of the vertical screen, NOT a photorealistic game environment: a beautifully restrained orthographic 2.5D black-box theatre schematic with a stage platform, upstage truss and exactly eight backlight fixtures in a row, eight subtle blue cones onstage and fine fixture labels B01 through B08. The eight selected fixtures have thin cyan selection halos. Stage shown is isolated preview Cue 14 and clearly labeled “离线预览 · 不改变现场” + “Cue 14 桥段” + “预演画面”.
Left navigation has just “灯具” and groups “全部灯具 24”, “面光组 8”, selected “逆光组 8”, “染色组 8”, minimal search; do not show irrelevant inventory. Right inspector heading “逆光组 · 8 台”, subsection “正在编辑 Cue 14”, a practical intensity horizontal slider at 65%, discrete color swatches with 冷蓝 selected (color preview plus exact text), fade field 2.0 s, and the main button “保存到 Cue 14” with “仅保存，不触发播放”. Avoid large empty graphic color wheels: prioritize direct values and actual meaningful controls.
Below central canvas use a single compact cue strip (not a giant timeline): five rows or slim segments for “11 前奏”, “12 主歌” marked 正在播放, “13 副歌” marked 下一条, “14 桥段” marked 编辑中, “15 尾声”. Cue 14 editing selection outlined teal, Cue 12 running icon understated, Cue13 next arrow. At absolute bottom a persistent, visually distinct run bar showing “正在播放 12 主歌” and “下一条 13 副歌” with fixed right-side “GO → 13” button. This run bar reflects the live sequence independently of the preview canvas. Typography crisp and Chinese text accurate. Flat intentional panels, minimal 6px radii, substantial negative space around stage, realistic editing application. Small concept direction name may appear subtly near logo, no option numbers, no explanatory text outside the app.
```
