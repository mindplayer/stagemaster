# 桌面工程工作台

DESKTOP-001，2026-09-23。当前正式入口为 Tauri＋React 工作台，数据和编辑事务由 Rust 管理。

## 当前功能

- 从空白工程开始；打开／保存 JSON、另存为、修改工程名称及备注。
- 通用单通道调光和四通道 RGB 调光档案；添加灯具、命名、线路／起始地址配适。既有工程可携带已支持的归一化档案。
- 新建场景、改名、调整灯具属性、释放／清除记录、删除场景；保留原始预设引用，调整具体属性时明确变为字面记录。
- 撤销／重做、未保存提示、正常退出／新建／打开前保存保护；错误和取消保留当前工程。

编辑界面只读 Rust 返回的投影视图，发类型化命令；不解析工程正文，不计算播放结果。舞台画布／时间线原型代码留作后续接入参考，不在正式入口显示。

## 构建与运行

```sh
npm --prefix apps/ui-prototype run desktop:build
npm --prefix apps/ui-prototype run desktop:dev
```

本机应用：`target/debug/bundle/macos/舞台大师.app`。打包后使用嵌入资源，不依赖 Vite 服务。此产物是本机开发构建，尚非签名、公证或升级分发安装包。

构建脚本显式将 Cargo、npm 缓存及临时文件定位在项目 tmp/；Rust 工作区检查使用同一 CARGO_HOME。前端仅宿主适配器依赖 Tauri API。浏览器宿主尚未接 Rust 服务，不提供虚假的工程读写。

## 当前边界

只接受通过严格 JSON、既有 Schema 和灯光子集领域校验的工程；场景列表、时间线、外部媒体、机构、资源／扩展尚未接收，明确拒绝而不丢弃字段重存。本轮不输出 DMX、不连接设备、不播放音视频。工程格式仍是未发布的 0.1.0-draft.1。

存储限 8 MiB／64 层；同目录临时文件同步后替换。稳定锁文件用于本产品多进程协调，保存前后比较已加载磁盘字节；不同步遵守锁的第三方程序仍可能在最终比较与替换的间隙写入，因此不宣称任意外部编辑器间的完整文件事务。跨操作系统、崩溃自动恢复、网络盘断电和硬件持久性尚未验收。撤销记录最多 32 次并限制序列化历史预算 16 MiB。
