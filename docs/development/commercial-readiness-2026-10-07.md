# 首次商业交付进度评估

StageMaster 已越过界面原型阶段，处于软硬件集成和产品化验证阶段。工程编辑、场景执行、设备安装和受限自主播放已有实质实现；**目前还没有一份通过真实灯具、长期运行及客户安装验收的商业版本**。最快路径是交付范围明确的固定场地灯光套装，再扩展声光电与专业预演。

日期：2026-10-07。工单：[PLAN-006](tasks/PLAN-006-first-commercial-release.md)。源码基线：main `c31e382`。配套[完善计划](first-commercial-release-plan.md)是本次结论的实施入口。

## 进度依据

本次核对当前源码、任务和保存的验证记录，实际打开最近已验证的桌面候选，检查打开工程、编辑、执行、设备和发布入口。没有重新运行整个测试集、连接实板、输出灯具、播放音乐或启动 UE。

原生界面候选为 `desktop-release-0yVoVN`，绑定 `ce49137`；到本次基线，前端差异仅两个验收夹具，产品前端未变。它适合本次界面审查，不能充当最新 Rust 后端的组合验收。80 灯、20 场景工程使用通用测试灯型，也不是 80 台实灯的交付证明。

最新保存的检查点包括 PREVIS-014 的 **1,362 项 Rust 测试和 2 项文档测试**、严格检查，以及 UX-051 的 **486 项 UI 测试**。它们来自不同但明确的源码检查点，不能相加成商业完成率，也不是本次重跑结果。

**不沿用旧“70%”作为商业完成比例。** 那是 AUDIT-001 特定改进范围的主观估计。现在最准确的阶段描述是“功能基础已形成，真实输出和客户交付尚未闭环”；剩余项目的风险和耗时远高于按钮数量所暗示的比例。后续按计划的六个交付门逐项计数，避免虚假的精确百分比。

## 四个需要立刻改变优先级的问题

1. **真实 DMX 应该提前。** `LogicLine::enable` 仍保留 RS485 禁用，正常运行固件与试验镜像的资格必须分别确认。600 秒逻辑 UART、绿色指示灯、软件帧一致性都不能替代 RS485 差分波形和实际灯具。继续优化界面不会降低这项不确定性。
2. **“断开后继续播”和“无电脑能用”还差本地操作。** 桌面已有设备节目控制，受限 Runtime 已有控制权和状态机；现有面板来源的探针不是客户按钮。盒子必须能选节目、开始／推进、停止并反馈状态，否则客户上电后仍需要开发者或电脑。
3. **音乐编辑与设备节目是两条能力链。** 当前发布页明确：音乐、卡点、时间线渐变不随设备包导出。不能把音乐工程导出为纯场景包后宣称原灯光秀已完整部署，更不能默认蓝牙音箱与盒子精确同步。
4. **内部构建不能替代发行包。** 本次常规启动内部候选超时；其源码明确要求指定验收实例。按已有参数启动后正常，最终退出码 0。这是内部包用途限制，不能误诊为正式版本启动缺陷；但也证明尚需不依赖源码路径、环境变量和开发工具的客户组装。

## 数据和框架判断

- 继续复用当前工程、编译器、Runtime／Player、安装器和端口模块。没有证据支持重选 Rust／C++／Flutter，或重新实现状态机。
- ESP32 继续做受限自主播放器；完整工程在电脑处理，受限包经预算校验后安装。存在 8 MiB PSRAM 及既有实板记录，不等于可以无限装载或已经覆盖全部栈峰值。降级网桥仅在后续测量证明目标场景不适用时讨论。
- 电脑执行主机到真实输出节点的链路不能用“盒子自主播放成功”替代。首发若承诺电脑实时控灯或音乐联动，必须增加该链路的真实出口；最快范围先承诺设备驻留节目的远程操作。
- 工程 JSON 与随附资源目前是文件和目录协作。首版可先做可验证的“复制工程及所需资源到文件夹”，不用先创造加密新格式；单文件容器以后按版本契约增加。
- 云、U 盘、商业身份、许可和内容校验边界继续保留。首单不需要先开发云账户、商城、支付和订阅，但开发凭据不能直接当量产凭据。
- 当前用户自定义档案灵活性保留；“可建档”与“已测可交付灯型”分开。不能通过隐藏未知通道、缩短通道占用或虚构默认值获得发布资格。

## 开发方法的调整

旧 execution-plan 和 Sol 入口仍指向 10 月 4 日的 AUDIO-020 可视编辑，已有不少内容已完成。它们应更新到本计划，避免重复建设。旧 H1–H5 的完整音乐／三维目标保留，不能将本次收窄的首发套装通过写成它们全部通过。

已完成的大量保护测试是资产。下一阶段把精力从零散微调和重复证明转到同一候选的真实交付：每项局部改动做相关验证，在候选冻结时做一次全面回归和代表任务。真实失败保留；未知历史失败依影响和可复现性归类，不因一次通过就宣称修复，也不因为孤立历史记录无限扩展诊断框架。
