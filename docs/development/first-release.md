# 第一版交付标准

2026-10-06：用户要求以第一版可交付为优化标准。沿用[H1–H5](sol-handoff/roadmap.md)，优先完成主流程、数据保护、执行稳定性和可复现交付，不扩H6–H8，也不将试用标准写成商业成熟度。

## 范围与出口

第一版目标是Mac单机编排、可选本机音乐、唯一只读三维和一款ESP32播放盒的一路DMX受控试用。无音乐剧本也是完整主流程，基础编排不依赖UE。三维、声音、真实输出分别报告资格；软件试用可以先准备，但不能代替完整软硬件出口。

内部试用步骤、音乐丢失处理和恢复边界见[操作与恢复说明](first-release-operations.md)。其版本绑定和实际验收范围必须一并阅读，不当作客户发行说明。

| 必过项目 | 当前结论与剩余门槛 |
| --- | --- |
| 工程安全 | 严格打开、撤销重做、保存重开和资料缺失恢复沿用已验证实现；阶段出口需在最终版本重跑代表任务，不静默丢数据 |
| 编排与现场 | 循环目录／精确／成组编辑、亮度、总控、释放、批量与回执已交付；原生拒绝历史与音频预留偶发原因仍未全收敛 |
| 音乐与三维 | 当前候选静音原生／GPU通过；用户确认第一段声音正常、暂停后无声，恢复／自然结束听感尚未确认；不声称声卡时延／物理同步合格 |
| 灯型安全 | 声控、自走和未知危险宏继续核心／界面双层拒绝；实际11／18通道灯型未知范围和光学不得虚构，测试子集不冒作实灯完整档案 |
| 播放盒 | 原受限自主运行与逻辑UART证据保持；接线、差分波形、实灯、完整最坏组合、完整栈与8小时压力仍是必过门槛 |
| 安装与恢复 | 优化内部包不是客户发行包；最终干净安装／升级／回退、无编辑器客户三维、权限／签名／最低系统仍需验证 |
| 交付资料 | 准确版本、能力／容量、操作与恢复、已知问题、日志入口、素材和第三方告知；材料收集不等于商业或法律批准 |
| 真实使用 | 未参与开发的灯光师完成无音乐剧本、音乐片段、脱机盒子三条任务；自动测试不能替代 |

## 当前优化顺序

1. 归档正在进行的验收真实结果，停止测试音频与所属进程，保护来源与用户output/。
2. [DESKTOP-006](tasks/DESKTOP-006-dependency-notice-materials.md)：补桌面Rust／界面依赖的离线告知索引与原文，列出缺项，不修改原包或许可判断。
3. 按依赖满足的H1–H5软件缺口继续，以最终版本运行三条代表任务并完善试用说明；缺硬件／客户权限的部分只暂停对应出口。
4. 现场条件明确后做H3／H4实测；全部门槛满足后才称完整第一版受控试用可交付。

不前置多轨、云端、移动端、完整专业控台和光学扩展；不删除已有能力或弱化验收来换取“首版完成”。公共语义与持久格式仍按ADR处理，普通实现自主推进。
