# 第一版交付标准

2026-10-06：用户要求以第一版可交付为优化标准。沿用[H1–H5](sol-handoff/roadmap.md)，优先完成主流程、数据保护、执行稳定性和可复现交付，不扩H6–H8，也不将试用标准写成商业成熟度。

## 范围与出口

第一版目标是Mac单机编排、可选本机音乐、唯一只读三维和一款ESP32播放盒的一路DMX受控试用。无音乐剧本也是完整主流程，基础编排不依赖UE。三维、声音、真实输出分别报告资格；软件试用可以先准备，但不能代替完整软硬件出口。

内部试用步骤、音乐丢失处理和恢复边界见[操作与恢复说明](first-release-operations.md)。其版本绑定和实际验收范围必须一并阅读，不当作客户发行说明。

| 必过项目 | 当前结论与剩余门槛 |
| --- | --- |
| 工程安全 | 严格打开、撤销重做、保存重开和资料缺失恢复沿用已验证实现；阶段出口需在最终版本重跑代表任务，不静默丢数据 |
| 编排与现场 | 循环目录／精确／成组编辑、亮度、总控、释放、批量与回执已交付；原生拒绝历史与音频预留偶发原因仍未全收敛 |
| 音乐与三维 | 已验音乐候选`b0f3a7b`／`desktop-release-qooqnJ`静音原生／GPU通过，不是后继main或新包的组合资格；用户确认第一段声音正常、暂停后无声，恢复／自然结束听感尚未确认；不声称声卡时延／物理同步合格 |
| 灯型安全 | 声控、自走和未知危险宏继续核心／界面双层拒绝；实际11／18通道灯型未知范围和光学不得虚构，测试子集不冒作实灯完整档案 |
| 播放盒 | 原受限自主运行与逻辑UART证据保持；接线、差分波形、实灯、完整最坏组合、完整栈与8小时压力仍是必过门槛 |
| 安装与恢复 | 优化内部包不是客户发行包；最终干净安装／升级／回退、无编辑器客户三维、权限／签名／最低系统仍需验证 |
| 交付资料 | 准确版本、能力／容量、操作与恢复、已知问题、日志入口、素材和第三方告知；[DESKTOP-010](tasks/DESKTOP-010-native-handoff-exports.md)已补当前内部候选报表／包的软件交接实测，非整个盒子资格；材料收集不等于最终附包、商业或法律批准 |
| 真实使用 | 未参与开发的灯光师完成无音乐剧本、音乐片段、脱机盒子三条任务；自动测试不能替代 |

## 当前优化顺序

2026-10-06 用户明确当前核心不是音量／听音。听音保留后续独立验收，不再反复追问准备或将其作为软件开发前置；完整首版标准不因此降低。

1. [EXEC-017](tasks/EXEC-017-source-package-script-consistency.md) 完整三步源工程／安装后运行对照、[EXEC-018](tasks/EXEC-018-observation-binding-lifecycle.md) 后台观察归属、[EXEC-019](tasks/EXEC-019-preview-intent-lifecycle.md) 离线预演未发送意图保护已完成；后两项有真实组件红绿与各自独立 release 桌面无音乐流程证据，不转移旧音乐／GPU 资格。继续优先编排数据、执行稳定性与主链路，跳过已交付项。
2. 核对已完成项后继续依赖满足的 H1–H5 核心软件缺口；每项内聚实现与实际验证，不因既有绿色检查宣称没有可改善的核心路径，也不无限扩展局部 UI。
   [AUDIO-024](tasks/AUDIO-024-managed-resource-paths.md) 已补受管理缓存／随附路径保护、错误指导和真实原生拒绝／安全位置另存；不自动拆链接、不混同资料完整与声音输出，也不转移旧包资格。
   [RECOVERY-002](tasks/RECOVERY-002-bounded-record-discovery.md) 已补超量恢复目录的64候选有界集合、准确遗漏和原生选择／取消保护；不删旧副本、不改变预算或恢复格式，不把候选上限当作全部内存／崩溃资格。
3. DESKTOP-006／009／011 材料及 DESKTOP-007／008／010 原生流程已交付的部分沿用；不重复收集或把文档数量当产品进展。保护来源、output/ 和历史失败，不重放已收尾的测试音频。
   [DESKTOP-013](tasks/DESKTOP-013-source-bound-internal-build.md) 已将源码／Git差异／输入指纹自动随新内部包封存，归档后再核对身份／后台／来源；新包仅有限基础打开资格，不移植旧包资格或当作客户发行完成。
   [DESKTOP-014](tasks/DESKTOP-014-current-source-renderer-integration.md) 来源接线与当前包只读预资格已通过，修复scope引用泄漏并兼容完整自动快照／旧封套；组合重签及目录映射待明确授权，音乐／唯一三维新来源资格仍未完成，不以准备工作关闭H1／H5。
4. 有条件时分别接续听音、H3／H4 实物与 H5 客户环境验收；缺条件只暂停相应出口，全部门槛真实满足后才称完整第一版受控试用可交付。

不前置多轨、云端、移动端、完整专业控台和光学扩展；不删除已有能力或弱化验收来换取“首版完成”。公共语义与持久格式仍按ADR处理，普通实现自主推进。
