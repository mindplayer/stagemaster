# 项目文件规则

更新：2026-09-18。StageMaster 的源码、工程和开发产物统一放在 `/Users/sunqi/projects/stagemaster`，当前文件树只保留现行版本与有效参考资料。

| 内容 | 项目内位置 | Git |
| --- | --- | --- |
| 产品源码、测试、工程清单 | `crates/`、`apps/` 及根工程文件 | 纳入版本 |
| 脚本、工具和配置模板 | `tools/`；部署接线按需放 `infra/` | 可复现且无秘密的文件纳入版本 |
| 需求、架构、工单与交付 | `docs/` | 纳入版本 |
| 持久开发产物 | `data/development/` | 忽略运行状态和原始大文件 |
| 日志与临时文件 | `logs/`、`tmp/` | 忽略；需要临时根的命令显式指定项目 `tmp/` |
| 隔离任务工作区 | `.worktrees/<task-id>/` | 忽略，由 Git worktree 管理 |
| 当前 Cargo 构建产物 | `target/` | 忽略，可从最新源码重建 |
