4. 默认第一项：按 2026-10-07 首发计划开 R0 候选与交付路径，随后优先 R1 实灯／差分验证。AUDIO-020 可视编辑和后继 EXEC／UX 已交付范围不重复；发现真实回归先修具体故障。

## 已确定的产品方向

| 项目 | 当前决定 |
| --- | --- |
| 用户任务 | 同时支持按剧本人工推进与按时间／音乐编排；音乐是可选输入 |
| 专业能力 | 编排和现场控吸收 MA／Titan，专业展示吸收 Depence；学习公开行为与标准，不复制私有代码 |
| 界面 | 中文、组件化、剪映式连续工作流；舞台、资源、时间、属性协作，常用项就地操作、高级项渐进展开 |
| 当前平台 | MacBook 上的 Tauri 2＋React＋TypeScript，Rust 负责领域和执行；以后适配平板、手机、Web、ARM 与控台 |
| 渲染 | UE 作为独立可替换渲染后端，画面在应用内部；客户版需随产品交付可运行组件，不以安装 UE 编辑器为要求 |
| 首款盒子 | 微雪 ESP32-S3-RS485-CAN，一路 DMX。保留受限包解析和自主状态机，主机编译完整工程；网桥是另一个角色 |
| 设备家族 | 按能力组合独立播放器、输出节点、控制面、带屏控台；设备身份不等于固定角色 |
| 连接 | 传输和业务分离；已有 BLE GATT 先用，有线／局域网另接适配。不把星闪记作已选或已实现方案 |
| 音视频 | 当前本机音频播放／监听已实现；未来兼容外部播放与监看，不扩张为专业音视频编辑器。视频同步与外部动作尚待实现 |
| 云端 | Fastify＋PostgreSQL＋对象存储；资产、版本、目录、分发和商业权限。不是实时灯光求值器 |
| 交付 | 云端与 U 盘并行，先校验并准备本地内容再执行；物理 U 盘直连按设备能力单独实现 |
| 商业保护 | 身份、权益、内容保护、安装和激活分离；具体生产方案后议，当前不实施历史 24 小时限时规则 |
| 控制面与机构 | 推子／旋钮输入经同一语义控制入口；电机／激光专用安全能力与现场控制器独立，不用普通灯值旁路代替 |

主语言保持 Rust＋TypeScript；UE 适配允许必要的 C++，不引入 C++26 重写核心。脚本按现有构建／测量工具使用，不为“语言统一”重写可靠工具；包体要按实际链接与资源测量。

## 跨任务不变量

1. 编辑文档、草稿预演、已准备运行快照三者分离；保存不隐式替换正在演出的版本。
2. 单调执行时间、媒体消费位置、编辑播放头分离；禁止前端／UE 创建第二正式时钟。
3. 先合成语义属性，再编码 DMX；粗细轴整体处理，零值、释放、停止和熄灯不是同一操作。
4. 观察不会取得控制权；旧工程代次、旧控制者、旧票据、旧设备回执不得操作新对象。
5. 解析／资源准备在调度外；热路径、队列、内存、文件与解析工作量须有界。PSRAM 或大 Flash 不豁免预算。
6. 连线、安装成功、运行、驱动完成、物理测量分别报告；绿色灯不是 DMX 合格证据。
7. 渲染故障、UI 关闭、云不可达不得自动破坏已准备的本地播放；故障策略必须按原契约显式处理。
8. 未支持能力显式拒绝并定位，不静默丢弃、不虚构颜色／行程、不增加占位按钮。

## 开发节奏

每个增量解决一个可验收问题，涉及核心→宿主→UI 时可纵向完成，不按文件数机械拆单。先读相关成熟经验，再局部实现、相关回归和真实操作。错误、取消、撤销、重开与跨对象保护同属完成条件。

不估算“几天完成全部 MA3”。用路线中的出口报告进展：已实现／已软件验证／已原生验证／已实物验证分别记录。普通局部改动无需重复全量构建和全部硬件验证；对依赖、格式、调度／控制权变更按风险扩展验证。

真正阻塞需要用户明确的是设备接线／可用测量工具、商业许可政策、最终采购和公开部署等事项。UI 的普通排版、拆文件、错误处理和既定接口接线由开发会话自行完成，不每一轮把决定退给用户。
