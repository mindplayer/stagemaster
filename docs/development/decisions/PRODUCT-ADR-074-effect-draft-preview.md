# ADR-074：单例效果草稿即时预演

2026-10-01，当前会话评估采用；EFFECT-004，基线 `7422578`。接续 AUDIT-001 U03。

参考 [Titan Shape Generator](https://manual.avolites.com/docs/effects/shape-generator/) 的运行中调整周期、幅度、相位以及明确记录／清除边界。本项目先限定桌面单场景效果草稿，复用 Rust 工程校验、编译与唯一 Player／UE；不引入 TS 效果求值器或真实现场多源合成。

编辑器显式开启“即时预演”，替换当前离线播放并停止音乐；开始后同一效果的参数更新经 250 ms 合并、最多一项在途及一项最新候选送宿主。字段错误保持最近有效画面并显示原因，不抢输入焦点。正式“应用”沿原事务产生一次历史；取消或结束即时预演恢复进入时的已应用场景参数。不会恢复此前的音乐或其他列表播放。

桌面 preview_request 增加 beginEffectDraft／updateEffectDraft／endEffectDraft：begin 校验 generation、预览 epoch，参数仅为 sceneId、effect、illuminate；不是通用编辑旁路。update 还校验预览 epoch、递增 serial，以及同一场景／效果身份；锁内只读取版本／所属身份并克隆快照；完整编译在锁外完成，回到锁内重新核对 generation／content version／epoch／serial 后才替换。编译期间发生正式编辑或更换播放时，候选直接丢弃；失败不能停止音乐或替换正在播放的计划。end 以 epoch 限定所有权，旧结束请求不影响新的预演。快照 loaded 增加可选 draftEffectId，明确临时来源。

正式 Document、保存、恢复、代次及历史均不被预演修改。临时 Document 克隆经正常 EffectEdit 与可选点亮命令编译，不保存；开始前保存一个有界的已应用单场景编译结果供恢复，不保留第二套 Player。更新与恢复保持唯一 Player 的累计时间和暂停／运行／停止状态；周期改变按累计效果时间求值，允许相位变化，不声称现场无跳变变速。暂停后改参数在同一时刻重新求值。

任何正式内容编辑／历史变更清除草稿预演；载入音乐／场景／列表、打开工程同样更换 epoch，旧更新不可夺回播放。界面目标变化／离开效果编辑器结束所属预演；IPC 乱序、关闭中的更新与失效回执均有保护。停止／暂停不依赖有效草稿，继续同样不应隐式提交草稿。

计划／属性／命令沿用现有容量上限；稳定状态保留基线和当前草稿两个有界编译结果，原子更新编译期间临时多一个候选结果，临时工程不进入 32 节点历史。桌面会话与 UI 调度分别小模块；不改工程 JSON、设备包、UE 协议和实板固件。

验证出口：独立 Rust 输出对照、暂停时间、串号／身份／代次、失败原子性、结束恢复、正式编辑与保存隔离；UI 最新值合并／结束竞争／错误焦点，原生已有及新增效果、关键帧／双轴、取消／应用／一次历史／保存重开、唯一 UE。编译开销和预演手感须实际记录，不能以节流参数声明性能。

原生验收补充：渲染 HTTP 帧请求保持原快速失败策略，UE 对已有有效帧收到 503 可短暂保持上帧并按正常速率重试，不刷新 LastFrameAt；满 2 秒仍失效，403／409／损坏响应及场地／灯位写入失败不隐藏。仅观看容错，不向设备复用旧帧，不更改协议版本或真实输出。
