# PRODUCT-ADR-146：混合场地对象的原子平移

2026-10-04；已接受，实施与验收见 STAGE-007。基线 `322d1ab`，main，当前会话单写者。

参考 Vectorworks Vision 2025 的 [Modifying scene objects and fixtures](https://app-help.vectorworks.net/2025/Vision/Vision_help/Vision/Modifying_scene_objects_and_fixtures.htm?agt=index)：混合对象共用移动工具，精确调整采用相对三轴位移，保持对象之间的距离和各自高度差。复用本项目场地对象、挂接关系、锁定快照及编辑历史，不另建分组文件或播放器。

新增 `StageEdit::TranslateObjects { targets: StageEditLock[], deltaMeters: SpatialVector3 }`：1–256 个唯一直接目标，支持灯位、支撑体、地台、座区。位移严格十进制最多六位小数，三轴范围沿用灯位平移；各对象最终边界仍由既有工程验证器负责。支撑体挂接的灯具加入受影响集合；同一灯具无论直接选中或经挂接加入都只移动一次，最多覆盖工程已有灯位容量。未偏移的坐标保留原字符串，安装角、尺寸、空间归属及挂接关系不变。命令经原 Document 候选事务和锁定快照验证，任何直接或间接成员锁定／越界即整体拒绝；零位移不制造历史。空间归属不代表父子坐标，空间／围护不加入这次成组变换，界面明确告知原因；单空间原编辑保持。

界面选中集合扩展为有序对象身份，最后一个为主对象。目录修饰键多选、筛选外计数、平面高亮／聚焦、拖动和方向键使用同一集合。纯灯具组保留排列／挂接入口；混合组提供相对 XYZ 精确移动、取消和锁定。混合组不向三维发布其灯具子集，避免三维悄悄只移动部分对象；提交后场地仍由既有投影同步 UE。三维直接混合对象手势与框选留后续，不冒充本次实现。

草稿归属当前工程身份、场地内容快照及固定目标，通过已有 collect／beforeChange／accept 与全局保存、切页、历史协作。拖动预览为展示计算，最终位置由 Rust 命令决定；取消、来源变化和卸载不得提交旧手势。没有持久工程格式、执行语义或设备行为变化。
