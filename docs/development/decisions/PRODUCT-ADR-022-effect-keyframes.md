# PRODUCT-ADR-022：关键帧效果与编辑复用

2026-09-27；当前 Astra 审查接受，基线 `3a33ff5`，实施 EFFECT-002。

参考 [Titan 19 关键帧效果](https://manual.avolites.com/docs/effects/key-frame-shapes/)的帧状态、段间变化、时间位置和换灯范围，及 [MA Phaser](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html)的多步属性循环。本次采用绝对值、最多 32 个循环关键帧，逐段支持保持、线性和平滑；不接相对层、预设跟踪、现场速度主控或运动求解。

工程保留 `lighting.effects.basic@1`，关键帧效果另需 `lighting.effects.keyframes@1`。原有三种 waveform 和存储保持兼容；新增 `waveform: keyframes`，该模式下每个 channel 用 `keyframes` 替代 low／high，不允许混合或携带被忽略的值。帧为 `{position, value, transition}`：position 是周期的万分比，0–9999，首帧必须为 0，严格递增；value 为 u16；transition 控制本帧到下一帧的变化，末帧连接下一轮首帧。同一效果各属性的帧位置和过渡方式一致，适合以完整灯态编辑；各属性数值可独立设置。周期、灯序、相位及暂停／渐变规则沿用 ADR-021。

Rust 工程校验与编译权威化，播放内核编译为 Q16 关键帧曲线，每条属性最多 32 点，计划累计最多 131072 点，超限明确拒绝；采样无分配，效果内存报告包含点数组。预算不是 ESP32 已通过的容量承诺。UE／TS 不重复求值曲线。

编辑器拆出关键帧组件，支持增删、重排、均分时间、逐帧颜色／亮度、精确位置和过渡方式；取消不提交，一次应用进入一个历史节点。关键帧排序错误保留草稿并定位，不自动排序改变用户意图。原两端效果到关键帧转换是显式操作，只对可准确表达的平滑／线性／脉冲提供转换；不提供会丢弃帧的隐式反向转换。

效果复用先从当前工程其他场景复制独立参数，可保留原灯具或使用当前选择并重算灯序；新 UUID，默认停用，兼容性检查，应用后互不联动。暂不增加另一套持久模板池。半速／倍速只修改当前编辑草稿的周期，应用后重载预览，不冒充相位连续的现场速度主控。
