# PRODUCT-ADR-099：真实工程准备与本机独立执行进程

状态：accepted；2026-10-02；HOST-002；基线 `29e91e2`。接续 ADR-097／098，不改工程和设备包格式。本轮建立可运行进程与本机应用入口，尚不替换桌面或开放远程现场控制。

## 决定

`stagemaster-execution-host` 作为独立程序组合既有 DiskFile、工程编译、安装存储、Runtime 和 HOST-001。调用者明确指定工程、节目类型／身份及全新的运行目录；只读工程，按既有目标档位编译、校验／安装／载入，全部成功后才公布连接信息。不开机自动播放，不自动取工程第一个节目。暂时只允许显式 software-output 档位，没有物理输出适配；此许可仅限本地软件执行，不能替代生产授权。

复用项目已有 Axum／Tokio／Serde，实现仅 IPv4 loopback 的本机 HTTP／JSON 适配。主播放线程仍由 HOST-001 拥有；HTTP、JSON、会话及回执表在外层。核心不依赖 HTTP，也不把这个局部协议冻结为未来全产品 SDK。后续桌面 IPC 和远程认证网关适配同一应用边界，不复制播放逻辑。

## 身份与请求语义

- 每次进程启动产生新 hostId 与随机读取／控制凭据。凭据写在新建的私有目录／文件，stdout 只给非敏感就绪信息。读取凭据只能查询，控制凭据可创建操作会话及显式关闭本机进程；禁止浏览器 Origin、重复认证头、未知主机代次，接口不提供 CORS。
- 操作会话由服务端生成，创建本身不取得运行控制权。当前凭据代表同一本机操作者的读取或控制权限，不声称已实现多人账号／生产身份。Grant 主体由会话派生，客户端不能在 JSON 中填写 principal／lease 获权。
- 每会话最多一个在途操作；采用十进制字符串 serial，从 1 连续递增。保留最后一次请求和结果：相同 serial／负载返回相同记录；相同 serial 不同内容拒绝；跳号拒绝；早于保留窗口的 serial 返回不可追溯，绝不重新执行。新 hostId／sessionId 后旧请求无效。
- 运行核心的控制序号由适配器维护，和操作会话序号分开。提交动作带权威 expectedRevision；操作／业务失败各自报告。取得控制权后返回历史权威状态，不等待观察快照。收到内核 Receipt 后推进对应控制序号，包括 Receipt 中明确的业务拒绝；接纳／租约失败未产生 Receipt 时不推进。等待超时不能据此推断执行结果或另发新序号。
- HTTP 接纳返回 pending／complete 记录，后续可查询原回执。接纳后的处理不随 HTTP 断开取消，等待超时不解释为未执行；不会自动重新启动节目。会话失效不停止节目，控制租约按既有规则到期。

## 生命周期与预算

会话最多 8 个，空闲 60 秒且没有在途操作时回收；每个只保留一条回执。请求体最多 8 KiB，命令期限最多 5 秒；有界后台处理与 HOST-001 固定队列组合，不能绕过内核配额。连接数量及连接生存时间有上限，慢头／慢体不能无限占住任务。查询不需要运行控制权，状态投影不泄漏原生 Lease。

进程拥有执行宿主，操作客户端退出／被杀或本机 HTTP 断开都不关闭它。显式关闭先撤销接入，再停止宿主并等待线程；客户端关闭不得暗中映射到关闭进程。正常结束撤销发现文件；进程重启生成新身份，残留旧文件不能控制新实例。不承诺操作系统杀死执行进程后继续输出或自动恢复节目。

## 验证门槛

真实工程文件到编译／安装／载入／HTTP 状态，源文件摘要不变；无效工程／错误节目／已存在运行目录拒绝。真实子进程控制客户端被杀后，执行进程仍在，同一节目实例和位置继续；新会话显式接管，旧会话的延迟动作被拒绝。重复操作不重复启动，过期／冲突／跳号和陈旧 hostId 有明确结果。读权限不能写，缺认证／Origin／重复认证头／超大输入拒绝；表满和回收受限。关闭退出、重启凭据轮换，以及慢客户端不拖住执行须有独立证据。

本轮仅 Mac 软件验证；Windows／移动端生命周期、桌面迁移、远程认证、第二种解码器承载、跨设备同步和专业多执行器仍按后续工单推进。
