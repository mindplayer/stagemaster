# ADR-092：关键帧亮度模板及显式文件版本

2026-10-02 接受，基线 `9eacc42`，当前会话主工作区单写者。承接 ADR-090 的 MA 配方／Titan 可复用属性意图和现有关键帧效果求值器。LIBRARY-002 的原生验收发现，实际 Volare 工程主要使用关键帧，基础曲线模板不能完整导出这些效果；下一增量应解决现有编排的复用，而不是增加空的云端界面。

保留格式 1 的 `intensity-wave` 原样。格式 2 只定义 `intensity-keyframes`，携带 2–32 帧的归一化亮度、周期内位置和保持／线性／平滑过渡，以及共用的周期、相位、灯序展开和反向。位置必须从 0 开始并严格递增，范围 0..9999，亮度范围 0..65535；末点到下一轮仍按现有求值器语义处理，不自行补帧或改变过渡。文件仍最多 16 KiB，不携带灯具、地址、控制通道、脚本、颜色或运动。

格式号与配方类型严格对应；拒绝给旧格式塞新类型，也拒绝任意新版本。原工程来源外壳、摘要与不可变身份规则保持，格式 2 来源额外声明 `lighting.effects.template-keyframes@1`，使不支持的新旧软件边界明确；本地效果已有 `lighting.effects.keyframes@1` 继续由原编辑器维护。来源快照即使当前效果改为其他形式仍要求来源对应能力。新模板和老模板可在同一工程并存。

关键帧结构／排序验证复用现有核心与 Schema，导出／绑定转换放独立 recipe 模块。绑定只生成已有 SceneEffect，仍经过整场景编译、容量、冲突和审阅保护，运行时及硬件协议不增加第二套曲线实现。非适用的基础波形占空比不属于关键帧配方；应用后内部采用既有默认值，不影响输出。

桌面沿用同一导入导出工具；审阅展示只读曲线和帧数、范围，保留精确关键帧信息与灯序。验收要求基础格式兼容、新格式往返、三种过渡与周期边界逐值一致、32 帧边界、乱序／重复／超范围／未知字段／版本交叉拒绝、来源能力缺失拒绝、静态参数保持；正式应用导出已有渐入效果到另一个无冲突场景，取消、一次历史和保存重开通过。云目录及其他属性配方仍后续。
