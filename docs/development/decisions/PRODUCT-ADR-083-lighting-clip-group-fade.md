# PRODUCT-ADR-083：灯光片段的统一进入渐变

状态：采用；2026-10-01；对应 AUDIO-015。当前会话审查实施。

已有独立片段持久化 fadeMs，由 Rust 编译进入渐变。增加 `editLightingClips` 的 `action: {kind:"fade", fadeMs:u64}`，沿用非空、唯一、最多 512 项的稳定 id 集合；未知字段拒绝。它只设置已有 fadeMs，不更改工程格式、运行控制权、效果起点或媒体时间，不更改停用片段语义。

原子预检所有选中身份与锁定，再检查每段长度。任意一项失败不改任何片段；fadeMs 可以为 0 或等于片段长度。停用片段同样可编辑、同样受长度约束。无变化不产生历史。现有编译与时间语义继续有效。

界面共用音频草稿收集器；开启时固定 ids，混合值不默认为 0，搜索仅改变列表可见性。显式应用、保存或离开先收集，错误定位且保留输入／上下文；取消仅放弃此次渐变。原移动参数尚有输入或删除确认时先结束原操作。表单、预检、宿主与核心分层，不在 UI 模拟核心提交。

参考：沿用项目已研究的控台成组时间编辑及独立片段进入语义；不引入外部媒体处理、波形或混音依赖。本轮验证结果记入工单后评估出口。
