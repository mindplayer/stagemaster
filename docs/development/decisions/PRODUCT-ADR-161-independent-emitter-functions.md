# PRODUCT-ADR-161：独立光源的受控功能区间

状态：2026-10-05 当前实施会话审定，先记录再实现。接续 ADR-160／FIXTURE-006／H3，不放开声控、自走或未知控制宏。

## 问题、资料与成熟机制

[用户 18CH 资料](../../fixtures/user-supplied/README.md)明确图案光源频闪在通道 8、染色频闪在通道 15，各自 0–15 开光、16–255 慢到快；图案光源色盘／图案盘在通道 9／10。既有单元只支持连续值，不能把两个快门合并为根级 shutter，也不能用百分比绕过功能区间。30W 未确认的频闪／图案子范围仍不猜测。

参考 [GDTF 1.2 ChannelFunction／ChannelSet](https://gdtf-share.com/help/developers/gdtf_1_2/file-format-definition/index.html)：功能归属、原生区间与固定轮盘档位分开。复用本项目 FunctionTable、精准目标、直接切换和区间位置；不实现 GDTF 导入、Hz 推断、几何或新的灯具时钟。下面的有限白名单是本项目安全决定，不是标准强制或实灯测量结论。

## 决定与失败行为

- 保留 `emitter.<key>.<base>` 及原 1–32 单元／连续强度组合，额外支持单元 `shutter`、`color-wheel`、`gobo-wheel`。功能必须有 typed selection／原生区间、LTP；不接受 normalized 数值或函数效果。不能只建功能而缺该单元的连续光源强度。
- 除既有 emitters@1、fixture-functions@1，新增能力 `lighting.fixture-emitter-functions@1`，建档自动声明；缺失／未知版本或未使用模式中的非法定义读入均原子拒绝。无新增持久字段，旧连续单元保持原样；旧读取器拒绝新能力。
- 单元功能键表达允许的种类：shutter 仅 `open`／`closed` 固定档及 `strobe` 区间；color-wheel 仅 `open`／`slot-<稳定后缀>` 固定档；gobo-wheel 另可 `shake-<稳定后缀>` 区间。全表继续 1–64、唯一、不重叠、代表值和粗细精度校验。不得用任意 UUID 功能、声控／自走／随机／复位键或改变控制方式冒充上述功能。档案仍须以可信通道资料确认真实功能，不能从名字或裸值识别厂家隐藏宏。
- 18CH 已知 128–255 自动来回换色／换图、本轮不建可执行区间；第 16–18 通道内置混色／电机程序和混合宏仍不开放。固定图案和明确的单图案抖动是显式受控功能，不混同整机自走；未知频率、颜色、图案图片保留未知。测试档案不发布为实灯。
- 复用原功能编译与执行语义 2、FunctionTable 输出、LiveMixer／原播放器、释放与历史；功能直接切换，不渐变穿越中间值。OutputMaster 只作用原强度掩码，快门／轮盘不缩放；执行包不新增字段或固件功能。端点、区间外／代表值和自主键必须经核心拒绝。
- 界面每单元就地添加功能通道，复用拆出的功能卡、批量固定档与默认选择；中文标签含单元名，显式选择受控种类、控制方式锁定、原生数值留空待填。改变连续组合保留功能通道，移除单元仅改草稿；复制／取消／精确输入／错误定位和上下文保持沿原事务。
- 色盘外观仅固定档、沿原 appearance 能力；语义完整目标区分单元，稀疏预设／手动同样保留完整键。模式换灯只匹配准确属性和稳定功能身份；原固定色盘显式重映射可用于对应单元色盘，审阅按单元列清差异，不跨光源猜映射。图案抖动／频闪定义改变仍拒绝直接交换。
- 三维沿 `unmodeled-emitters`：同一灯体／轴、光束隐藏、唯一视窗，不让 TS／UE 执行频闪或图案模拟。真实功能输出监看不当物理反馈。

## 验证与出口

先复现旧 API 拒绝双快门，再实施。验证两个单元、非零起址、8／16 位任意粗细、开光／频闪端点、静态轮盘／抖动、直接切换／渐变隔离、能力／非法自主键／空隙原子拒绝、稀疏预设与手动、整组换模式／重映射、模式文件往返及旧连续模式兼容。相关和最终全量 Rust／UI／格式、严格检查、真实组件及正式桌面两灯操作／历史／保存重开实际执行，保留失败日志。
