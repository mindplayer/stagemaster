# PRODUCT-ADR-180：UE验证的有限报告助手所有权

状态：2026-10-06 当前实施会话审定，先记录后实施；关联 [PREVIS-013](../tasks/PREVIS-013-owned-crash-reporter-cleanup.md)。仅开发验证工具的子进程生命周期，不改变工程、执行时钟、控制权、公开接口、依赖或客户沙盒／签名。

现场三个旧 StageMasterPreview 报告助手各占一个 CPU 核心。实际 UE5.8 本地源码 `Engine/Source/Runtime/Core/Private/Mac/MacPlatformMisc.cpp` 的 `GenerateInfoAndLaunchCrashReporter` 先生成报告，再以 `POSIX_SPAWN_SETPGROUP` 启动独立 CrashReportClientEditor／CrashReportClient；它不属于已有 UAT 进程组。该机制解释原组收尾覆盖不到助手，不解释助手内部忙循环或此前媒体／GATT异常。

选择沿用已有 `runCommand`，显式给 UE 命令声明实例级报告收尾范围。仅接受项目内唯一实例布局的 `CFFIXED_USER_HOME`，报告目录以该布局为根，固定 StageMasterPreview／UE5.8 命名；不把项目根、tmp根或全局 Library 作为自动清理根。不接受额外任意程序或任意命令白名单，不推断其他项目所有权。

用系统实际 PID／UID／启动时间／完整命令行及加载的主可执行文件交叉确认；仅对该命令开始后新增、范围准确、非交互报告助手发送 SIGTERM，立即前重新核对完整身份，有限等待并复查。没有报告助手正常返回；识别不完整、命令输出超限或助手仍存活必须明确留证失败，不使用强制广域 SIGKILL、不修改保护或无限重试。报告文件不移动／删除，已有原失败保持，终止上传助手不等于成功上传报告。

三个历史对象另作一次性维护，先保存准确进程、原项目日志绑定及报告目录元数据，逐个复核后仅终止这些 PID；全局旧路径不会进入生产自动范围。系统只读进程信息不对外展示无关命令行或读取无关用户数据。

其他选项：仅杀原组已被现场反证；按名字扫描杀全机有跨项目误杀风险；关闭报告／改全局 UE 配置损失诊断并扩大范围；引入通用进程管理平台不合首版增量。保留引擎成熟的报告生成机制，补工具有限所有权与真实失败收尾验收。

本项不能证明桌面所有崩溃类型／Shipping／实际GPU资格；主桌面 Renderer 另有生命周期，应独立核对后处理，不用本工具测试取代正式组合原生出口。

实际自审补充：SIGTERM后，助手可能在ps收集身份后、lsof读取映像前结束。393项初验留该失败，新增确定性单元先红后绿；仅新系统查询证实PID已不存在才视为结束，仍存活、身份更换或探测不明继续失败。系统查询上限2.5秒、整体检查期限5秒／4096行／16助手，超时留失败；不是硬实时或防恶意同秒PID复用的原子句柄保证。进程级双重身份检查加单写者／唯一实例限制适用于本地开发验证，不作为新的系统权限／安全平台。收尾中取消保持回执取消，失败／证据写入问题不能擦除原业务失败；原组已结束后不再对其旧组ID发信号。
