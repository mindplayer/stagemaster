# ADR-068：独立预演输出总控

状态：采纳；2026-10-01；EXEC-001；基线 `036c9c2`，当前会话评估。

参考 [grandMA3 Grand Masters](https://help.malighting.com/grandMA3/2.5/HTML/masters_grand.html) 和 [Titan Playback Controls](https://manual.avolites.com/docs/running-the-show/playback-controls/) 的亮度抑制、持续可见控制及零值提示机制。本项目先补单机预演总控；不把停止恢复默认值当熄灯，也不把软件预演称作物理急停。

核心 `stagemaster-playback::OutputMaster` 为纯 Rust 无时钟／I/O 值对象，百分比 0—100 与独立 blackout 锁存；熄灯不覆盖记忆百分比。缩放使用整数舍入，100% 逐值保持、0%／熄灯归零，只作用于编译标明的强度属性。优先数值 dimmer；没有 dimmer 且完整数值 RGB 时同时缩放 RGB，避免有调光通道的灯具被重复缩放。功能通道、水平／垂直、颜色轮、快门、控制与未知通道保持。未能判定强度的灯具数量必须反馈，不宣称全灯受控。

CompiledOutput 在编码前应用总控，同一有效属性用于槽位和灯具监看。Player 与原计划不变；音乐、效果相位、渐变和列表推进继续。旧 render 默认 100% 保持兼容，包格式／设备路径不变。静态三维编辑源只对 Light 的渲染强度应用相同系数；播放源已在输出编码层处理，不再次缩放。

桌面 Session 唯一持有总控，独立 output_request 快照／控制接口带专用 epoch 和递增 serial，旧工程请求、重复／乱序操作拒绝。新建／成功打开工程重置 100%／解除熄灯并更换 epoch；取消打开、编辑、撤销、保存、切页、载入不同节目不重置。它不进入工程 JSON、历史或包。错误草稿不拦截总控，按钮始终明确显示“预演”。

界面为常驻预演输出控制，百分比可拖动／键盘／精确输入，熄灯锁存及解除明确分开。连续输入采用至多一个请求和一个合并待办，旧快照不覆盖待发意图；错误保留实际回执状态且可重试。零值／熄灯有持续反馈，恢复百分比不擅自解除熄灯。无新增自动快捷键，避免输入剧本时误触。真实 DMX、安全联锁、多执行器混合、组总控／速率总控仍独立后续。
