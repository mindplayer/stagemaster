# PRODUCT-ADR-175：内部候选与告知材料的有限关联

状态：接受，2026-10-06，当前实施会话判断。接续 [DESKTOP-011](../tasks/DESKTOP-011-candidate-notice-handoff.md)；沿用已有内部组装、第三方告知和客户发行边界，不改变产品契约或安全资格。

## 决定

采用“不可变 .app 副本＋旁置材料＋私有核验清单”的内部审查交接目录。复用 Node 文件工具和已验证原来源／组装清单；按原字节复制，对照来源、材料、链接与执行位，签名仅只读检查。完整复制便于材料审查者核对实际文件，但明确不得从此副本自动启动，原本机绝对资格／内部身份不因复制获得可移动客户资格。

不把告知写进已有签名封套或重签原候选，不提前制作DMG／安装器；当前法律／完整链接清单、客户签名／权限／最低系统和UE资格条件未齐。仅保存外部引用不足以交接实际字节；旁置与副本关联能补这一缺口，但不等于最终告知已经包内嵌入或商业发行已批准。

清单 `stagemaster.internal-notice-handoff/1` 是工具私有结果：原来源提交／实例、优化及组装证据摘要、材料声明与原文摘要、逐文件字节／链接／模式、只读签名结果、完成或失败状态。固定未批准／非最终二进制清单／非客户资格，缺项不删；只写全新项目任务目录，输入变化／超限／外部目标／链接祖先拒绝，失败不登记完成。工程／播放格式、授权安装、激活、运行与输出语义不变，不进入产品加载器。

## 验证边界

可证明内部副本／材料字节关联与来源保护，不能证明法律充分性、所有内嵌组件／素材许可、客户安装／移动运行、完整渲染与硬件资格。所有旧失败和未完成出口保留。没有新增后台、播放器、时钟、代理、签名服务或未来占位能力。
