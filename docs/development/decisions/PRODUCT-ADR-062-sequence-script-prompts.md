# ADR-062：步骤剧本提示与运行快照

状态：接受，SEQUENCE-002 实施；2026-10-01，当前会话评估。

[grandMA3 的步骤备注](https://help.malighting.com/grandMA3/2.0/HTML/notes_cues.html)用于提示台上触发动作；[QLab 属性检查器](https://qlab.app/docs/v5/fundamentals/inspector/)将操作说明放在待执行位置。复用这些成熟机制，结合既有人工／自动等待；不复制命令语言或新建平行播放器。

工程步骤新增可选 `script`：`section`（幕／场，80 字符）、`trigger`（台词／动作提示，1024 字符）、`notes`（排练备注，4096 字符），均为纯文本；允许换行／制表，拒绝其他控制字符。字段全空时编辑器移除对象。含对象须声明 `lighting.sequence-script@1`；旧工程原样接受，旧读取器拒绝新能力以免丢失提示。每列表文本 UTF-8 合计最多 64 KiB，避免宿主监看复制无界增长；工程仍受既有容量限制。

独立 `updateStepScript` 命令负责写入／清空；旧 `updateStep` 不触碰提示。复制保留，删除清理无用声明；与基础编辑、排序可在同一原子批次及撤销节点完成。文本不会改变推进方式、时间或自动执行；幕场是步骤标签而非新增调度层，重排顺序仍显式。

Rust 工程层验证，视图返回可选对象；编译时把提示复制到 `CompiledStep` 的宿主元数据，执行台当前／下一步只能读取载入快照。修改后的提示不能冒充正在运行版本，仍需显式重新载入。纯 Player／DMX／设备包不携带文本，避免占用 ESP32 实时内存；输出应逐帧保持一致。

界面提供属性录入、列表提示、按幕场／台词／备注搜索、执行台完整当前与下一条提示；筛选和选择不执行。多行文字自动换行，长备注可展开，Enter 换行、Esc 取消，错误定位、撤销及保存共用既有事务。完整剧本文档导入、行锚点、跨媒体调度及幕场折叠后续，不能以标签宣称完成。

验收：旧格式兼容、能力缺失／超长／控制字符原子拒绝、复制／删除、编码重开、编译快照隔离、输出不变；中文多行输入、取消、错误焦点、搜索、执行人工等待、旧版提示、撤销及保存重开。
