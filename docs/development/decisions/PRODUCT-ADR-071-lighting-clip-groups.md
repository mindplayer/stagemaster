# ADR-071：独立灯光片段的原子成组操作

状态：采纳；2026-10-01；AUDIO-007；基线 `527919e`，当前会话评估。

沿用 ADR-067 参考的 Premiere 独立片段／普通移动与删除机制，以及现有卡点、步骤组接口。按时间顺序保持所选片段的相对起点、时长、场景引用和渐变；未选片段与节奏点完全保留，删除留下空隙。此处“组”为瞬时编辑选择，不新增持久组或隐式波纹。

`AudioEdit::EditLightingClips {ids, action}`：1–512 个唯一有效 ID；action 为 `move {destinationMs}`、`copy {destinationMs}` 或 `remove {}`。目标是最早片段的新起点，不依赖传入 ID 顺序。Rust 做 checked 时间运算、裁切时长与数量限制、半开区间碰撞检查；任何不满足即整组失败。move／remove 遇锁拒绝整组；copy 可读取锁定来源，核心分配新 UUID 并解锁。新结构严格拒绝未知字段。

命令复用工程事务／一次历史／恢复点，旧运行列表快照不变；音乐预演按新工程版本重新求值的现有规则不变。无持久格式、能力版本、执行时间或设备协议变更。移动仍以新起点重启片段效果；保留相位的裁切／分割继续独立规划。

界面使用固定右侧组属性，卡点批量与片段批量互斥。单对象草稿在进入或切换前收集；组目标输入仅是操作参数，Esc／取消恢复原起点，保存不隐式移动。错误保留选择、筛选、目标并聚焦目标输入；复制成功选择新片段，删除有含隐藏项数量的确认。复用已有受控复选框、范围选择与 DockPane，不引入通用时间线引擎。
