# PRODUCT-ADR-145：三维整组旋转与间距缩放

状态：accepted，2026-10-04，STAGE-006。当前会话评估实施，基线 `5dd48f8`。

## 依据与边界

接续 AUDIT-001 U08 与 ADR-094。参考 [UE Transforming Actors](https://dev.epicgames.com/documentation/en-us/unreal-engine/transforming-actors-in-unreal-engine) 的工具分离、世界轴、共同中心、实时反馈和精确输入；沿用当前共享选择与版本保护，不依赖编辑器专用 gizmo。比例作用于灯位间距，真实灯体尺寸不随之变化，避免把场地布置变成失真的光学模型。本增量提供绕世界竖轴旋转和三轴等比间距缩放；任意轴旋转、混合构件与框选仍在总目标中。

## 共享命令

新增 `StageEdit::TransformPlacements { fixtureIds, yawDegrees, spacingScale }`，选择 1–256 个唯一已布置灯具。中心为全部原始灯位世界坐标包围盒中点，顺序不改变中心；缩放后绕中心旋转。角度为十进制字符串，最多六位小数、−360～360；正比例 0.01～100。空间坐标仍限制 ±100000 米，结果六位小数。旋转同时累加安装 Z 角（世界 Rz 左乘既有 Rz Ry Rx），保留 X/Y；缩放只改位置，保留朝向、灯体尺寸、空间与挂接身份。中心、比例、安装角不属于灯具水平／垂直电机值。

Rust 从当前版本工程计算并原子校验所有成员，任意缺失／锁定／越界拒绝整组。等效零操作不产生历史，未变字段保留原始精度。既有挂接为关系而非刚性约束，变换不搬动支撑体，与已有平移相同。工程格式不变，保存的仍是正式灯位。

## 预演交互

交互版本升为 3，旧渲染器可观看但不能编辑。沿用 `generation/version/fixtureIds/requestId` 及原有 2.5 秒主机、3 秒渲染草稿期限。新 `transform` 提案只含角度／比例，不接受渲染器指定持久坐标或中心。拖动以开始时的位置和中心计算，不逐帧累计误差；选组、工程、版本、来源、连接或锁变化立即取消。Esc／失焦／拖出视窗恢复整组，松手只提交一次。旋转和间距工具显示实时值，并支持精确输入走同一提案通道。UE 仅显示临时变换；Rust 回执和工程同步决定最终状态。

## 验收

核心核对非对称组的共同中心、旋转方向／安装角、缩放与单灯行为、锁定／越界原子拒绝、最大组、零操作及保存往返；宿主核对单次历史、陈旧版本与非场地来源拒绝。UI 检验协议、选择／连接期限及精确输入；UE 自动化检验左右手坐标、手势数值、草稿还原。正式桌面使用独立工程副本验证平面到三维共享选择、实时操作、取消、锁组、撤销重做、保存重开。真实灯具和硬件不在此项范围。

实际结果见 STAGE-006：独立坐标、协议和原生闭环已通过。官方组件的窗口 resize 监听不足以覆盖停靠布局变化，增加独立容器尺寸观测并调用其公开坐标重配方法；有效尺寸变化取消旧手势，不重连流、不修改第三方库。原生此前偏移不能命中，修正后旋转／缩放和拖出取消通过。
