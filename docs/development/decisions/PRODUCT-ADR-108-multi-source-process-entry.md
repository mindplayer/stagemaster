现有受保护本机进程已具备凭据、操作会话、严格序号和可查询回执；多来源组已经接入同一个后台宿主。本项让同一应用服务按启动时固定的执行档位承载旧单节目或新来源组，不复制 HTTP 服务、会话注册表、命令工作器或调度循环。

新组模式启动时读取明确的有界来源清单，基于同一工程快照准备场景／列表／手动层。准备完成后不依赖源文件。服务器保存来源 ID 到私有 Key 及稳定步骤 ID 的映射；客户端不能构造核心 Key、租约或原始属性下标。来源清单属于本机准备输入，独立版本校验，不能经执行队列修改。组模式使用独立的 v2 协议与能力声明，旧 v1 单节目调用保持。

应用层复用类型化宿主，通过小型映射接口完成操作、状态和帧投影。原有会话与权限、回执窗口、连接／请求／工作预算保持。手动修改使用灯具 ID、属性名、归还／连续值／功能选择；复用已有灯具功能转换，整批校验后再进入后台。准备快照身份和启动身份必须可观察，换宿主的旧 URL、旧会话及不匹配模式操作拒绝。

实施审查补充：应用操作的原始 `Instant` 必须原样送入后台信封，不能先计算剩余 Duration、再在下一层重新开始相对期限。宿主接纳参数兼容既有 Duration，并通过显式 Deadline 类型支持同一进程的绝对 Instant，二者都受最多 5 秒的接纳预算限制；过期绝对期限立即拒绝，排队后仍检查原时刻。此为进程内公共调用扩展，不把单调时钟 Instant 放入网络格式。

验收包括真实独立执行进程与独立控制客户端：两个来源同时运行、仅停止目标来源、手动覆盖／归还、客户端被杀后同一组继续、明确接管与旧输入拒绝、重复回执不重放、非法来源／步骤／属性／功能／批量不部分应用，移除源工程及清单后运行和目录不受影响。保留全部原单节目入口与接入边界回归。当前仅软件输出，桌面迁移、物理端口、多时钟和商业保护不是本项完成声明。
