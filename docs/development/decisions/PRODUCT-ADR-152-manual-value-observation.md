# PRODUCT-ADR-152：手动设定值的权威观察

2026-10-04，接受；EXEC-008，基线 `f3bc19f`。

延续 ADR-151 参考的 grandMA3 编程器机制：持有属性、值和释放分别表达。本增量复用原 Session 稀疏贡献，显示电平前设定，不从 DMX 最终混合值反算编程器，不把界面上次输入当后台事实。

Session 提供手动来源值的只读借用。LiveBackend 按来源维护从该借用产生的不可变 Arc 切片；准备时建立，手动修改／释放后仅在内容变化时替换，非可写业务副本。最多 64 来源，每项最多 512 个 Option<u16>。观察和历史回执只克隆 Arc，tick、电平修改、重复读取不创建属性数组；有界内容分配仅发生在准备／手动内容改变。历史快照不随以后命令改变。原固定持有掩码保持。

共享宿主 Profile::State 由 Copy 放宽为 Clone，要求 clone 有界、无 I/O、无按属性数分配；现有设备状态保持 Copy，现场宿主使用固定数组和 Arc。这是软件宿主边界，不改变 MCU 状态机或作硬实时承诺。实际 State 尺寸、快照复用与旧回执不可变由测试保护。

本机协议 2 可选能力 manualValues 依赖 manualOwnership。手动来源新增 heldValues:u16[]，与既有 held 的目标顺序和长度严格一致；两者同一快照与映射生成，0 是实际持有，释放目标在两者中同时移除。此紧凑平行数组避免重复目标长字符串扩大响应；单来源增量上界约 3 KiB，原 8 MiB 响应限制保持。普通来源不携带。客户端严格检查能力、配对长度和功能通道量化／合法区间／固定槽代表值，失效状态不发布。旧后台没有该能力时显示数值不可用；旧客户端可忽略新增可选字段。

界面展示原始 u16 值对应的百分比或功能名称／区间位置，仅作观察格式化；保留原始值供精确核对。未持有不显示默认值或零，数值相等按原始值比较。多个值不任意挑首灯，定制轮盘使用各灯自己的定义。数据陈旧标明最后已知，当前草稿不被轮询覆盖。整层明细可搜索分页，所选属性单独汇总；无新增命令、时钟或工程持久字段。
