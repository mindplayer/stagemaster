# ADR-085：相对轴调整与等指向翻转

2026-10-02；接受；POSITION-002，基线 `ed844c6`。当前会话按用户新增的专业摇头灯要求直接实施。

## 参考与取舍

[Avolites 位置编辑](https://manual.avolites.com/docs/controlling-fixtures/changing-fixture-attributes/) 将双轴独立控制、精细操作和另一支架姿态翻转放在位置工作流；借鉴其保持已有灯间差异、只动需要的轴。复用 Rust 物理映射与两轴正逆计算，不在前端加第二套几何。

[MA 配灯](https://help2.malighting.com/grandMA3/2.4/HTML/patch_add_fixtures.html) 区分输出、预演与操作反向；[位置校准](https://help2.malighting.com/grandMA3/2.4/HTML/patch_position_fixtures.html) 用已知世界点及实测轴角求安装姿态。本项目当前 `zeroCorrection` 是物理模型零偏，**不是**控台最终输出偏移，也不是四点测量校准。现有档案反向描述物理角与通道映射，不应被当作操作方向偏好覆盖。

## 契约

- 增加编辑命令 `position.offsetAxes {sceneId,fixtureIds,panDegrees?,tiltDegrees?}`：十进制有符号增量，至少一轴非零。逐灯从本场景常值／预设／档案默认解码实际 8／16 位轴角，加增量，再由 Rust 编码。空或零增量的轴不写入，其他属性、预设资源、安装姿态和实例零偏不变。修改的预设引用成为当前场景常值，未修改轴引用保留。不是正在播放的瞬时帧或列表继承状态。
- 增加 `position.flip {sceneId,fixtureIds}`：由同一纯空间模型求当前射线的另一解分支，选择最短可达展开角。含实例零偏、机械范围；不依赖是否布置舞台。轴向奇点没有唯一支架解，明确拒绝；另一分支不可达也拒绝。最终射线精度受实际通道量化限制。**仅终点等指向，中途不保持光点，不承诺无碰撞或真实运动轨迹。**
- 两命令均复用 1–128 灯唯一集合、整批预检／单次历史与保存。任一灯失败不得部分写入；相对增量小到不能改变所选通道量化值时明确拒绝，不假装微调成功。被启用效果控制的请求轴拒绝并定位效果名，避免把静态底值调整误当瞬时效果编辑。
- 持久格式、能力声明、播放器、DMX 编码器、UE 协议不变；保存仍是既有轴属性常值。命令是新增严格枚举，未知调用拒绝。
- 桌面新增相对调整草稿、粗／细步进和独立轴输入；步进累计于草稿，应用才一次写入。翻转是明确两轴操作，经既有待保存草稿保护。移动安装灯位、记录默认位置、手工零偏和设备复位不得混用。

## 后续顺序与边界

1. 本任务：相对微调、逐轴保持、翻转、真实精度与失败定位；给后续参考点调焦提供可靠入口。
2. 校准工作流：先完成参考点采样、单灯身份／档案／安装修订、结果残差／留出点检查，再求安装姿态。手工模型校正与输出补偿单独建约，不把已有 `zeroCorrection` 悄悄换语义。
3. 专业运动：旋转轴操作偏好、扇形、定位预设、时间／速度／加速度／黑场移位、连续跟随与避障分别评估。当前没有实灯反馈，不伪装已到位；现场验证需在明确真实设备任务中完成。
