# PRODUCT-ADR-023：支撑体与灯具挂接

状态：accepted。日期：2026-09-27。任务：STAGE-001。基线：`9021f7c`。

用户希望一轮交付若干重要功能。当前会话评估后选择完整场地装配工作流：水平直桁架／灯杆、批量挂灯、关联移动／旋转、解除与删除保护、按支撑体选灯、平面测距。复用现有工程、原子历史与三维网格桥，不另建场地或播放内核。

参考 [Vectorworks 关联机制](https://app-help.vectorworks.net/2027/eng/VW2027_Guide/LightingDesign1/Concept_Attaching_loads_to_rigging_objects.htm?agt=index)及[挂载管理](https://app-help.vectorworks.net/2027/eng/VW2027_Guide/LightingDesign1/Managing_loads.htm?agt=index)：关联与位置分开；挂载保持或明确重排；支撑体变换带动灯具，解除保持世界位置。本次不做结构承载计算、吊机驱动、厂家桁架库或自动碰撞挂接。

## 数据与命令

- 新能力 `stage.rigging@1`，有 rig 构件或非空挂接数组必须声明；旧工程缺少数组按空处理，旧读取器应拒绝新能力，避免静默丢失关联。
- `StageConstruction.shape` 增加 `rig`：`rigKind` 为 `truss|pipe`、空间归属、中心世界坐标 `positionMeters`、水平角 `yawDegrees`、长度 `lengthMeters`、横截面宽高 `widthMeters/heightMeters`。当前只水平直支撑体；管材使用圆／椭圆截面，两种尺寸均明确可编辑。实体身份沿用构件 ID，不能用灯组代替物理关联。
- `stage.attachments` 是 `{fixtureId, constructionId}` 唯一关联表。一灯最多一个支撑体；必须有灯位，且灯位与支撑体空间归属相同。不保存第二份局部坐标；世界灯位是唯一位置源，Rust 根据前后支撑体变换同步灯位。
- `putConstruction` 更新 rig 时，Rust 绕旧中心做水平旋转再平移／升降，带动全部已挂灯位和底座 Z 角；空间归属同步。长度／截面变化不自动重排灯位；需显式重新均布。底座 X/Y 保持，Z 归一至 [-180,180)，不改变场景参数或摇头控制轴。
- `attachFixtures` 提交 1–256 个有序灯具 ID、支撑体 ID 和可选均布参数（首端余量、末端余量、下挂距离）。无均布参数时要求已有灯位并保持世界位置；带均布参数时按灯序创建／重排灯位，新灯位底座为零，已有底座保持。`constructionId:null` 解除，必须不携带均布参数。换挂属于明确指定新支撑体。
- `removeConstruction` 增加可选 `detachFixtures`，默认 false，仍有挂灯时拒绝；显式解除后删除只去掉关联，不删除灯具或灯位。`removePlacement` 同时解除对应挂接。单独将已挂灯位改到其他空间须先解除；删除空间的明确解除流程同时解绑空间归属，保留支撑体挂接及世界位置。复制支撑体只复制实体，不复制灯具／地址／挂接。
- 所有依赖更新属于一条 Rust 编辑事务；失败全回滚，撤销／重做恢复实体和关联。交互草稿、测距、选择与镜头不写工程；测距为 XY 平面距离，不能当三维净距。

## 模块与预算

独立 Rust `rigging` 模块维护关联、变换和校验；TS 独立支撑体字段／挂灯面板负责表单与命令。UE 只消费 Rust 生成的杆件网格与已求得灯位，协议不变。沿用最多 512 构件、1024 灯位，1024 条关联、一次挂接最多 256 台；长度 0.1–1000 米，截面 0.02–10 米，下挂 0–1000 米。渲染三角面总预算沿用 100000。

验收覆盖旧文件、坏引用／重复挂接／能力缺失、批次原子失败、旋转与高度／底座角、独立调灯再移动支撑体、解除／删除／空间删除、复制不复制配适、保存历史、网格预算和原生六项工作流。结构与载重验算不在此模型中，后续能力须有独立契约。
