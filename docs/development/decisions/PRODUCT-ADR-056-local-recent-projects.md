# PRODUCT-ADR-056：本机最近工程目录

2026-10-01；UX-024；当前会话审查接受。接续 AUDIT-001 U11，依赖既有 DiskFile 校验、保存冲突检查和未保存保护，不更改 Show 文档。

借鉴成熟编辑器最近文档入口与 Tauri 原生文件选择机制：记录只来自本机成功打开／保存的工程，最多 12 项；同路径去重并前移，显示工程名、路径、最后访问时间及文件可用性。记录不包含工程内容、音频、播放状态或云端身份，也不属于撤销历史。调试数据放项目 data，发布构建放应用本机数据目录。

桌面适配新增 `recent_request(list|forget)` 返回本机目录；工程命令新增 `openRecent {generation,id}`，只接受目录中的标识，由 Rust 解析路径并复用现有打开流程。前端不借此获得任意路径读取接口。文件在点击前后改变时仍由 DiskFile 完整验证；失效记录不会替换当前工程。移除最近记录只操作索引，绝不删除工程或媒体；重新打开文件即可再次加入。

目录采用版本化、有大小和条数上限的 JSON，串行锁、临时文件及原子替换；多实例更新先重新读取，避免覆盖其他实例新增项。目录损坏或不可写时明确报告，不静默清空损坏文件，不把已成功保存的工程误报为保存失败。索引可用不代表工程内容／媒体完整性已通过，资源健康继续由实际加载与工程检查负责。

界面在启动页提供最近工程，在已打开工程时提供按需目录入口；打开复用草稿应用、未保存确认、原子替换及工作区重置，取消保持原上下文。顶栏“安装”改为“下发节目”，设备底层安装状态名称保留真实含义。此增量不是云端工程分发，也不实现媒体健康聚合或跨机最近列表。
