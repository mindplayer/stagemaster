# PRODUCT-ADR-059：离散属性播放与包兼容

状态：接受，执行基础已实施。2026-10-01；FIXTURE-003A；基线 `1162f74`。为 AUDIT-001 F02 的功能区间建档提供执行基础，不代表完整灯库已完成。

## 依据与取舍

[GDTF Logical Channel／Channel Function](https://www.gdtf.eu/gdtf/file-spec/dmx-mode-collect/)将物理通道、逻辑属性、功能区间和命名档位分层；Snap 明确要求直接跳到新值。[MA 的 SnapPercent](https://help.malighting.com/grandMA2/en/help/key_keyword_snappercent.html)将色盘／图案盘等非渐变属性与渐变时间区分。2026-10-01 核对官方资料；采纳非连续属性独立的切换语义，暂不照搬控台命令行或增加未验证的任意切换百分比。

已有播放核心对所有属性统一渐变，这会在两个离散档位间经过其他功能；不能只加界面下拉框。核心先明确能力，随后建档／场景类型化功能值按独立增量接入。

## 决定

- Rust `Plan` 增加严格递增、不重复、在属性范围内的 `snap_attributes: Vec<u16>`。空列表等价旧计划；原 `new`／`with_effects` 保持行为，新增 `with_snap_attributes` 显式构造。列表一次分配，播放无逐帧分配。
- 步骤延时期间保持上一可见值；延时结束即直接采用离散目标。连续属性仍按原整数渐变。暂停、继续、跳转、人工推进、自动跨步、循环和停止共用此规则；停止恢复档案默认值，不统一归零。
- 此首版离散属性不能附加动态效果，防止效果曲线或跨步混合重新生成中间档位；输入计划和不分配扫描器均拒绝冲突。未来命名档位追逐须独立定义，不偷偷降为连续曲线。
- 内核仅处理已编译数值与属性索引，不认识厂商、功能名称、物理通道、UI 或硬件。功能选择及区间到数值的转换仍归工程／灯具编译模块。
- 播放包容器仍为 1；无离散属性的包保留执行语义 1／`stagemaster-lighting-1` 和旧字节布局。有离散属性时提升执行语义为 2／`stagemaster-lighting-2`；新解码器读两版，旧解码器在头部拒绝版本 2。不可用旧头携带新语义。
- 语义 2 的节目可用旧五字段块或新六字段块；六字段在末尾追加索引数组。全包扫描必须检查版本与块形态一致、索引顺序／范围、效果冲突与预算。单块解码按确切数组长度识别；未知形态拒绝。
- 按实际索引数量增加常驻／装载预算，空列表不增加堆分配。设备预算不提高，现有安装固件不自动升级；上层接入时必须向旧设备报告版本不支持。
