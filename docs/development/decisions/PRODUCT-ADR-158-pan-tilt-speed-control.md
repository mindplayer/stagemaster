# PRODUCT-ADR-158：两轴速度通道独立于位置与渐变

状态：接受，当前实施会话评估；FIXTURE-009，基线 main `ce0447d`。不改变既有时钟、输出权、工程结构或受限节目包版本。

## 问题与依据

FIXTURE-006 的用户资料确认 30W 11CH 的通道 9 是两轴速度，0–255，但方向／物理速度未提供；18CH 的通道 5 明确由快到慢。现有编辑器仅可建两轴位置，不能把速度当 `pan`、`tilt`、亮度或软件渐变时长。

[GDTF 1.2 属性表](https://gdtf-share.com/help/developers/gdtf_1_2/annex/index.html)区分 Pan／Tilt、PositionMSpeed、PositionEffect 和 FixtureGlobalReset。借鉴这种语义分离，复用本项目 FIXTURE-005 的全范围 normalized／LTP、粗细映射、预设与播放器，不引入 GDTF 导入器或另一个物理运动求值器。

## 本次选择与边界

- 新建档属性键 `pan-tilt-speed`，中文“两轴速度控制”；表示一组共同速度通道的原始控制位置，不表示真实速度百分比、度／秒或软件渐变时长。仅支持全范围线性 8／16 位映射，最多一组，须同时建两轴位置；不接受 functions 表或功能默认值。未知正反方向保留，不自动反转。分轴速度、含宏／保留段的混合速度通道另议。
- 复用既有 String attribute、normalized 值、LTP 混合和通用 DMX 编码，沿用 `lighting.basic`。当前格式／运行已支持完整映射的通用 normalized 属性，不新增字段、能力版本或执行版本。旧工程不变，旧读取器可执行该通用映射但旧建档编辑器可能明确拒绝编辑／导入；不声称旧编辑器支持新操作。
- 新通道默认值草稿留空，须按说明书／测量明确填写，不能默认声称零值最快、最慢或停机。移除两轴时一并移除依赖速度草稿，界面说明；取消恢复原定义。切换 RGB／调光基础组合、定义／取消几何保留速度映射。
- 场景精确输入、复制、稀疏预设、清除／释放、列表渐变及有界包执行沿用当前规则。两轴速度与软件渐变可同时存在但不相互代替；总亮度／熄灯不改变该控制值。动态效果白名单不扩展，真实机械运动延迟不由 UE 推断。
- 同属性换灯沿用准确属性集合、值类型、混合与轴模型比较。只证明控制值重新编码，不保证两台实灯真实速度等效。
- 不发布完整 11／18 通道模式，不把测试默认或色片标签写为实测；自动／声控、复位持时及多发光单元仍独立待办。不会用该属性承载复位或外部电机。

## 出口

领域／模式文件／工程往返、非零起址、8 位端点及任意粗细顺序、默认／场景／预设／释放／渐变／总控、整批替换与失败原子拒绝。真实组件验证添加／移除／必填精确值／取消及错误定位；正式桌面独立验收工程验证两灯编排、一次撤销重做、保存重开和文件复用。实灯、速度方向／物理范围与机械延迟仍未测量，软件通过不能关闭完整 H3。
