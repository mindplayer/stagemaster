# ADR-077：片段裁切与重新安排分开

状态：采纳；2026-10-01；AUDIO-013；基线 `af76c72`；当前会话独立评估。

参考 [OpenTimelineIO 时间范围](https://github.com/AcademySoftwareFoundation/OpenTimelineIO/blob/main/docs/tutorials/time-ranges.md) 的素材时间与轨道位置分离，沿用 ADR-073 的整数源时间偏移。灯光场景为可求值的循环源，不导入视频引擎；最多一小时的源范围仍遵循现有上限。

新增 `trimLightingClip {clip}`，与普通 `putLightingClip {clip}` 同样校验对象身份、锁、启停、元数据和原偏移；传入的 effectOffsetMs 必须等于工程旧值，调用方不能任意指定源时间。Rust 计算新偏移 = 旧偏移 + 新开始 - 旧开始，拒绝负源时间、溢出、重叠、渐变大于新长度及总源范围越界。范围和其他可编辑属性一起原子更新，一次历史。格式仍为现有 effectOffsetMs，并按现有能力声明，不新增持久字段／运行时钟／固件语义。

移动片段始终保留原偏移。时间线端点手势（含键盘）使用裁切命令，临时显示边界由 UI 约束但最终语义由 Rust 决定；左边缘不能越过源零点，右边缘不能超出一小时源范围。属性页显式选择“重新安排”或“裁切”，原普通精确编辑维持重新安排兼容语义；裁切时显示算得的待用效果起点，不伪装成已提交值。取消丢弃全部草稿，工程变化后重新从当前对象计算。

进入渐变独立属于片段边界：保留原渐变长度，从新的边界重新计算；前段是否紧邻仍按现有规则选择边界快照。因此本项保留动态效果进度，不承诺重新裁切后的进入渐变区或后继过渡输出逐点相同。需要完整保留历史渐变的“内部截取”必须另有持久来源与过渡进度契约，不能仅靠效果偏移冒充。

验证：Rust 对未渐变采样和渐变完成后采样逐点比较；反复裁切／向左恢复／移动／复制、前后边界、源零点／一小时、无修改／锁／重叠／非法直接偏移／保存重开；UI 输入错误定位、手势吸附与有界范围、取消、一次撤销／重做及音乐游标保持。
