# ADR-054：复用成熟波形组件

2026-09-29；AUDIO-002；基线 `dda2052`；当前 Astra 审查接受。

用户明确暂缓自动节拍，优先改进波形显示与编辑，要求复用成熟库。选用 WaveSurfer.js 7.12.12（BSD-3-Clause），锁定仍提供现有插件接口的 7.x；8.x 是另一主要版本，本增量不同时承担迁移。比较 [WaveSurfer](https://github.com/katspaugh/wavesurfer.js) 与 [BBC Peaks.js](https://github.com/bbc/peaks.js)：两者有波形／缩放／标记；前者可使用预计算峰值、无生产依赖且发行许可流程较简单，后者为 LGPL-3.0，当前无需再引入一套图形依赖。不是将音乐上传外部服务。

WaveSurfer 只渲染预计算数据，使用公开 setTime／zoom／scroll API 跟随 Rust 权威时间；不向它提供音频 URL，不调用其播放或解码。复用其 Timeline／Minimap 插件，编辑命令、历史及声音仍由既有模块拥有。卡点使用独立交互覆盖层，取消／拖动一次一事务及中文可访问名称由本项目负责。

原临时波形只有混合声道的 20 ms 绝对峰值，换绘图库不能还原已经丢失的细节。宿主临时接口改为 10 ms、逐声道的真实最小／最大包络，最多 2 声道／1 小时、1,440,000 个 f32（5,760,000 B 单份），不保留整段 PCM，不进入 JSON／撤销历史或 ESP32。旧工程格式保持不变。公开组件最大缩放与源包络精度匹配，不能声称是逐采样编辑器。

本轮验收包括真实音乐双声道、缩放／概览定位／播放头、标记拖动／取消／一次撤销、错误恢复、长音频及裁切边界、组件卸载释放资源。保留用户正在操作的窗口和未保存内容，不重载覆盖。
