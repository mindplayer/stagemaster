# PRODUCT-ADR-128：复用设备工作器的运行应用入口

状态：accepted，应用入口增量已实现并验证。2026-10-03；产品基线 `8d13434`，main；期间框架文档提交 `f22a611`，DEVICE-003 第二增量。

## 依据与取舍

当前可信 Session 已有独立操作范围，ManagedWorker 已持有唯一安装器和 Runtime。直接在无线任务中调用载入会把存储读取带进保活路径；直接照搬安装 Gateway 的 Open 又要求维护窗口。先实现存储／运行所属工作器的有界应用入口，再接线缆消息与就绪协商，比先冻结一套与工作队列不匹配的字节格式更能降低返工。

复用 [ADR-041](PRODUCT-ADR-041-maintained-install-worker.md) 的串行工作所有者、独立撤销检查和原 [Runtime 契约](../../module-api/device-runtime.md) 的控制租约／请求回执；连接分权沿 [ADR-127](PRODUCT-ADR-127-device-operation-permissions.md)。不创建第二个 Player、网络服务或调度器，不修改安装或工程字节。

## 决定

1. `install-worker::operations` 在 application 特性下提供 `Connection` 与类型化请求／回执，只借用原 ManagedWorker。创建连接只核对当前身份／启动上下文，不进入维护、载入或取得控制权。
2. 调用者是可信平台适配，提供新鲜单调时间和当前已认证 Grant 的查询闭包；每次处理前后及空闲轮询重检同一 session／上下文／权限修订／期限。闭包必须从现行 Session 或等效持续校验的撤销通道取得事实，不能返回长期缓存的 Grant。队列按会话归属路由，不接受对端提供授权闭包。未来跨核适配必须证明这个条件，不直接复制演示闭包。
3. 查看状态、分页目录／步骤要求 Observe；取得、续期、归还控制权与播放动作要求 Control。进入／取消／结束安装维护还需 Installation。不存在远程“已静默”命令，实际确认只留在输出宿主。
4. 连接拥有自己的 Runtime Lease，不能用网络传来的其他租约控制；主体与 Remote 来源从准入事实生成。输入租约不能长于剩余开发许可。接管须显式，请求携带期望业务修订。
5. 每个准入会话只建立一个 Connection，不得通过重建对象重置请求号。一次一个请求，连接内连续非零序号；只缓存最后完整请求／回执。同一请求重试返回历史结果，包含取得控制权、载入和结束维护；同号不同内容／跳号关闭输入连接。新连接不重放旧操作，先重新读取状态。业务失败也消费序号，重新意图用新序号。
6. 状态、目录、步骤用固定上限的值返回；每次一条目录／步骤，固定修订避免跨包拼接；不把所有灯具／步骤复制进回复，不新增无界队列。运行采样和物理发送不由这层伪报。
7. 断线、权限失效和旧请求撤销仅归还本连接的租约，保持 Runtime 自主执行；不能释放新控制者。慢载入在执行前获准后可能完成，后置检查失败只报告结果不可再交付，不声称回滚，也不自动重试。

## 增量出口

真实工程导出、原安装器／ManagedWorker、真实 Noise＋Session、独立推进的 Runtime 组合验证目录到执行／暂停／继续／下一步／停止、回执丢失、观察隔离、接管与旧断线、坏权限／过期、维护与失败后重试。此增量是实际应用调用边界，尚无正式线缆编解码、无线队列、桌面组件或物理输出；这些仍是 DEVICE-003 完整出口，不能用内部 API 代替网络验收。
