# PRODUCT-ADR-020：建模交互与预演剖视

2026-09-27，UX-013；当前 Astra 评估通过。基线 `8d49ada`。

## 问题与取舍

尺寸输入、对象组织与直接缩放是本轮可用性重点，仍以既有空间多边形和 Rust 工程命令为权威，不持久化一套 UI 尺寸模型。新建矩形／L 形转换为轮廓；尺寸编辑缩放现有多边形。草稿画布独立于已应用的正式三维投影。房间改变不暗中移动成员。

围护目前将地板、墙和顶合为一个显示网格，无法只隐藏遮挡视线的外壳。决定只调整可重建的预演投影：一个围护生成 `id:floor` 固体网格和 `id:shell` 外壳网格，分别添加 `viewRole: solid / enclosureShell`。舞台原 ID 保留，角色为 solid。工程 JSON、空间 ID、成员关系和输出语义不变。Rust 仍生成所有几何；UE 不推断墙体拓扑。

旧接收方忽略新增字段也能绘制拆分网格。新 UE 将缺省角色按 solid 处理，拒绝未知角色；网格接收上限由 512 提至 1024 以容纳拆分，总三角面预算仍为 100000。用户选择剖视后，外壳隐藏于主画面，同时开启 UE 的隐藏阴影，保留遮光；不可见外壳不拦截对象选择射线。剖视为 UE 视图状态，经 Pixel Streaming `cutaway` 动作切换，状态消息添加可选 boolean `cutaway`，旧消息默认为 false。该动作没有工程写入资格，不更改实际灯光。

不宣称物理级光学准确性；原先通用预演的光学限制仍然存在。实际渲染、隐藏阴影和切换恢复均须原生验收。
