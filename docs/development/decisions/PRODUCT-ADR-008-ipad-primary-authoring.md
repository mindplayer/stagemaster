# PRODUCT-ADR-008：iPad 作为主要编排终端

2026-09-23；基线 `4f3cc4b`／main，干净工作区。状态：产品方向采纳；型号、渲染后端与移动宿主尚待验证。

## 用户要求与范围

用户预计以后灯光编排的主力是 iPad。将 iPad 从轻量补充端提升为主要创作终端：在产品已经支持的能力范围内，能独立完成工程打开、选灯／编组、场景与效果编辑、时间安排、预览、保存和向独立播放盒交付。不把这理解为首版立即实现完整专业控台功能，也不把每个未来高级渲染特性列为 iPad 首版必需。

当前 Mac 仍是开发与既有验收入口；此决定调整设计基准和验证顺序，不自动改变首版交付操作系统承诺，不安装工具链、不签名发布或启动新端实现。

## 决定

1. **触控优先。** 先保证手指可完成主流程，再为 Apple Pencil、键盘、鼠标增加精细操作。Pencil 可选，悬停、压力、捏压等硬件特性不能成为基本编辑的前提。
2. **本地编排。** 本地工程、Rust 校验／编辑／编译和基本预览不依赖电脑或云端在线。手机／电脑中转及商业授权仍按既有 AUTH-001 规则，离线创作不等于修改设备播放授权。
3. **响应式工作区。** 先兼顾 11／13 英寸横屏的内容层级，再适配窗口缩小、竖屏和软键盘；这里的尺寸是设计假设，不是最低硬件规格。主场景、时间线与当前对象信息优先，资源和深入参数按需展开，不能把桌面四栏整体缩小。
4. **保留共享技术框架，尽早验证移动宿主。** 沿用 Rust＋TypeScript／React 和 Tauri 2；iPad 以可离线的安装型应用为优先验证路径。当前只有桌面宿主，不能把桌面构建成功或 Safari 打开页面当作 iPad 产品验收。薄原生桥接只进入平台适配层，不能复制业务核心。
5. **空间编辑与渲染质量分开。** iPad 必需的是可直接操作的空间视图与有用的本地灯光预览；专业画质按实测能力提供。轻量本地渲染仍是优先验证候选，UE 移动渲染可对比，桌面 UE 或串流作为增强；本轮不锁定具体三维库。
6. **独立硬件负责持续现场输出。** iPad 编辑／编译／传包／控制，ESP32／ARM 在节目安装并激活后自主运行。切换应用、锁屏、网络波动或渲染卡顿不得让硬件等待 UI 刷新。直接从 iPad 连续发送现场数据若后续需要，须单独限定前台运行与故障策略，不作为自主播放默认路径。

## iPad 输入与显示要求

| 区域 | 建议交互与约束 |
| --- | --- |
| 舞台选择 | 点按选灯；显式多选／框选工具；不依赖 Shift 或右键；被遮挡对象可从列表选取 |
| 舞台导航 | 在舞台空白处单指拖动旋转，双指拖动平移、捏合缩放；提供可见导航工具替代。选中物体本体不因导航直接移动，只有明确布置工具的把手发起变换 |
| 参数 | 常用触控命中目标约 44×44 逻辑点，数值可点开精确输入；混合值／未记录／不支持分别显示；软键盘不挡住目标字段 |
| 时间线 | 点按选片段，再拖动移动；选中后显示加大命中区的裁切把手。空白单指横向滚动、双指捏合缩放；播放头独立拖柄；临时关闭吸附有可见入口 |
| 曲线 | 点击选节点后放大命中区、显示数值；手指拖动有避免遮挡的反馈，Pencil 可更精细；不能只靠细小曲线或悬停浮层 |
| 手势仲裁 | 按下时确定手势归属和移动阈值；滑动列表不误拖资源；手势中途增加第二指时，安全取消未提交单指编辑再进入导航，不同时触发变换和镜头动作；实际规则经真机试用修正 |
| 通用操作 | 撤销／重做、取消、复制、删除有可见入口；键盘与 Pencil 的快捷动作是同一命令的补充 |

以上是待实测默认值，不是系统固有手势。主界面优先让舞台和时间线保持上下文，参数可收起或扩展；调曲线时保留必要的舞台反馈。左利手、误触、掌触、触控取消、多任务窗口与字体放大进入验收，不强迫所有用户购买特定 Pencil。

## UE 的移动边界

Epic 提供移动渲染路径，但图形特性不等同于桌面；当前官方说明 Lumen 不支持 iOS／tvOS／iPadOS。这不否定 UE 移动三维或定制光束的可行性，也不证明其性能和体积适合本产品。选择后端前应测帧时间、输入延迟、灯数、内存、安装包、发热和长时间降频，不能只看静态画面。

桌面方案中的“独立 UE 进程／窗口”不能直接照搬成 iPad 的本地旁路进程。iPad 若采用本地 UE，须验证同一安装包中的原生视图／输入与渲染集成；若采用 Pixel Streaming，需远端渲染主机和网络。主编辑界面与本地工程应继续可用，串流掉线只影响该预演来源。基本预览与专业预演使用同一中立场景和已求值属性，不复制节目语义。

## 下一阶段出口

先把现有设计改为 iPad 横屏主工作面；现有三张桌面候选继续作为区域层级参考，不当作已选定的 iPad 稿。实施前建立小范围移动验证工单，至少验证：

- Tauri iOS 宿主调用同一 Rust 工程模块；安装型应用离线启动，真实创建／保存／重开；文件导入导出与沙箱权限可用。
- 真机手指完成选灯、改参数、拖片段、改曲线、撤销；Pencil 与键鼠分别作为附加输入；前端模拟触屏不能替代真机验收。
- 窗口变化、软键盘、切后台／恢复和系统终止后工程恢复策略；未来持久草稿不得只在退出回调才保存，也不把当前正常退出保护称为崩溃恢复。
- 局域网权限、发现／重连和向盒子传包的可行性；Mac 上能访问 USB 串口不代表 iPad 有相同路径。
- 同一代表性灯具场景的本地三维编辑与预览预算；高画质增强断开后基本工作仍可继续。

这些是后续验收门槛，本轮只更新设计与执行顺序，未运行 iOS／UE 或真实设备测试。待用户提供 iPad 型号后调整性能档位；未确定型号不阻塞交互设计。
