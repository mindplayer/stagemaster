# ADR-025：摇头灯档案、静态对焦与预演

2026-09-28；接受。POSITION-001，基线 `0d2b47d`，干净 main。当前会话直接实施，延续 ADR-016 的两轴边界。

参考 MA3 [XYZ](https://help2.malighting.com/grandMA3/2.4/HTML/xyz.html)：空间直线路径与轴角渐变不同；参考 [GDTF 通道](https://www.gdtf.eu/gdtf/file-spec/dmx-mode-collect/)：逻辑功能、物理范围与粗细字节分开。复用现有 Rust 两轴求解器、glam、工程原子命令和 UE 只读桥，不新增 UI 求解引擎。

- Profile 可选 `positioning`，kind 固定 `intersectingOrthogonal`；pan/tilt 各保存 minDegrees/maxDegrees 十进制字符串和 reversed。仅相交正交两轴、轴心兼出光口，零角沿局部 -Z，pan 绕 +Z，tilt 绕随动 +X。每轴对应同名 normalized / LTP 通道。归一化值仍代表通道设定，物理映射只在 Rust 位置模块转换一次。
- 新能力 `lighting.positioning@1` 必须声明。旧工程不变；旧读者拒绝新能力。Fixture 可选 `zeroCorrection`（panDegrees/tiltDegrees），仅手工轴零偏，非自动校准或实灯反馈。安装位置与方向仍归 stage placement。模式交换保持运动模型完全一致，否则拒绝，避免换灯暗改已记录位置；更广泛物理值迁移另立接口。
- 工程 `op:position` 独立命令域：按角度记录一轴或双轴、按共同世界目标求解并记录双轴、记录档案默认位置、修改单灯零偏。每批最多 128 台；求解失败整批不改，明确灯名／原因。目标输入是本次静态对焦命令，最终只保存轴角对应的属性，不持久保存另一套抢占控制的目标。界面明确“对准并记录轴角”。移动灯位后不会自动追踪此前目标。
- 16 位按实际整数编码；8 位量化纳入预演和求解回读。不能声称量化后的射线精确过点；本轮验收检查误差与精度边界。已有场景预设、复制、列表跟踪及轴角渐变复用统一属性管线；暂不开放轴属性的循环效果或真实硬件输出。
- UI 灯库扩展可选两轴及独立物理范围／反向；编排提供中文位置面板，精确轴角、默认位置、共同世界目标和手工零偏。草稿、错误定位、取消、选择上下文、统一历史与保存纳入既有工作台事务。
- 预演桥协议从 1 升至 2，旧组件明确拒绝，避免静默忽略运动；帧新增可选姿态，Rust 输出底座、水平轴、灯头的世界基向量与出光方向；UE 仅坐标转换和渲染，不能自行 lookAt 重新求解。固定灯兼容原路径；摇头灯显示独立底座／支架／头部，播放帧改变灯头和光束，底座不随位置属性旋转。

审查结论：该增量不承诺空间目标轨迹、自动校准、非相交轴、多头、连续旋转、速度／加速度／避障、轮盘或实灯到位。关节字段和版本化能力显式扩展，不能仅在界面加两个百分比滑条当作完整摇头灯。
