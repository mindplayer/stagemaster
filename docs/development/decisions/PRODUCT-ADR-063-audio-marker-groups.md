# ADR-063：音频卡点成组整理

状态：接受，AUDIO-004 实施；2026-10-01。

依据 [QLab 检索与选中全部结果](https://qlab.app/docs/v5/tools/find/)的检索集合机制，以及已有音频时间线／事务。先实现可用的多卡点整理，复用现有场景引用和 Rust 最终校验，不将此声称为完整自由长度片段或多轨。

工程格式、播放语义不改。AudioEdit 增加 `editMarkers { ids, action }`；action 为 `move { destinationMs }`／`copy { destinationMs }`／`remove`。按真实时间排列选中项，destinationMs 是最早选中点的新时间，保留各自相对间隔、名称、场景引用与渐变；移动保持 UUID，复制由 Rust 生成新 UUID。数量 1–512，未知／重复 ID 拒绝；复制后仍不超过 512。

操作在一次 Document 事务上提交，最终时间重叠、越界或渐变冲突整体拒绝，无自动覆盖／裁短／移动未选卡点。删除同样可撤销。灯光持续区间仍由相邻绑定卡点决定，成组调整后重新求边界，效果在各自新卡点重新计时，未搬运连续波形片段或隐藏结束状态。

UI 独立批量整理面板，搜索、勾选、选中当前筛选结果、清空、已选／隐藏数量、原时间范围、精确目标时间与移动／复制／删除。搜索不清空已选，隐藏项计数明确；删除就地确认及取消。操作使用现有工程草稿收集／原子撤销，失败保留选择及输入，返回单点编辑恢复选择；切工程／音乐／范围清理过时批量上下文，不发播放命令。

验证：按选中时序而非传入顺序计算、移动身份／复制独立性、最终碰撞／范围／渐变／数量原子拒绝、删除及重开；原生筛选隐藏项、精确输入、失败取消、撤销重做、保存重开与播放位置保持。设备断开。
