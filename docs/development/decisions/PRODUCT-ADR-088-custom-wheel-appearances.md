# ADR-088：色盘实测建档与显式模式变体

2026-10-02，接受；基线 `ee709fb`；当前会话评估、实现和审查。

## 成熟机制与适用边界

用户实灯出现装反色盘、定制色片、同外壳不同批次。参考 [MA3 2.4 sMArt](https://help2.malighting.com/grandMA3/2.4/HTML/operate_smart.html) 的档位快捷选择、[Titan 19 自定义灯库](https://manual.avolites.com/docs/patching/fixture-personality-options/) 的用户版本及显式应用、[Titan 工程内灯库副本与换灯](https://manual.avolites.com/docs/patching/changing-the-patch/) 的工程隔离和功能映射、[GDTF Wheels](https://gdtf-share.com/help/users/gdtf_builder/wheels/index.html) 的轮盘／档位定义与批量创建。采用这些机制，复用本项目功能表、草稿、模式复制／导入导出、显式替换和原子历史；不复制大型控台层层嵌套的界面。

GDTF 的物理色度／滤片光谱不是屏幕色块；本增量不把屏幕选色标成光学标定，不宣称 GDTF 导入或真实光束色彩准确。原功能键表示稳定的控制档位身份，名称不是身份，也不能仅凭“红色”自动匹配不同灯具。

## 持久契约与实施决定

1. `FunctionDefinition` 可选 `appearance`：`{kind:"open"}` 表示已确认通光；`{kind:"color", colors:["#RRGGBB"]}` 表示单色外观，两个颜色表示半色外观。缺省表示未标记，不能默认白色。仅允许色盘固定档位，拒绝自动换色等连续区间和其他属性；图案图像以后独立扩展类型。颜色是显示近似值，不控制灯具的 RGB 通道。
2. 使用 `lighting.fixture-wheel-appearance@1` 能力声明，带外观的工程自动写入、读入严格要求；无外观的旧工程／模式文件不改。沿用独立模式文件 envelope v1，旧读取器按严格字段拒绝，不能静默丢颜色。
3. UI 记录名称、原始区间、代表值、通光／单色／半色；颜色文本可精确输入，未确认保持未标记。按起点／每档宽度／数量生成固定档位，预检范围、重叠、容量；中值为可编辑代表值，明确生成后仍需逐档核对，不推断颜色、盘片数量或自动区间。生成只在用户显式按钮后写入草稿。
4. 模式使用中不原地修改。复制形成独立身份，编辑后由既有“替换灯具模式”明确选择目标灯具；工程内旧模式和其他灯具不随之改变。仅名称／外观不同且功能键、控制方式、区间、代表值一致时允许保留编排替换。新比较器按功能键匹配，忽略顺序及显示元数据；沿用既有 8／16 位模式替换契约：区间采用原生数值，按目标粗细通道重新编码，不保证字节布局相同。改变区间或键仍拒绝，留待明确的语义映射增量。换成外观标记不同的模式只保留控制值，不保证原颜色；界面必须说明。
5. 多灯共同属性仍要求完整显示定义一致，避免不同定制色盘被同一颜色标签误导。场景入口显示已标记色块及固定档位快捷选择；范围功能保留独立调节。清除标记、取消和撤销均有明确路径。
6. 不执行全通道取反：色盘固定区间、半色区间、正反转／停止／速度区间可能混用。后续反序辅助只能在明确选定固定档位内调整映射，不能影响自动区间。

## 主动补齐顺序

- 本次 FIXTURE-007：上述建档、外观、批量生成、仅显示差异变体替换和编排入口，软件测试、原生历史／保存往返。
- 后续实际适配：多发光单元／主亮度依赖、白色等混色；频闪常开／关闭／速度方向；轴速度；内置程序控制权／模式依赖；复位持时及释放恢复。沿用 FIXTURE-006 资料缺口，不编造未知通道。
- 受控试灯：单灯选择、原始值步进和回读区分、功能区间提示、离开恢复、复位等动作隔离；接已有独立输出授权，不以编辑色块触发现场 DMX。
- 库更新／换灯：语义对应预检、未知／不等价项明确、预设引用保留、影响范围审阅；不承诺任意灯替换保持完全相同效果。
- 个人库／标准适配：版本与来源、工程锁定副本、导出分享；GDTF／OFL 经适配器接入，多轮盘／图案资源和真实光学参数另增，不绑定 UI。

## 验收与风险

测试严格外观数据／能力声明、离散编码不变、自动区间无损、导入导出、选定灯变体隔离、粗细精度替换仍按既有契约重新编码、撤销与持久化、多灯定义差异；生成 14×10 档不会越入 140–255 自动区间。500 行以上既有文件仅契约接线并记录，业务放独立模块。屏幕颜色不是实测光谱，不能自动推出最佳跨灯颜色或驱动 UE；不同物理色盘的最终颜色仍需实灯核对。
