# PRODUCT-ADR-156 后台执行的输出总控

日期：2026-10-04。状态：当前实施会话评估通过，EXEC-013 已实现并完成相关／组件／正式桌面验收；最终完整回归复现既有最近工程锁失败，由 PROJECT-003 接续，不宣称全量出口通过。基线 main `31e4b98`。

## 问题与参考

编辑预演的 OutputMaster 不能控制独立后台；把它接成全局界面变量会混淆输出权威，或在后台采样／UE 再乘一次。复用现有 Rust OutputMaster、工程强度识别与来源合成，不另造播放器、时钟、租约或推子队列。

参考 [grandMA3 2.5 总控](https://help.malighting.com/grandMA3/2.5/HTML/masters_grand.html) 的独立总亮度入口，以及 [Titan 19 播放控制](https://manual.avolites.com/docs/running-the-show/playback-controls/) 对总控／节目电平的区分；只采用共同机制，不前置其完整控制面。

## 决定与边界

1. 每个已准备来源组持有一个后台输出总控，初始 100%、非熄灯。Rust 在来源语义合成之后、DMX 编码之前，仅对工程已识别的连续强度属性应用一次；功能／控制通道、位置、色盘不缩放。有独立调光时不重复缩放 RGB；无调光且完整连续 RGB 时沿用既有 RGB 回退。无法识别的灯具数量明确显示，不能宣称全部熄灭或机械急停。
2. 复用 OutputMaster 的整数 0–100% 精度。百分比与熄灯为两种独立命令，修改一项不覆盖另一项的旧快照。熄灯保留总亮度目标；解除后按当前节目与手动贡献恢复，不恢复旧帧。
3. 命令属于组级输出控制，不伪造来源身份；经过同一认证、控制租约、版本、序号、截止时间和 applied 回执。0%、熄灯、归还控制权、客户端消失都不释放手动值、不停止节目或音乐。释放仍用既有属性释放／手动层停止；节目停止与熄灯分别表达。
4. 总控属于后台运行状态，不写工程持久化／撤销历史。断开、控制权到期、接管及编辑器退出不重置；明确关闭并重新准备才回默认值。核心合成诊断值与软件输出帧都是总控后的结果，来源持有值与赢家不受影响。
5. v2 可选能力 `outputMaster` 配合目录 `output.uncontrolledFixtures`、状态 `output.percent/blackout`；严格校验声明与状态一致。旧后台可以观察，但不出现可操作总控。源协议、工程格式及物理输出完成语义不变；v1 不接此命令。
6. 桌面复用现有单在途／最新目标调度器与实际回执校验，增加无来源的组级目标策略；冻结后台、布局、会话与能力。真实推子、轨道外结束、键盘、精确草稿、取消不回滚、失联／接管停止后续发送。编辑预演总控不联动，UE 只读后台最终帧，不二次应用。

## 验证与未含范围

核心覆盖来源合成／默认与 RGB／功能掩码、0 持有、黑场后当前进度、拒绝原子性；真实宿主验证租约／版本／重放／只读再连／帧一致。组件与正式桌面验证两真实节目＋手动层、连续／精确／熄灯／释放／退出重开。物理 DMX、实灯、机械安全与跨输出端口总控不由本增量冒充通过；后续 H4 才验收实际输出。

实际结果见 [EXEC-013 交付](../tasks/EXEC-013-background-output-master.md#实际验证)。原生 37%／熄灯在编辑器退出重开后保留，只读不抢权；预演熄灯与后台权威隔离，明确释放才归还手动贡献。工程字节不变，没有另建播放器、时钟或队列；未增加第三方依赖。现场物理和听音门槛保持未通过。
