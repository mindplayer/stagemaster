# PRODUCT-ADR-137：设备运行与输出静默协调

2026-10-03；接受；基线 `df435e7`，main，当前会话单写者。[OUTPUT-002](../tasks/OUTPUT-002-dmx-transmission.md) 接续 ADR-103／133／136。

现有正常运行固件始终持有 OutputDisabled，因此可直接确认维护静默。UART 接入后该前提不再成立：需要从原端口的真实 Quiet 回执取得当前维护窗口，不能沿用直接确认，也不能因蓝牙断开停止自主节目。沿用原 Runtime 控制权／实例、原 Port 输出权与原有界发送任务；不新增播放器或改设备包和运行协议。

## 决定

- 在原 install-worker 提供可选本地输出协调器，持有一个 Port，绑定同一启动身份；不暴露可跳过门禁的可变端口。运行维护请求先关闭端口并等真实 Quiet，再在原 with_quiescent 内确认原 ManagedWorker 当前请求。出错不授予维护许可。
- 本地播放器组装中，首次观察到新的已授权节目实例才请求本地来源；只载入节目、只连接／读取状态不激活输出。开始后暂停、保持和控制端断连不撤回自主输出；停止节目仍按原 Runtime 生成档案默认值。停止发送与灯具熄灭不是同一操作，不追加原始全零帧。
- 维护、显式输出关闭、来源超时会撤回输出；取消维护或重连不会凭旧实例自动恢复。新的已授权开始可在正常端口恢复后请求输出，端口／协调故障不能自动清除。新实例尚在等待输出权时若节目已停止，则取消这次请求。
- 帧必须来自当前运行器的启动、修订、已载入节目、实例和采样时间；只提交 render(Some) 的完整快照，None 不复用旧缓冲。原 Port 继续执行线路、新鲜度、最新帧和完成回执规则。
- 正常运行固件的逻辑侧验证组装复用原认证 GATT、存储与第二核运行器，第一核独立发送任务拥有 UART。GPIO17 归 UART 时不再承担连接绿灯控制；GPIO21 在实验 Line 中始终关闭，保留当前实板固件，不新增虚假 RS485 能力／界面状态。

此轮先验证实际运行组装、启动／维护／取消／断连／过期／故障与完整帧；独立硬件看门狗和实际 RS485 开启仍是下一出口，实验镜像不能直接当物理交付。新增正式输出状态／控制入口若需要公开协议变化，另记契约，不挪用逻辑播放回执冒称物理完成。
