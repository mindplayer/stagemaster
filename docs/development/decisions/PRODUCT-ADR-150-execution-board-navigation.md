# PRODUCT-ADR-150：后台执行台浏览边界

2026-10-04，接受；EXEC-006，基线 `9f87591`。

依据 AUDIT-001 U05 与实际组件：按搜索过滤后再创建卡片会丢掉卡片输入；单纯堆叠 64 个节目也难以现场定位。参考 [Titan Playback Groups 的显示模式](https://manual.avolites.com/docs/running-the-show/playback-controls/#playback-group-workspace-display-options)，采用类型／运行状态／常用的就地浏览，持续保留明确的运行概览。本增量不引入互斥播放组或隐式释放行为。

节目浏览组件只从原目录和观察快照派生视图；过滤、固定、排序不向执行宿主发修改命令，不改变来源优先级。对最多 64 项的既有目录保留已创建组件身份，通过 hidden 移出展示与可访问树，并禁用操作；隐藏时取消重新执行确认，输入和选择保留。切换执行目标时后台组件仍保留，停止轮询并禁用输入；重新显示读取真实状态。新 hostId／layout 销毁旧草稿，当前编辑工程改变不把旧后台伪装成新工程。

运行概览基于权威来源状态；音频使用原音源状态，手动层无伪造运行状态。读取失败标明最后已知状态，不能把未知当全部已停。结束与停止分别显示，结束可能保持末值。筛选外节目不会停止，未应用输入有显式定位／逐项取消，不批量暗中提交。

常用顺序属于本机界面偏好，键为 `stagemaster.executionPins.v1`，版本 1，最多 20 个工程、每工程 16 个语义来源键；场景／列表使用 kind＋原对象 ID，音乐／手动使用角色键。目录中未准备的固定项仍保留，重新载入可恢复；显式清理不可用固定项释放容量。存储拒绝或配额失败不阻止执行，仅提示本次保留。偏好无控制租约、权限、运行值、自动播放或媒体路径，不进入工程或设备包。

实现后以纯数据预算测试、实际 React 交互和正式桌面验收覆盖；不通过增加平行播放器或轮询命令维持界面。
