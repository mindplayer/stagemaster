# PRODUCT-ADR-098：独立执行宿主与有界客户端入口

状态：accepted，2026-10-02；关联 [HOST-001](../tasks/HOST-001-independent-runtime-host.md)；基线 `4a3f7c1`。依 ADR-097 先验证执行生命周期，不改工程／包格式或设备固件。

## 决定与范围

新增可复用的标准系统宿主 `stagemaster-runtime-host`，组合现有 `stagemaster-runtime`；只依赖运行／包核心和标准库，不依赖 Tauri、UI、文件驱动、蓝牙、云端或 UE。首个档位承接已准备的单节目，仍使用原有控制租约、幂等回执、播放器和逻辑帧，不复制一套执行语义。此档位用于证明部署边界，不是专业多执行器能力上限。

选择独立线程的可嵌入宿主库，而非立刻公开网络端口：先验证唯一状态所有者与有界入口，再由独立执行进程组合该库和经过认证的 IPC／网络适配。线程隔离只能抵御客户端句柄消失和慢调用，不能证明同进程崩溃隔离。桌面替换、独立进程、跨设备鉴权、多执行器和音视频协调必须后续验收，不将库测试当产品端到端完成。

## 所有权、时钟和入口

- 可信组装方在工作线程外完成工程编译、包验证、节目载入与许可策略配置。启动只接纳 Operation、已载入且选中一致、Idle、无实例／无控制者的 Runtime；准备失败不得启动线程。不向普通客户端暴露装载、维护、直接 tick 或 render。
- 宿主线程唯一拥有 Runtime，使用自身 Instant 映射到准备时的单调毫秒基点；客户端不能提供运行时间。迟醒只求值当前位置，不突发补发历史帧。刷新周期是软件目标，不保证普通操作系统硬实时。
- 宿主拥有创建控制连接的可信入口，Grant 必须来自上层已认证会话。客户端只持自己的私有租约，通过受限动作枚举提交开始／暂停／恢复／下一步／停止；不能读快照后冒用他人租约。身份认证仍由后续外部适配承担。
- Acquire／Renew／Release／Submit 走固定容量队列，每轮限制处理数量。每个入队操作有本机截止时间，过期尚未执行的操作拒绝，不消耗运行核心命令序号。队列满明确返回未接纳；不静默丢弃已接纳的离散动作。
- 回执通道容量为一，工作线程不等待消费者。等待超时不取消操作，原 Ticket 可继续查询；丢弃 Ticket 不撤销已接纳动作，重复业务请求必须复用原序号／修订／内容。未知结果不能当未执行。
- 连接回执携带取得控制权那一刻的权威状态，客户端可直接使用其修订发首条命令；它是历史回执而非实时状态。不能依靠可能延迟／跳过的观察快照推断新连接已接管。
- Client 丢弃不自动停止节目，也不伪造已释放控制权；显式 Release 或原租约到期释放输入权，重连先取得新授权。旧连接操作由内核拒绝，不能撤销新连接。

## 观察与退出

状态与单路逻辑帧发布为固定大小的最新快照，不积累消费者队列，不包含硬件“已发送”承诺。观察者只获得复制值，无权持有运行对象或向其加锁；发布尝试繁忙时跳过并累计计数，播放继续。快照带采样时间和序号，不能当实时实物反馈。

Host 所有者与 Client 生命周期分开。只有可信 Host 请求关闭执行线程；停止请求不占普通命令队列，可唤醒休眠线程。关闭／故障立即撤销观察侧有效帧；关闭等待超时保留可再次等待的宿主，不声称线程已退出。意外 panic 显式变成 Faulted，不保留可误用的有效帧。宿主 Drop 请求结束并释放句柄，不能据此声称同步退出完成。

已载入的计划在运行中不访问包存储，客户端不能让该线程加载文件或进入维护；换节目／运行计划替换将单独定义。许可策略由可信宿主注入，必须有界、无 I/O；本轮不新增生产许可实现。实际物理输出仍由未来端口所有者接入，当前库只产生可核对逻辑帧。

## 必须通过的证据

1. 真实线程持续运行，所有控制客户端丢弃后位置继续推进，租约到期后新客户端能够接管，运行实例保持。
2. 快照只读／拥塞、无人读取回执、队列满和过期请求不改变既定播放含义；旧控制者不能停止或释放新控制者。
3. 同一个开始请求重试返回历史回执，不创建第二个实例；已过期的未执行请求仍可用同序号重新提交。
4. 包存储在准备后变为不可访问／慢状态，运行和控制不再读取；逻辑帧按采样时间与独立 Player 参考一致。
5. 错误准备状态拒绝、关闭超时／再等待、正常关闭及许可策略异常后观测失效，线程不泄漏。

这些证据证明本宿主边界；不证明生产网络、专业后台进程、真实 DMX 时序或跨设备声光同步。
