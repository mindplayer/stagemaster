# PRODUCT-ADR-061：音乐灯光段落的确定性进入渐变

状态：接受，AUDIO-003 已实现所述子集；2026-10-01；AUDIO-003，基线 `28657cc`。

依据 [QLab Light Cues](https://qlab.app/docs/v5/lighting/light-cues/) 的独立场景内容、持续时间与渐变机制，以及既有剪映式段落／属性布局。复用本项目 Rust Player 的单场景渐变和离散属性规则；不采用浏览器插值，不为此引入另一个播放器或音乐解码器。

## 可用子集

音乐卡点新增可选 `fadeMs`，省略／0 完全保持旧硬切。非零须绑定场景，渐变从该卡点开始，不能超过下一个绑定卡点或音乐末尾；纯节奏标记不截断渐变。新增能力 `media.audio-transitions@1`，含非零渐变必须声明；旧读取器拒绝，老文件保持原样。清除音乐同步移除两项音频能力。修改卡点／裁切不得悄悄缩短邻段渐变，冲突给出段落名称及可用范围，原子拒绝。

灯光场景继续隔离求值：未记录属性回灯具默认值。进入渐变以**前一场景在本卡点边界时刻的输出快照**为起点，新场景效果从本卡点计时；复用 Player 的线性连续属性混合与功能属性直接切换。前一效果在过渡中不继续运行，未来双场景持续交叉混合须另立模式，不更改此次语义。位置轴沿角度编码渐变，不冒充世界坐标轨迹。

任意定位与连续播放结果必须相同。由于禁止相邻渐变重叠，前一场景在新边界一定已完成进入渐变，因此只需独立求值前一场景在边界的效果，不用回放全曲或保存任意多历史快照。每次重建最多编译两个单场景计划，完成前一快照后释放其播放器；仅缓存当前一个播放器。沿用每个场景既有容量约束，不把 512 卡点拼成新的超大计划导致旧工程退化。

新增 `Document::compile_audio_marker(marker_id)` 返回当前单段编译结果；从文档自己已验证的音乐信息找相邻边界，不能由 UI 传入初值。无活动卡点返回灯具默认状态。桌面用原生音频游标与工程版本定位／重建，未变版本和卡点时仍只 advance；后退重建。编排、时间线和三维共享唯一声音与灯光会话。

## 界面与输出边界

卡点右侧选择“直接切换／渐变进入”并精确输入秒数，显示允许最大时长；时间线上显示实际渐变范围，选段落不播放，拖动边界仍一次事务、Esc 取消。拖动约束同时尊重前一渐变结束／本段渐变长度；精确输入仍由 Rust 最终校验，错误草稿定位，不自动改变其他卡点。

此能力属于宿主音乐编排。当前播放包仍导出场景／列表，不会自动带入音乐卡点渐变或音频；设备播放协议和固件不改变。界面须将此边界说清楚。本任务不包含自动拍点、多轨、自由片段平移、离散档位追逐、双场景效果持续交叉混合或音箱延迟校准。

## 验收

旧文件和零渐变等价；默认到第一段／静态跨段／前一动态边界快照／新动态相位／离散通道直接切换；0、边界、中点、结束、前后跳转、暂停位置一致；纯标记穿过、裁切／重排冲突、原子失败、能力声明及未知字段拒绝。原生输入、错误取消、一次撤销重做、保存重开、实际音乐和内嵌 UE 对照；设备断开，原工程不改。
