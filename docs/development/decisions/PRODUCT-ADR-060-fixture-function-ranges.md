# PRODUCT-ADR-060：灯具功能区间与类型化选择

状态：接受，FIXTURE-003B 已实现并验收所述子集。2026-10-01；FIXTURE-003B；基线 `abc5f7a`。

## 依据和边界

沿用 [GDTF 的逻辑通道／功能／档位分层](https://www.gdtf.eu/gdtf/file-spec/dmx-mode-collect/)与本项目[灯具建档设计](../../ui-design/fixture-definition-design.md)。同一个物理通道的不同区间可能有完全不同的行为，不能把原始 DMX 值作为跨灯型通用功能身份，也不能在区间之间直接渐变。执行基础已经由 [ADR-059](PRODUCT-ADR-059-discrete-playback-attributes.md)实现。

首个可用子集为单单元灯具的一个色盘、一个图案盘、快门／频闪和棱镜通道；原有亮度／RGB／双轴保持。一个功能通道含有不重叠的命名区间；可选离散档位或区间内数值。多轮盘／多单元、关联通道、复位／灯泡控制、完整 GDTF 导入仍独立扩展，不把一次性命令作为普通场景状态。

## 数据与接口

- `lighting.fixture-functions@1` 声明新能力，旧客户端严格拒绝，旧工程不用增加声明。
- 档案属性 `valueType.kind = function`；默认值及场景／预设值采用 `{kind: function, functionKey, position}`，position 为 0–65535 的区间内比例。功能键独立于中文名称、DMX 地址和档案修订。归一化连续值与功能值互不替代。
- 对应 channel 保留既有 attribute／encoding／offsets，增加 `functions`。每个区间含 key、name、mode（slot／range）、dmxFrom、dmxTo、dmxDefault；DMX 数值按本通道真实 8／16 位填写，不要求粗细相邻。每通道最多 64 区间。
- `slot` 保存 position=0，输出代表值 dmxDefault；禁止以非零位置绕过离散语义。`range` 用整数四舍五入映射到闭区间，编码结果不会落入其他功能；选择功能时 UI 由 dmxDefault 求相应初值。区间可留空隙，空隙不能成为合法场景值；默认必须指向已定义功能。
- 公共建档 DTO 的 `defaultValue` 允许原有 u16 或类型化功能选择；`functions` 可选。由 Rust 生成持久结构，不能从 UI 传任意原始通道写入。新增场景功能编辑命令复用原子批次／历史；既有释放／清除仍作用于属性。
- UI 数据投影同时提供语义选择和已解析数值；编译仍以 Rust 为唯一转换来源。预设引用／解除／复制必须保留完整类型值，不能用界面显示的原始输出替换。
- 按 ADR-059 编译功能属性为直接切换索引；区间内数值本增量同样直接切换，不假装已支持区间内渐变或命名档位追逐。播放包语义提升至 2，发布入口核对目标版本；现有实板不自动升级。

## 交互与兼容

工程灯库分开模式信息、线性通道、功能通道及区间编辑；搜索、复制、精确输入、错误定位、取消／撤销、保存重开沿用统一事务。场景属性显示功能名称及必要的区间参数；多灯只编辑真正共有且含义兼容的功能，不悄悄跳过不支持的灯。

使用中模式仍先复制再显式替换。首版安全换灯要求功能定义完全一致（地址／粗细映射可变），不按名称猜测两种灯型等价；跨定义功能映射另做差异确认。三维适配只模拟自己理解的功能，未模拟的图案／棱镜等须明确呈现支持边界，不能把原 RGB 预演当完整光学效果。

## 验收

8／16 位区间端点／代表值／保留空隙、重叠／重复／默认错误、类型错配、原子批量失败、引用更新／解除、编译直接切换与打断、包版本／目标拒绝、旧工程重开。真实界面完成建档→配适→选择功能→预设／复制→撤销→保存重开及数值预演。未接实灯前不宣称真实通道表正确或物理效果通过。


目标兼容具体承接：96 字节设备描述保持版本 1，使用既有可扩展能力位的 `PACKAGE_SEMANTICS_2`（bit 5）声明可读取新执行语义，必须伴随节目目录能力；不代表已具备播放／物理输出。旧描述无该位按语义 1，未知位保留的旧解析行为不变。原生主机从声明投影 `executionSemantics`，上传准备从已完整校验包读取要求；开始和恢复均在发送前比对。新固件源码声明此位，但本增量不刷入现有设备。

三维的具体承接：本子集尚未存颜色、图案纹理、棱镜光路或快门开闭／频率的可解释物理语义，不按功能名字猜测光学效果。含这些功能的已布置灯具保留灯体／灯位／双轴姿态，Rust 投影新增 `lightSimulation=unmodeled-functions`（保留原 `optics=generic-illustrative` 几何字段供已部署 UE 兼容读取） 并隐藏光束，界面列出受影响灯具；不阻断其他灯具与场地的预演。数值监看和包输出仍完整，不把隐藏光束解释成实际灭灯。可解释光学元数据与渲染适配另行实施。
