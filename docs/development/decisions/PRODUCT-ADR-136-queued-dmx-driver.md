# PRODUCT-ADR-136：有界 DMX 驱动交接

2026-10-03；接受；基线 `08b550f`，main，当前会话单写者。接续 [OUTPUT-002](../tasks/OUTPUT-002-dmx-transmission.md) 与 [ADR-135](PRODUCT-ADR-135-dmx-transmission.md)。不改变工程、设备包、运行协议或原 Port 的控制权。

同步 Driver 不能等待整帧 UART；当前单帧事务也不能自行成为另一套播放器。本增量在原 dmx 下提供可选队列适配，Driver 只复制完整帧／发布停止和取回回执，独立接收任务持有原 Transmitter。继续复用 [Embassy 短时互斥](https://docs.embassy.dev/embassy-sync/0.8.0/default/blocking_mutex/index.html)和 WakerRegistration；核对本地锁定 0.8.0 源码。跨核选 CriticalSectionRawMutex，单执行器测试可选 NoopRawMutex，不手写原子队列或 unsafe。

## 决定

- 固定一帧请求、一个完成槽、一个停止请求；在途帧或未消费回执存在时不接第二帧。原 Port 继续合并最新待发快照。停止独立于帧槽，丢弃待发帧和旧回执，在每次轮询时优先于线路 Future；取消后仍用原 quiesce 排空，才发布当前停止票据的 Quiet。
- 两端各有唯一所有者，队列只绑定一次。发送任务被取消／销毁会关闭线路并向 Driver 报告关闭；控制端销毁唤醒发送任务清理。销毁不伪造 Quiet，整核停顿仍须独立硬件看门狗。
- 错误锁存，先向原 Port 报告故障，再允许观察后续真实 Quiet；错误后不接新帧，停止仍可尝试。旧完成与新停止竞态时不覆盖新请求、不恢复来源，不无限重试失败的排空。
- 成功发送后的空闲等待独立监控最后一帧的新鲜度期限；没有新工作时到期关闭方向脚，不重复发帧、不伪造停止回执。实际发送超时仍由原单帧事务处理。定时器和 UART 必须合作让出执行，硬件看门狗不能以这些软件期限替代。
- 队列锁内只做固定大小复制和状态／唤醒，不执行 UART、文件解析或 await。生产数据无堆，所有请求和回执都有固定上限；真实 RAM／栈峰值继续由板卡验收确认。

验收覆盖满槽背压、真实唤醒、停止打断各发送阶段、完成竞态、取消、故障后静默、无上层轮询时过期关闭，以及真实工程／Runtime／Port／队列／事务的完整帧。S3 交叉构建覆盖实际同步组件和 UART 类型；本轮不刷机、不启用 RS485 或改用户窗口。随后将该驱动与固件 Runtime 快照、显式输出激活、维护门及看门狗接线，再做物理时序验收。
