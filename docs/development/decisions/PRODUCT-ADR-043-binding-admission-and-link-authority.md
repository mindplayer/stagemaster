# PRODUCT-ADR-043：绑定准入与连接权限

日期：2026-09-29；DEVICE-002B，基线 `0a713dd`；当前主工作区／当前会话实施。状态：接受核心实现，真实协议栈与桌面接入另验收。

## 依据与边界

沿用 [ADR-036](PRODUCT-ADR-036-authenticated-device-session.md) 已实测的 LE Secure Connections 和 [ADR-042](PRODUCT-ADR-042-device-binding-vault.md) 的持久档案，密码协议、地址解析和密钥持有证明继续交给 trouble-host。核对锁定 0.8.0 源码的 ConnectionEvent、security_level、BondInformation 与 set_bondable：绑定标志只决定是否保存密钥，不能阻止未经准入的配对。因此产品必须另管理有限准入、失败、实时权限及断开，不把已连接或栈 RAM 绑定当成安装许可。

在 `stagemaster-device-auth` 增加无堆、单一所有者的 Authority。可信适配层输入当前连接的认证等级／绑定密钥证据；这些类型不提供无线解码。主体只能从已核验档案查得，不能由远端提交。核心输出带连接代次的短生命周期 Grant，硬件适配再转为现有 AuthorizedLink／工作队列代次，不使认证模块依赖安装、UI 或硬件库。

## 生命周期决定

- 默认关闭新增绑定；本地物理操作显式打开 90 秒窗口，每个窗口最多三次尝试。连接重试、失败报文、再次打开同一窗口都不延长期限或重置额度。产品物理按键／USB 调试入口由板级适配落实，当前核心调用不冒充已接物理入口。
- 每条连接有内部分配、启动内严格递增且不回绕的代次，以及由设备可信 RNG 提供的非零 128 位业务随机数。拒绝紧邻重复随机数；更早重复须依赖 RNG 质量，不能宣称保存无限历史。新连接默认无权，旧连接的晚到事件不修改当前连接。
- 仅栈确认“由持久绑定密钥恢复的已认证加密”且密钥／身份与当前档案一致，才建立安装主体。普通加密、缺少绑定、未知密钥或新配对事件不能走恢复入口。恢复后的业务保活为 6 秒，只能由适配层在已有诊断协议校验成功后续约；普通请求和查询不续期。
- 首次配对必须属于当前准入尝试，认证成功后仅生成持久化提案。立即关闭准入和当前权限，写入／回读成功后重新连接并证明新绑定密钥，才开放安装。这样提交完成晚于取消或断开时也不会向旧连接补授权限；不额外自研一次密码挑战。
- 撤销或任何凭据变更先撤销连接和档案可用性，再进入存储任务。恢复只接受相同本机身份、至少为最后已确认修订的核验结果；恢复不会自动复活旧连接。提交不确定时允许显式读回完整旧／新档案，但 UI 不能报告撤销成功。
- 每次取权限和续约都重新核对当前认证等级及绝对期限；超时、降级、时钟倒退、断开或取消均不可复活。适配层必须同步撤回现有工作器 LIVE_EPOCH、清空半包／通知并断开实体连接；Grant 是瞬时事实，不能作为永久缓存。

公开设备描述与诊断仍可用于发现和排错；首版开发配对不产生播放权限、商业授权或物理输出。现有工程格式、节目包格式和诊断线协议不变。本轮不凭规划更新固件能力声明。

## 验证与出口

覆盖新旧连接交错、弱认证、错密钥、准入截止／额度／取消、提交后重新证明、撤销与旧档案、保活截止／无效请求不续期、时钟倒退和秘密脱敏。补持久存储与连接核心的组合试验，验证真实存储结果决定后续权限。随后把同一机制接到板端单一 Flash 所有者和栈事件，实测重启／取消／撤销，再接桌面和 GATT 安装；核心测试不代替这些实际验收。
