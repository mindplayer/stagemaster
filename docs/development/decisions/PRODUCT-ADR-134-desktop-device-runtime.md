# PRODUCT-ADR-134：桌面设备运行入口

状态：accepted，软件实现与验收完成。2026-10-03；DEVICE-003 第八增量，基线 `c0fc927`，main，当前会话单写者。上一目标回合仅核对进度，分类 no progress；本回合核对工作区与存活的界面验收服务后接续实现、验证和集成。

## 决定

复用现有 device-host Service／运行客户端和设备 Runtime，桌面通过 ApplicationHost 接入，不创建播放器或蓝牙所有者。沿用现有设备面板与成熟控台的“目录、载入、执行和明确控制权”区分，观察连接不启动节目；功能区组件独立，原生投影／状态协调／视图分文件。

1. device-host 增加 JSON 应用适配，严格解析操作，稳定身份为十六进制字符串，所有 u64 编号／修订／时间为十进制字符串，避免 JavaScript 丢失精度。它只投影经现有客户端验证的状态／回执；网络协议、工程与设备包格式不变。
2. 原生桌面的运行连接期望范围来自已加载的可信配置，不接受前端传入权限位。连接与取得控制权是两个动作。旧安装连接保留，新运行连接无自动降级或自动切换安装。
3. 状态读取、目录／步骤分页和正式控制经过同一串行 Service。界面保留 epoch、启动身份与修订，拒绝迟到回复覆盖新上下文；不在通信错误后重放控制。未确认请求保留为不确定状态，断开不显示节目已停止。
4. 取得控制权须显式点击；界面只对本次成功获得且仍匹配的租约定期续期，组件收起保持状态，控制界面消失后租约自行到期，节目继续独立推进。重新打开／重连不自动取得或抢占控制权。接管另行明确确认。
5. 节目目录搜索、选择／载入、步骤选择／执行、暂停／继续／下一步／停止及维护进入／退出均用真实操作；空目录、未载入、模式不符和过期状态明确展示。现场动作没有伪造撤销；编辑历史与设备动作独立。物理发送没有回执时显示未确认，不用软件运行状态推断。
6. 权限解析、跨语言投影与真实 Service 的程序控制用软件集成测试；组件隔离验收只验证界面，不操作蓝牙或灯具。完成类型／界面测试、原生编译和桌面打包后记录真实验证范围。固件实板／DMX 仍按原工单后续验收。
