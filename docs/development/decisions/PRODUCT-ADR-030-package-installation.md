# ADR-030：传输无关安装与双槽提交

2026-09-28；接受。PLAYER-003B，基线 `31e040f`，当前会话直接实施。

参考 [ESP-IDF OTA](https://docs.espressif.com/projects/esp-idf/en/stable/esp32s3/api-reference/system/ota.html) 的备用槽校验后更新选择信息、[littlefs 元数据对](https://github.com/littlefs-project/littlefs/blob/master/DESIGN.md) 的冗余提交与掉电恢复。这里只复用隔离写入／明确提交／冗余记录的机制，**不把固件 OTA API 当作节目数据分区的掉电保证**。复用已验证 Archive、tempfile、SHA-256 和操作系统文件锁，不自建文件系统。

## 决定

- 新增 `stagemaster-install`（no_std＋alloc）与独立 `stagemaster-install-store` 文件参考适配。核心只依赖包库和窄存储 trait，不引用工程、UI、BLE、墙上时间、授权或输出设备。
- 两个逻辑包槽、各一份固定版本提交记录。每次只写当前已安装版本的另一槽；在载荷持久同步及完整 Archive 校验之后写该槽的新提交记录。下一次更新可回收更老槽，因此最多保留当前与上一版本，不是无限历史。
- 提交记录含槽号、单调提交代数、长度及包摘要，自带校验。启动先读两份记录，再独立验证对应完整包，选择代数最高的有效候选；未提交的完整载荷也不自动承认。损坏项显式报告，存在较早有效项时可回退；相同代数冲突或无法可靠读取元数据时拒绝猜测。
- 代数高水位包含结构有效但载荷损坏的记录，防止后续安装被旧高代数记录反压；溢出明确拒绝。不是商业反回滚或授权计数器。
- 安装分为 begin／write／verify／commit。单块上限 1 KiB；只接受连续偏移，已经确认区间的完整重复块逐字节核对后返回相同进度；冲突、部分重叠、缺块、越界拒绝。不保存无限去重表，也不按不可信总长度分配整个包。
- 宿主每次打开安装器提供新的随机非零启动身份；事务由该身份和从 1 递增的计数组成。同事务 begin 参数必须一致，终态保留至下一事务；旧身份／旧计数不能改写新事务。传输断开不销毁安装器，通过状态续传；设备重启后暂存进度从零重新接收，已提交版本独立恢复。避免每个 BLE 小块落盘持久进度的磨损和另一套日志。
- 写入或校验失败后必须取消／重开新事务，可重试同一个包但不假装未知的部分写入已经确认。提交 I/O 错误可能发生在原子点之后，进入“提交结果待确认”，禁止取消或新安装；reconcile 先完成存储同步，再重读记录及载荷，确认新提交或保留旧版本。不能将一次错误回执等同于回滚。
- 安装成功只更新**已安装候选**，不创建／执行 Player。运行层显式取得不可变快照并装载节目；旧快照持有槽租约，备用槽被旧运行读源占用时返回忙，不覆盖读源。已经装载的 Plan 独立拥有内存；真正的节目切换与授权仍由后续运行层处理。
- 文件适配长期持有目录写锁，槽快照持有共享锁，暂存持有排他锁；同目录临时文件、文件同步、原子改名与目录同步。槽提交记录独立，当前槽不会被新上传改写。拒绝符号链接／非普通受管文件，不递归清理未知文件。

契约审查补充：核心需要的是候选选择的逻辑原子性，不要求 Flash 天然支持整份 96 字节原子写。`commit_record` 失败后目标记录可为旧、新或可检测损坏；另一槽必须保持完整。新记录只有元数据与全包均通过才能被承认。文件原子改名是更强的参考实现，后续 Flash 可用冗余记录与撕裂识别承接，不能据此跳过实板断电验证。

## 预算与边界

参考槽大小各 2 MiB，加两份提交记录和适配元数据；不据此冻结 ESP32 16 MiB Flash 分区。文件适配原子改名时可能同时占用临时载荷与旧备用文件，主机峰值磁盘预算须注明。核心重复核对只需 1 KiB 栈缓冲，Archive 验证另用既有参考预算；与正在运行的 Plan／无线栈并存的真实 MCU 峰值仍需测量。

文件参考的 fsync／rename 语义不证明 ESP32 Flash 的原子粒度、电源、擦除磨损或实时性；后续 Flash 适配必须满足同一 trait 的持久性契约并做实板断电验证。SHA-256 不是签名；安装身份不是设备绑定或播放授权。现有 20 字节 GATT 诊断协议不变，本轮不开放未授权远程安装端点或假设备界面。

验收包括逐存储原语故障／重启、提交响应丢失、损坏／不兼容包、重复与冲突块、旧事务、暂停传输／续传、取消、被占用槽、两实例写锁、严格启动恢复、真实文件参考往返与同内核逐帧对比。实际结果见 PLAYER-003B 工单。
