# PRODUCT-ADR-041：安装工作器与运行维护互斥

日期：2026-09-28；状态：接受；DEVICE-002C，基线 `a35eab8`，主工作区，当前会话单一写入。

## 问题与决定

现有 Worker 隔离了 Flash 与无线回调，Runtime 已有停止、静默确认和维护令牌，但实板工作任务仍直接调用 Worker，没有把两条边界接在一起。正式 GATT 开放前必须落实每次存储操作的维护约束，不能只靠连接授权或编译宏假设播放已停止。

在 `stagemaster-install-worker` 内增加组合层 `ManagedWorker`，拥有 Worker 和 Runtime；底层安装、传输、运行语义仍各自独立。所有安装队列命令必须在 Runtime 的当前维护令牌闭包内同步执行。运行态及尚未确认静默时拒绝操作，并撤销工作连接；故障／旧请求不能隐式停止正在运行的节目。时钟错误在副作用前拒绝。

静默确认只由可信输出宿主提交，不能从无线布尔字段转换。当前固件持有 `OutputDisabled`，GPIO21 保持低电平，没有输出队列或发送任务，因此允许在启动时确认静默；这不是未来真实输出驱动的确认实现。进入维护释放旧计划、目录与读源，操作由同一存储核串行执行。

未完成、失败或待确认安装事务阻止结束维护；须先按原事务归属取消／对账，不能用退出维护跳过。结束维护重新校验最新持久快照；恢复失败保留维护，可以重试。成功只绑定目录，不选择、载入或播放，并撤销旧安装工作连接。下一维护期使用更高连接代次，旧队列不会复活。

组合层公开必要控制委托和只读状态，不暴露可变 Worker／Runtime，避免旁路写入。底层 Worker 保留给独立协议测试和其他明确具备维护机制的宿主；ESP32 正式工作任务只持有组合层。

## 复用与验证

复用已有 Runtime 维护令牌、控制租约、NOR 读源租约和 Worker 连接撤销；不另造运行状态机、不改工程／包／无线格式。固件继续为开发诊断和受控本地探针，不新增未经认证的 GATT 写权限。

验证未确认拒写、运行／暂停／结束期间拒写且不停止播放、读源释放、未完成事务不能退出、取消或提交后恢复、坏快照恢复失败、旧维护／连接／迟到静默确认和时钟倒退。软件测试和 Xtensa 编译先行；真实固件资源与主机保活另以实测记录，不能与无线安装混称。
