# PRODUCT-ADR-109：桌面接入独立后台执行

- 状态：accepted，本机软件增量已实施和验收。
- 工单：[HOST-005](../tasks/HOST-005-desktop-background-execution.md)；基线 `142ae02`，main。

## 决定与参考

沿 HOST-004 的唯一执行进程接入桌面，不在界面重新实现播放器。现有音乐、效果草稿和三维编辑预演仍需其速率／定位语义；执行区提供明确的“编辑预演／后台执行”切换，后台使用已准备的不可变工程快照，不随编辑改变、不自动接管 UE 或物理设备。

复用 [Tauri 外部二进制打包](https://v2.tauri.app/zh-cn/develop/sidecar/) 的 externalBin 和目标架构命名；Rust 从安装位置启动固定程序，不向网页开放任意命令或路径。采用标准进程 API，输入关闭、日志落盘，退出桌面不杀后台。开发构建先串行生成后台，生产包携带同一程序。此增量只验证当前 Mac 平台。

沿既有 M09 多来源控制、M18 执行连续性研究，桌面属于控制客户端。可准备多个场景／列表和手动层；载入不等于播放，获得控制权不等于重新执行，关闭编辑窗口不等于停演。后台明确显示软件输出；尚未完成的物理输出与音视频同步不伪装为已接通。

## 接口与生命周期

- 独立 Rust 客户端复用 v2 目录／状态／会话／回执协议。只接受私有运行目录中发现的本机精确 URL，禁用代理／重定向、有界响应与请求期限；凭据不传 TypeScript。
- 桌面服务负责快照、清单、固定后台程序和运行记录；工程锁仅在获取快照时持有。一次管理一个后台，保留原进程与记录直到证实结束，不因超时另起进程。
- 本地记录只保存运行目录身份；重开应用仅观察。控制会话在 Rust 内维护序号；请求发出即记为待确认，丢失响应只查询原回执，禁止自动重发或继续发送冲突操作。显式重连会丢弃旧控制会话，再取得控制权须单独操作。
- 取得控制权与明确接管分开；租约续期仅维持控制权限，不驱动节目。客户端退出、失联、租约到期不停止节目。已获控制的服务定期续约，续约结果同样经过回执处理。
- 后台状态按启动身份、布局和版本校验。来源操作绑定后台身份和预期修订，旧界面不能误控新后台。
- 运行目录增加进程持有的文件锁；只有实际拿到旧锁或持有的 Child 返回终态，才可判定进程结束。正常关闭走已有 shutdown，再等终态；观察失败本身不能清空记录或重启。
- 界面提供来源检索／多选载入、已准备目录、状态、明确控制权、执行／暂停／继续／下一步／停止、精确电平与关闭后台。切页／切模式不隐式停演，旧预演键盘不接管后台。

## 验收边界

真实进程验证客户退出与重连、旧版本拒绝、接管／归还、失落回执、失败启动／正常关闭；界面隔离验证准备、取消、错误、状态和操作禁用；构建核对后台随应用交付。沿现有协议的物理输出、完整手动编程器界面、独立渲染观察、多时钟和云端交付继续后续；不把本工单完成当整轮完成。

## 实施审查补充

确认回执可能早于下一次只读状态发布，客户端采用较新修订的确认状态，计数仍保留观察含义；代理故障用例同时验证失落响应和较旧状态。原生验收发现新增包装组件破坏旧网格落位，已让编辑预演保留原栏位、后台使用全宽区域并移除旧步骤导航。命令、进程管理、文件和界面分别维护小文件。

调试构建新增项目内独立验收数据实例；不改用户常用应用的数据目录。运行记录早于进程启动的崩溃间隙暂不自动修复，以保留未知状态为先，后续恢复工具必须基于进程证据或明确操作，不能按时间推断终止。
