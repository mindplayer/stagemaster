# PRODUCT-ADR-148：三维场地业务对象与平移

2026-10-04，已接受；基线 `5e976f2`，main。实施 STAGE-009。

参考 Autodesk [Selecting Objects](https://help.autodesk.com/cloudhelp/2017/ENU/3DSMax/files/GUID-FAC648D5-F56D-4044-A9A3-0795926C9397.htm) 的类型过滤／复合对象选择，复用当前场地业务身份与 UE 射线、包围盒和临时组件位移；不以网格零件作为新工程实体。

只读 Mesh 投影增加 constructionId、movable、attachedFixtureIds，关联真实构件；围护多个网格共一个业务身份，支撑体列出已挂接灯具。现有协议 2 可忽略附加字段，旧消费者仍可显示；新增交互版本 4 才可编辑对象。持久格式和灯光帧不变。

三维内部以有类型的对象键保持一个有序选择，边界仍传 `{kind:"placement"|"construction",id}`，不把编码键写入工程。场地页双向共享完整集合，场景编辑仍只选灯。范围缺省仅灯具，显式全部对象允许点选／矩形选择构件；构件矩形以世界包围盒中心投影判定，灯具按安装点，均保留遮挡／穿透规则。空间本身不在本增量三维命中范围，围护可查看但禁止直接平移。

混合组水平／升降使用原 `StageEdit::TranslateObjects`，通过新增版本保护的 `previsObjectTranslation` 接入原 Session 编辑和历史。构件及挂灯去重、锁定、容量和合法范围最终由 Rust 判定；UE 仅以投影成员预览位移。纯灯具继续旧旋转／间距能力，含构件时不显示未实现的旋转／缩放。锁定与不可移动目标只阻止编辑，不阻止选择。

沿用最多 1024 个查看目标／256 个直接移动目标、源版本、连接轮次、唯一提案、取消与 3 秒临时预览回退。选择消息和对象平移提案严格定形，迟到／未知／重复目标拒绝，不能把混合组丢弃构件后只移动灯具。旧组件允许观看但不被新界面授权移动。无新的持久对象、播放时钟或硬件权限。
