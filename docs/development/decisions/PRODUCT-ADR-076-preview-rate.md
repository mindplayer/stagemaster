# ADR-076：场景／单列表临时预演速率

状态：接受。日期：2026-10-01。基线 b6c72c6；实现工单 EXEC-002。

## 参考与判断

[Titan 播放控制](https://manual.avolites.com/docs/running-the-show/playback-controls/) 区分按比例速率、固定节拍和效果大小；[MA 速度主控](https://help.malighting.com/grandMA3/2.5/HTML/masters_speed.html) 区分速度来源与倍率。复用“运行控制不重写记录参数、明确作用范围、恢复正常倍率”的机制。当前仅一个主机预演播放器，先实现整个播放器的排练速率，不声称等同多执行器效果主控或自动节拍。

## 契约

纯 Rust stagemaster-playback::RateClock 是无 I/O、无分配的单调时间映射，输入外部 u64 毫秒，输出逻辑 u64 毫秒。整数 25–400%，默认 100%。保存百分之一毫秒余数，轮询频率不能影响进度；改变速率先按旧速率推进至控制时刻，随后使用新速率，不能瞬间重采样整个既往时间。倒退、越界和溢出原子拒绝，0% 不代替暂停。

桌面每份 Loaded 独立持有 RateClock；监看、控制、UE 和效果草稿替换共用映射后的时刻，再交给既有 Player。延时、渐变、自动等待、循环和动态效果一同比例变化，手动推进仍须人工触发。显示经过时间仍是原编排逻辑时间，界面显示当前倍率并说明作用于所载入场景／列表；不误称为真实墙钟秒数。

preview control 新增 `{kind:"setRate",percent:整数}`，快照 loaded 新增 ratePercent。沿既有 epoch／serial、版本保护和严格未知字段拒绝；无载入／旧代次／乱序／旧工程拒绝。暂停时可改倍率但不移动播放位置或恢复播放；停止保留该载入内容倍率，重新载入／新建／打开工程重置 100%。更新／结束同一效果草稿保留倍率和当前进度。

速率是运行状态，不写 JSON、工程历史、播放包或设备协议。音乐仍由音频采样时钟驱动，音频／节目预演互斥机制不变，不能把音乐灯光单独变速。此增量不含音频变速、Tap Tempo、独立效果速度、物理设备输出或速度安全限制。

## UI 与并发

场景预演与专注执行台复用小组件：50%／100%／200% 快捷按钮、25–400 精确输入／应用、取消输入；明确当前实际生效值。仅控制已载入且当前所看一致的内容。输入草稿不进入工程 collect，不自动应用其他编辑草稿，不阻止暂停／停止；错误保持可恢复。所有变速仍经同一 usePreviewController 串行控制与旧回执保护，TS 不自行换算播放进度。

## 验收

独立时刻向量、频繁小步与一次大步一致、倍率切换连续、暂停／恢复、延时／渐变／效果／自动推进、重复／过时／越界拒绝、渲染与监看同源及无渲染也推进；草稿替换保留速率，加载重置，原音乐不受影响。原生界面精确输入／错误／取消、跨页、载入版本、历史未改和唯一 UE 验收。实际结果记工单；未以方案冒充已实现。
