# PRODUCT-ADR-047：独立 Noise 应用层安全会话

日期：2026-09-29；DEVICE-002B；基线 `050cb82`，主工作区、当前会话负责。
状态：接受有界协议实现与双端验证；无线适配及授权存储另行接入，不宣称生产认证完成。

## 选择与边界

落实 [ADR-046](PRODUCT-ADR-046-cloud-owned-direct-gatt.md)。采用锁定 `snow 0.10.0`、`Noise_IK_25519_ChaChaPoly_SHA256`，仅启用对应 RustCrypto 原语，不启用默认整套算法或平台随机源。宿主注入失败可报告的系统／硬件随机源；ESP32 须在 RF 随机熵已可用后使用。没有自写密钥交换、AEAD 或 KDF。

参考 [Noise 规范](https://noiseprotocol.org/noise.html)、[Snow 官方实现](https://github.com/mcginty/snow)、本地下载的同版本源码。Snow 支持 no_std＋alloc，具有错误返回和随机源注入，现有 ESP32 已有有界堆；相比噪声原语接口更低层的 noise-protocol，可少维护缓冲前提及底层状态。分配成本必须实测。两库的默认 X25519 接口均不拒绝全零协商结果，本项目在 resolver 的 DH 委托边界增加全零结果拒绝，不改写算法。Snow 没有正式审计声明，当前选型不等于量产安全认证。

IK 由电脑／手机发起，使用先验可信设备公钥；设备从加密握手取得控制端公钥。后者只证明密钥持有，**不自动代表该账号／控制端获授权**。云端或隔离开发准入策略另验证该公钥与许可，才能产生安装权限。设备公钥必须来自可信登记／实体认领，不从当前未认证广播直接信任。此层不要求系统蓝牙配对、链路密钥或云端在线。

## 协议与状态

固定 prologue 绑定本协议域、稳定设备编号、启动随机号、当前连接随机号；套件固定，不协商降级。每连接重新生成临时密钥。两个 Noise 握手消息没有业务载荷；完成后还须通过双向加密确认，载荷为握手摘要：发起端确认、设备确认回复。只有确认完成才能读取 `PeerProof` 和传递业务记录，防止旧握手首包造成安装权限或其他副作用。

握手和确认共用从创建起算的固定 10 秒期限，不因碎片或诊断保活延长。密钥证明不承载网络可伪造的角色；`PeerProof` 只由本模块构造，不实现反序列化。上层仍须核对设备／控制端信任策略，不能把该类型命名成“云端已授权”。

业务记录包含 1 字节类型和至多 1280 字节载荷，随后由 Noise 加密，最大密文 1297 字节；握手固定长度 96／48 字节，确认明文 33 字节。普通消息、保活请求、保活回复的类型及长度严格区分；保活载荷为空。分片属于外层连接适配，不改变密文记录边界。全部记录按 Noise 双向独立递增计数处理，不暴露任意设 nonce／回退接口；乱序、重复、篡改、过长和任一底层错误使当前通道失效。

确认后 6 秒业务存活期限仅由成功解密且格式有效的入站记录更新；本端发送和公开诊断保活不能续期。时间倒退、溢出、超时关闭。密文解密失败清除调用方明文缓冲，不把未验证结果交给业务。取消／断线须丢弃对象，不能跨新连接继承密钥或状态。

密钥参数、明文暂存使用 zeroize，接口不实现秘密 Debug／Serialize；不声称底层 Snow 的所有内部副本或优化后的机器内存都已安全擦除。生产密钥保护、可信时间及云端委派仍按 ADR-004／046 的独立门槛验收。

## 实施与验收

新建 `stagemaster-device-session`，不依赖 BLE、云端、存储、UI 或播放器。小文件分别负责随机源／密钥、上下文／时间、握手、确认与记录。跨语言／独立实现向量或互操作验证用于排除“双方同一错误刚好通过”；另覆盖错设备键、错上下文、全零 DH、认证前业务、重放／乱序／损坏／超限、固定期限、公开心跳不续权和随机源失败。

先验证工作区及 Xtensa 完整链接／资源，再接 GATT 密文分片和实际 Endpoint。后续开发凭据须每设备独立随机生成，留在项目忽略的私密文件，并与正式云端签发路径隔离；不采用通用测试密码或自报主体。该步骤没有更改工程格式、播放许可或启用物理输出。整个 DEVICE-002 继续到实际安装和桌面验收完成。


## 本轮结果

385 Rust 全量／严格检查、两端角色与独立实现互操作和 Xtensa 实际链接通过。ESP32 本地双端握手／确认约 0.50 秒、128 轮最大消息加密＋回复约 0.22 秒、额外堆峰值 1112 B，释放后恢复基线。详细条件、失败修复和恢复状态见[验收](../tasks/DEVICE-002B-session-acceptance.md)。资源可接受，批准继续做 GATT 有界记录及可信准入集成；尚未宣称无线安全安装、量产凭据或云端签发完成。
