# ADR-073：片段效果时间偏移与保相位分割

状态：采纳；2026-10-01；AUDIO-010；基线 `12ec189`；当前会话独立评估。

参考 [OpenTimelineIO 时间范围](https://github.com/AcademySoftwareFoundation/OpenTimelineIO/blob/main/docs/tutorials/time-ranges.md) 区分素材时间与轨道位置；复用本项目 Rust 整数效果求值，不引入视频编辑依赖，不把 OTIO 的 interchange 定义当灯光运行引擎。此增量先做不会重启动效的分割；完整裁切、裁切渐变和连续双源交叉仍后续。

`AudioLightingClip.effectOffsetMs?: u64`，缺省 0／序列化 0 省略，范围 0–3,600,000 毫秒且与片段长度之和不超过该界限。非零要求新能力 `media.audio-clip-offset@1`；与独立片段轨道配对，清除音乐移除能力；恢复全零仍保留声明。仅偏移动态效果采样时钟，不改变片段自身渐变／延时、音乐、卡点或空间。已有工程无偏移保持行为。普通编辑保留源偏移，修改须显式命令；复制／成组移动／停用保留，重置可显式从头运行。

`splitLightingClip {id, timeMs}`：锁定／不存在／边界／超容量／进入渐变未完成／源时间溢出原子拒绝；必须 start < time < end 且 time - start >= fade。左段保留 ID、名称、原渐变与偏移，仅收短结束；右段新 ID、同场景／名称／启停、fade=0、偏移=原偏移＋分割间隔，保持位置连续、其余片段／音乐不动，一次撤销。重复分割偏移累积。UI 明确最早可分割时刻，支持精确位置；从播放头填入使用原生已确认位置，不能用浏览器插值作为业务时间。

`resetLightingClipEffectOffset {id}` 显式清零，锁定拒绝、no-op 无历史；普通 put 不能暗改偏移。拆分后可在新位置独立重新设计渐变；初次分割保证全时间采样等价（包括后继渐变源快照）。若分割发生在渐变中，需要保存完整过渡来源，这不由简单 offset 冒充。

核心采用 Plan 的单场景效果偏移：限定一个无自动推进、无循环、无延时的场景，默认 0；采样先按各自周期取模再加偏移，保留原始 16 位相位与不同周期，不换算为有损相位角。渐变仍按片段本地时间。音乐编译给目标 Plan 设置偏移；采样前段边界时使用该前段偏移，保持已有最多两个场景编译的有界机制。设备包当前语义 1／2 不能编码偏移，编码器明确拒绝非零 Plan，禁止悄悄丢字段；旧包逐字保持，不升级或刷入固件。Plan 新增固定标量计入既有 512 字节元数据保守预算并加结构尺寸保护，实板部署另行验证。

公共边界涉及 playback Plan、project 音乐命令／格式和 package 编码拒绝；不新增音频时钟、UI 求值或实际灯具动作。验证涵盖各曲线／不同周期、渐变／离散属性、任意定位／反复分割、旧格式、严格能力／未知字段、事务／历史、包拒绝和真实应用保存重开。
