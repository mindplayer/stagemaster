# PRODUCT-ADR-144：挂灯草稿复用正式 Rust 编辑

2026-10-04，接受；UX-049，基线 `63ef812`。

原挂灯弹窗遮挡场地且参数横向裁切。采用现有侧栏／中央平面结构，参考 [Vectorworks 挂载关系与对象属性](https://app-help.vectorworks.net/2022/eng/VW2022_Guide/LightingDesign1/Concept_Attaching_loads_to_rigging_objects.htm?agt=index) 的支撑体关联、批量挂接和对象上下文；不承担荷载计算或结构安全认证。

增加只读 `riggingPreview(generation, command)` 宿主接口，command 仅允许现行 attachFixtures。原生宿主检查工程代次、复制已校验文档，在会话锁外调用现行 Document.edit，再返回所选灯位和是否有实际变化。预览不写文件、历史、恢复点或播放／渲染状态。正式应用仍走现有工程事务，再次执行完整校验；不把预览回执视为提交凭证。

界面保留最多一个执行中和一个最新待处理请求，响应绑定输入、工程代次与草稿源；取消、改参、换工程或来源变化后旧回复无效。输入无效或预览计算中显示已应用灯位，不保留上一份有效预览冒充当前结果。保存／离开复用 collect／accept；未改变的打开不提交，改变后的草稿须取得当前预览结果才可应用；取消不改原工程。

输入字段、会话模型、异步预览、宿主适配和显示分别组织。不增加 TS 挂灯计算、不改变工程格式、灯光核心、UE、音频或设备输出。平面显示目标支撑体与所选草稿灯位，UE 继续使用已应用工程。

验证包括 Rust 预览／正式应用一致、原会话和播放不受影响、陈旧代次与非法／锁定目标拒绝；界面迟到回复／取消、搜索灯序、空值和余量错误、切页／保存及一次撤销；原生独立副本保存重开。
