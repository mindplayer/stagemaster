# ADR-089：色盘固定档位修订的显式迁移

2026-10-02，接受；基线 `7befdf7`，当前会话审查。

## 问题与参考

FIXTURE-007 已支持外观记录和模式变体，但实际确认色片边界后，用户还可能修正代表值或固定档位区间。仅保存一个无法应用的新模式，不能完成现场灯库修正。[Titan 19 Exchange Mapping](https://manual.avolites.com/docs/patching/changing-the-patch/#exchange-mapping) 提供源／目标功能对应；本项目吸收明确对应和差异审阅，先实现稳定档位身份的受限迁移，不按名称、颜色距离或整个通道反转推测对应。

## 决定

- 既有 `exchange` 命令增加可选 `allowColorSlotRemap: boolean`，缺省 false，保留旧严格行为。true 只允许 `color-wheel` 中**相同功能键且都是固定档位**的起止值／代表值改变；功能键集合、固定／连续类型须相同，自动换色等连续功能的控制映射必须保持，其他功能属性也仍须保持原控制映射。完整目标模式照常严格校验。
- 原场景和预设继续引用稳定档位键，编译时使用目标模式的新代表值。只换所选灯具的 profileId，原模式／未选灯／预设引用不重写；整批原子提交及撤销，当前播放继续遵循现有会话版本失效流程。改变实际控制值不意味着已确认现场输出或保证光色相同。
- 界面同时列出源模式与目标模式、涉及灯具、每个变化色盘档位的前后名称、区间、代表值及外观。需要重新编码时，由明确的“采用新版本的固定色盘通道值”选择传入授权字段；默认不选，选灯／目标模式／源或目标修订变化后失效，取消不应用。
- 只要任何所选灯存在不支持的差异（缺少档位、连续功能改变、物理模型不同、属性集改变），整个候选仍不相容。颜色标签不同而控制映射相同沿用 FIXTURE-007，不额外要求重新编码选择。地址和新默认值仍按既有替换机制审阅。
- 无持久化字段／执行包语义变更。该布尔字段只允许已限定的编辑事务，不能作为任意设备输出或任意功能重映射的开关。跨厂商新键映射、删除功能、图案图像及控制宏后续。

## 模块与验证

控制映射比较从显示外观模块移至独立纯 Rust 模块；TS 保留预检投影，Rust 是最终裁决。界面差异组件和计算辅助独立于配适对话框。测试缺省拒绝／显式成功、只影响选定灯、场景及预设引用保持、自动区间不放宽、混合批次失败不变、过期选择、取消与原生撤销／重开。
