# PRODUCT-ADR-122：后台正式循环与预编译灯光复用

状态：accepted，本增量已实现并通过软件与原生静音验收。2026-10-03；TIME-001；基线 `db87319`，main，当前会话单写者。

## 依据与范围

继续 ADR-111～121 的独立时间域和后台音频链路。现有 LoopPlayback／PerformanceSource 已按实际 PCM 帧执行有限循环和本遍结束退出；后台入口仍拒绝循环，媒体 admission 和 LiveAudioTimeline 拒绝位置倒退。不能简单删除拒绝，也不能在每次回跳重新解码、编译或创建播放器。

复用 TIME-001 已记录的 GStreamer 机制：素材位置可回跳，运行时间保持连续；实际消费、控制意图和宿主单调时钟分开。复用本项目既有循环调度、缓存预算、完整帧一致观测、媒体组和受控回执，不增加第二套循环数学或独立服务。

## 运行契约

- LoopPlayback 增加从本次定位起累计回跳的 tick 数，有限次数结束和跨过多个循环也保留累计值；seek 归零，溢出保留旧游标并报告失败。与素材位置一起原子发布，回调无分配、锁等待或编译。
- 正式原生媒体观测包含实例、采样率、素材 tick、累计消费 tick 和累计回跳 tick。相邻观测满足 `新位置 = 旧位置 + 消费增量 - 回跳增量`；消费和回跳不得倒退、时基不得改变，消费速率仍受原时钟质量／速率／失联预算限制。暂停不能伪造消费或回跳。
- 只有准备好的音乐轨道可接纳 PCM 进度观测；仅已声明循环的计划允许回跳。激活时明确绑定这一观测形态及音源实例，运行中不能切换。普通线性来源保留原拒绝倒退规则。显式定位仍走新的准备／播放代次，旧样本失效。此入口仅供已绑定的可信媒体提供方，不是远程客户端任意回跳接口。
- 精确定位按原生采样率向下量化至实际采样帧（例如 44.1 kHz 的 2501 ms 对应 110294 帧）。先静音挂载并读取实际位置，再按该位置准备灯光，刷新原生健康观测后激活；受控入口核对原请求与实际帧的整数换算，不能放宽为任意一毫秒误差或伪造精确位置。
- 回跳复用原 LiveAudioTimeline 的预编译定点采样和贡献；在实际宿主时刻重新声明本组编排属性的所有权。一次观测跨过多遍也只求值一次；普通采样和暂停继续不抢回手动接管，未编排属性及其他来源保持。循环边界视为新一遍编排开始。
- 开始／暂停／定位／循环退出沿用原控制权、修订、期限与回执。退出绑定原音源实例、区段和遍数，实际回调确认后才完成；已过期的退出目标拒绝，不导致正常音乐停止。退出请求在确认或拒绝回执期间超时／被替代时，原请求失效，音源保持实际运行状态，界面退出“准备中”；真实音源或宿主故障仍按原规则停止。循环退出不等于停止或定位。
- 桌面声明循环能力并显示实际循环区段／遍数和退出状态；旧后台没有能力时继续拒绝不支持的操作。直到真实独立进程、客户端及桌面链路验证完成，不能宣称后台循环已交付。

工程格式、设备包、商业许可不变；音源采样仍为软件消费观测，不代表物理声卡呈现时刻或实机同步精度。准备缓存继续复用既有 64 MiB 上界。

严格检查发现循环命令扩展后，64 组的状态数组超过原有 16 KiB 栈预算。沿用已有终态回执的表达，`ObservationReceipt` 由包含完整 `GroupKey` 改为只包含输入 `generation`；固定组身份由所属 `MediaState.group` 提供，发布序号仍由该组独立单调生成。入槽、校验与执行继续使用完整组键，不缩减权限检查；旧代次拒绝回执保留原代次，不冒充当前代次。不在调度中新增堆分配或放宽栈检查，不改网络序列化格式。

## 验收

有限／无限循环、一次观测跨多遍及跨完整区段、暂停和恢复、手动接管与未编排属性、退出与取消、旧遍数／实例／代次拒绝、定位与末尾、异常观测不改输出、软件真实 PCM 与原 Host 的完整帧、桌面能力兼容和实际回执。按职责拆分，相关 Rust／UI 检查及静音软件验收；不触发真实灯具或刷机。

实际结果见 [TIME-001 正式后台循环增量](../tasks/TIME-001-independent-clock-boundaries.md#正式后台循环增量基线-db87319)：188 项相关 Rust、311 UI、严格检查、固件交叉检查、桌面构建与原生循环／退出／暂停／定位通过；未宣称物理同步或完整 TIME-001 完成。
