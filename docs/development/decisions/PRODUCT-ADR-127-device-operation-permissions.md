# PRODUCT-ADR-127：设备安装、观察与运行控制分权

状态：accepted，范围与现有安装接线已实现并通过软件验证。2026-10-03；基线 `4d741a4`，main；对应 DEVICE-003。FRAMEWORK-001 的完整基线回归继续使用原作业，本增量单独验证。

## 问题与依据

正式设备连接当前只有加密安装入口；Runtime 和 ManagedWorker 已有运行控制，尚未向连接公开。现有应用 Grant 只表示安装资格，没有操作范围。直接把它交给新的播放入口会把“可以上传节目”隐式升级成“可以控制现场”。公共设备能力、握手成功和当前操作者控制租约也不能代替这个判断。

沿用 [ADR-050](PRODUCT-ADR-050-application-installation-admission.md) 的确认后准入、逐次权限检查，以及 [ADR-033](PRODUCT-ADR-033-device-runtime.md) 的唯一控制租约／原请求回执；采用明确最小操作权限的成熟做法。复用现有 Noise、Session 和 Runtime，不新增密码算法、账号服务或第二套播放器。具体生产商业授权仍按 ADR-101 后议。

## 决定

1. 可信宿主构造的开发许可显式携带 Installation、Observe、Control 三个独立范围，可由可信配置组合；没有从网络位图反序列化后直接授予权限的入口。
2. 原 `DevelopmentPermit::installation`、SMDV v1 配置和 SMAP v1 就绪回执继续仅代表安装。新范围不修改现有配置／握手字节，不自动提升旧凭据权限。运行协议及能力协商另一个增量接入，不能借旧安装回执宣告可执行。
3. Session 的操作准入每次先校验当前身份、安全租约、开发许可期限和撤销，再检查指定范围。范围拒绝关闭该会话，沿用现有失败即撤销规则；Grant 的只读范围查询仅供展示／检查，不是可缓存的持续权限。
4. 现有安装 Gateway 在打开和每次工作前明确要求 Installation。后续运行网关读取要求 Observe，取得／续期／交接控制权和运行操作要求 Control；播放许可继续由 Runtime 的 PlaybackPolicy 独立判断，连接断开不停止已运行节目。
5. 本增量只实现范围及现有安装路径的防串权，验证真实密码会话和原 Gateway。不把它称为远程播放入口完成；后续仍须接完整消息、目录／状态、命令回执、失联重连、桌面组件与目标固件。

## 验收

旧配置只授予安装；观察、控制不能打开安装工作器，安装不能通过观察／控制准入；组合范围必须显式指定。错误范围、旧会话、过期及心跳均不能升级／复活权限；保留原安装／分片／恢复和真实本机承载回归。无新第三方、网络或持久化格式变更，不刷机、不连接真实设备、不输出 DMX。

结果：64 项权限／安装和 59 项连接承载回归通过，包含 6 项新增范围用例；全工作区严格 Clippy 与实际 Xtensa application-gatt 检查通过。旧 SMDV／SMAP 字节与锁文件未改。未来运行协议仍须显式接入，当前范围不代表固件播放能力；完整 FRAMEWORK-001 基线另待最终结果。
