# PRODUCT-ADR-177：内部构建的源码快照与归档身份

状态：当前实施会话接受限定方案，2026-10-06，DESKTOP-013。沿 H5 准确版本与可复现交付，不新增运行服务、签名或代理平台。

## 当前缺口

内部构建会验证原包标识、复制清单与本轮后台哈希，但源码来源仍靠各任务临时脚本手工记录少量文件。记录没有统一 Git 基线／源码差异与输入指纹。共享 Cargo 目标复制前只检查原包身份，归档后没有独立再检查身份；不把这一并发风险写成已有真实错包事故。

## 决定与范围

- 新构建自动捕获有界桌面仓库输入快照：Rust、桌面／后台、前端、构建工具及实际嵌入的两份工程 Schema；明确范围、文件字节摘要、执行位和 Git HEAD／真实源码差异。包含范围内未提交的新源码；不把工作区内容标成纯提交版本。不读取或遍历 output/、data/、logs/、tmp/、安装依赖树或历史工作器。
- 复用原 Git／Node／Tauri 构建；输入前后指纹和 Git 基线不一致则保留 failed 记录，不登记成功。输入快照不是不可变 checkout，不承诺捕获中途改写再恢复，不代替环境／安装依赖／编译器的完整供应链或二进制可重现证明。
- 将非敏感来源 JSON 通过已安装 Tauri 的资源映射随新内部包交付，不改旧包。只含相对文件路径、摘要、基线与差异，不保存父环境或密钥。既有资源数组／映射保持，保留名称冲突须拒绝；不修改签名、证书、权限或最低系统。
- 归档后独立核对实际包身份、后台哈希、源资源原字节及复制清单。失败保留新归档和日志供诊断，既有目标不覆盖。该机制不授权并行写同一模块，也不宣称任意共享目标并发构建已有事务锁。
- 新诊断字段为 `sourceEvidence`，版本 1；旧 build-record／旧原生资格保持历史事实，不回填或自动晋级。状态 `isolated-release-built` 仍仅表示构建／封存通过，`customerReleaseQualified=false`，不是原生、GPU、听音或客户发行通过。

上限先为 4,096 输入文件、单份 64 MiB、总计 256 MiB，有界目录扫描和 64 KiB 文件缓冲；超限显式拒绝，不悄悄省略输入。新能力私有于构建工具，不改变 Rust 权威、ApplicationHost、工程／播放包格式、时钟或控制权。

## 验证

真实 Git／文件夹具验证干净／已修改／未跟踪／删除／执行位、非 ASCII 路径、链接／预算与输入变化；归档夹具验证身份错配、来源文件错配、后台错配、目录／覆盖保护与真实非零命令。新内部包实际构建、核对随附来源和最终封存，原生基础打开／退出单列，不转移旧资格。源／包哈希只证明限定输入与档案一致，不替代首版全部出口。
