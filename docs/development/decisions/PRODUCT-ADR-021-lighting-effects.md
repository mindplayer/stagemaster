# PRODUCT-ADR-021：场景动态效果与统一播放

2026-09-27；当前 Astra 审查接受；基线 `a88c0b5`。实施工单 EFFECT-001。

## 参考与取舍

核对 [MA Phaser](https://help.malighting.com/grandMA3/2.5/HTML/phaser.html)、[Titan Shape Generator](https://manual.avolites.com/docs/effects/shape-generator/)、[Titan Key Frame Shapes](https://manual.avolites.com/docs/effects/key-frame-shapes/)。借鉴多值循环、速度与灯序相位分离、可编辑效果记录；不复制两家的全部层／跟踪规则。本次采用明确的两端值曲线：平滑、线性往返、脉冲。首批入口为亮度呼吸、亮度追逐、双色循环；运动学尚未接通，因此不以旋转三维光束冒充摇头灯编排。

## 持久化与编译边界

场景增加可选 `effects` 数组，并声明 `lighting.effects.basic` 版本 1；旧工程缺省为空，新能力由旧读取器明确拒绝，维持现有草案主版本。效果有独立 UUID、名称、启用状态、冻结的有序灯具集合、周期毫秒、相位／展开角度、反向、脉冲亮段比例，以及属性两端的 u16 绝对值。当前只允许亮度与 RGB。灯组调用提供选择顺序；之后改组不偷偷改变已存效果。复制场景时重建效果 UUID。

效果与静态场景记录并存，启用效果覆盖其涉及的属性，停用后恢复静态语义。同一场景的启用效果不能争用同一灯具属性，整次编辑原子拒绝；不同属性可以叠加。删除被效果引用的灯具必须先解除引用。每场景最多 32 个效果；编译最多 16384 条属性效果，单步不超过 512 条；周期 100–3600000 毫秒。无逐帧烘焙、无第三方新依赖。

Rust 工程模块编译为独立 `no_std` 播放模块的整数曲线。执行期间不分配、不依赖墙钟／网络／UI／UE；宿主只提供单调毫秒。曲线及相位只有一个求值实现。ESP32 可编译复用此核心，但本轮不宣称已验证其资源预算或固件包支持。

## 时间语义

每次执行步骤，在延时结束时将本步骤效果相位重置到保存的起点。进入步骤的渐变从上一可见值过渡到随时间变化的目标。延时期间保持上一可见快照；不暗中继续上一效果。静态继承仍按现有规则，效果不跨步骤继承。自动推进在精确边界求值，再进入下一步；迟到帧跳过完整循环时必须与逐步计算一致。暂停冻结渐变和效果相位，继续不补跑暂停时间；停止恢复档案默认值；有限列表结束冻结边界帧。单场景预览是同一播放器的一条手动保持步骤，持续运行直到暂停或停止。

展开采用半开区间：第 i 台的相位为起点加 `展开 × i / N`，360° 不让首尾重复；反向反转所存灯序的相位分配。相位表示滞后，脉冲以第一台先亮并按灯序传播。平滑使用定点 smoothstep，不称为正弦。颜色为归一化 RGB 通道插值，不承诺光度或感知均匀。

## 宿主与界面

复用统一工程命令、历史和保存；独立效果组件提供新增／修改／复制／启停／删除、精确周期、两端值、灯序及取消。单场景直接载入预览，无须创建额外列表。场景和列表共享唯一预览实例、代次与串行控制号；新增场景载入及控制序号快照，避免多个面板各自重新从 1 计数。三维使用现有播放输出来源，不在 UE 实现振荡器。编辑后旧预览保持明确的过期状态，需要重载，不自动触发真实输出。

## 后续边界

相对层、自由关键帧、速度主控／音乐节拍、效果跟踪、有限次、随机种子、像素映射、摇头运动／校准、模板资源池留为后续独立增量。不得把本轮两端曲线模型冒充完整 Phaser。以真实编辑、保存重开、撤销、可重复求值和三维共享输出作为本轮出口。
