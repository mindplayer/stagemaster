# PRODUCT-ADR-140：慢命令前刷新当前灯光快照

2026-10-04；接受、代表性边界实板复测通过；MEMORY-002，基线 `9f3fcb4`。不改包格式、公开命令或 Runtime 的执行语义。

实际边界包包含 128 步／24 属性节目，加载操作最长 32.711 ms；原固件在两次 25 ms 定时采样之间直接执行命令，形成 57.930 ms 间隔，超过既定 50 ms 验收线。持续运行最大 tick／render／采样 3.452 ms，UART 无故障，不能把这次失败解释为整个状态机不适合 S3。

原工作器仍唯一拥有状态机和存储；原 Ticker 继续 25 ms 周期，原发送仍在第二核中断执行器。增加小型板级采样节奏记录：处理已入队运行命令前，若距上次实际采样至少 10 ms，则先经原 tick／render／LocalOutput 发布当前完整帧，再处理命令；小于 10 ms 时复用刚完成的采样，不重复同毫秒帧。选择／状态／加载均不检查或绕过命令权限，原 Endpoint 仍在实际执行时和执行后核验授权、时钟与期限。

这是慢命令前服务输出，不能取消长期阻塞或保证任意重负载实时。正常运行／断线期间仍只有原周期；控制期间可能增加一次最新帧，原固定槽合并，绝不积压旧帧。没有提高线程优先级、降低语料或扩大 40／50／100 ms 与看门狗门槛。维护中没有输出许可，额外采样不会使能输出。

必须复测同板同包的完整状态切换与最大间隔；另测满 64 节目目录，避免只针对一个加载点。若同步工作本身仍超过预算，应继续拆分工作或优化实现，不能靠这层补帧声称解决。保持 GPIO21 禁用，真实波形与长期验收继续独立。

实板结果：同一四类边界包复测最大间隔 40.310 ms、最大工作 3.476 ms；满 64 目录逐个载入／运行／停止后最大间隔 27.631 ms、最大工作 2.702 ms。两组暂停保持、断线连续至少 41 秒约 40 Hz、同启动同实例重连及归还控制均通过，没有放宽原 50 ms 门槛。报告和首轮失败均保留，详见 [MEMORY-002](../tasks/MEMORY-002-device-capacity-acceptance.md)。

适用边界不变：这不能保证所有合法输入都低于预算；799,587 字节测试包安装时最长单次操作 1.629559 秒，已经接近 2 秒工作进度预算。最大完整文件的安装／恢复等长操作须继续独立验收和必要的分步处理，不能提高看门狗期限、旁路喂狗或把播放通过当维护上限通过。
