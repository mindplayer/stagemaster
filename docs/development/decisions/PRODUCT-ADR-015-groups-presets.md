# ADR-015：有序灯组、预设引用与属性复用

2026-09-27；接受；DESKTOP-004；基线 `8513eee`。当前 Astra 会话自行审查、实现与验收。

用户要求 goal 模式进一步丰满专业编排。继续现代组件式工作台，优先交付反复选灯、记录可复用属性、统一更新场景这条实际工作链。

## 参考与取舍

- [Titan 灯组](https://manual.avolites.com/docs/controlling-fixtures/fixture-groups/)：保存有序选择，召回、追加、扣除和调整成员顺序；灯组不是亮度主控。
- [Titan 预设编辑](https://manual.avolites.com/docs/palettes/editing-palettes/)：记录掩码、仅更新已有属性／合并／替换，以及查看引用范围。
- [MA3 预设更新](https://help.malighting.com/grandMA3/2.5/HTML/presets_edit.html)：已有内容与新增内容分开；更新数值不暗中扩展已保存场景的属性覆盖。

本轮只实现现有工程格式支持的逐灯预设，不混称通用／同型号共享预设。不新增灯光算法依赖，不复制控台深层菜单。位置、效果、嵌套预设和共享配方需要后续独立契约。

## 命令与状态

`EditCommand::Library { command: LibraryEdit }` 转交独立 Rust 库模块：灯组存储／复制／删除；预设记录／更新／复制／改名／删除；应用预设、解除引用、复制属性。所有操作由 Document 克隆事务统一校验；一条命令一次撤销，非法操作零修改。

灯组的 `fixtureIds` 是唯一、非空、有序 ID 集合；选择变换归界面，保存后归工程。修改组不会重写已有场景，删除灯组不删除灯具。成员失效报错，不静默裁剪。

记录预设明确来源场景、灯具集合和属性集合，仅捕获该场景直接记录的数值（引用先由 Rust 解析），不猜测前序继承值，不将释放／未记录补成零。无匹配时报错。更新三种模式：existing 仅交集、merge 保留旧项并合入、replace 替换全部；禁止移除仍有场景引用的目标。

应用预设只作用于所选灯具与掩码中的已记录目标，界面显示匹配数量；引用模式保留 presetId，独立值模式复制解析后的数值。新增预设目标不扩张旧场景引用。解除引用保持当前数值。删除被引用预设默认拒绝，也可显式选择“保留场景数值并删除”原子转换。

复制属性明确源灯、目标灯和属性集合，读取场景当前记录值；目标必须支持所选属性，任一不兼容则全部拒绝。复制的是独立值，不能把逐灯预设冒充跨灯引用。

ProjectView 新增灯组、预设内容和引用场景／列表投影，SceneValue 新增 presetId。持久格式沿用 draft.1 的 groups／presets／assignments，无格式版本变化。预设解析集中供视图、命令、编译使用。播放计划仍为不可变快照，编辑后已有预览失效，重新载入才反映修改。

## 界面与验收

独立资源池、灯组编辑、预设编辑组件接收投影并发命令；Workbench 只负责串行事务、宿主和当前选择。详细录入在可取消编辑窗内完成，窗口关闭请求不得丢失未提交录入。搜索／筛选不改变隐藏选择；组顺序可查看并调整。

验证顺序：核心原子性／引用保护／编译一致性；界面选择与命令转换；原生实际录入、取消、错误、撤销重做、保存重开与离线预览。结果写 DESKTOP-004；本轮无设备输出。
