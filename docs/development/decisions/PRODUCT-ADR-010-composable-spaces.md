# PRODUCT-ADR-010：可组合空间与异形室内场地

2026-09-24；基线 `cf13e72`／main；工作区 `/Users/sunqi/projects/stagemaster`，开始时干净。状态：方向审查通过；具体空间契约、迁移与产品实现待独立工单。本次不改变工程 Schema、Rust 类型或执行语义。

## 需求与判断

用户补充：实际场地可能是若干室内房间组合，每个房间形状、长宽、高度不同。此前 UX-007 已考虑不规则轮廓，但首个闭环仍偏向单一场地／舞台，不能把全局宽、深、高作为场地的唯一表达。场地应容纳多个空间，舞台只是其中一种设施；密室、展馆和无舞台的装置项目也适用。

## 成熟经验

- [Vectorworks 2026 空间设置](https://app-help.vectorworks.net/2026/eng/VW2026_Guide/Spaces/Space_settings.htm)区分平面边界、上下界及偏移，支持边界关联墙体；非水平上下界使用拟合几何。借鉴参数编辑和边界关系，不复制建筑面积核算、装修与能源分析功能。
- buildingSMART [IFC4 ADD2 TC1 的空间](https://standards.buildingsmart.org/IFC/RELEASE/IFC4/ADD2_TC1/HTML/schema/ifcproductextension/lexical/ifcspace.htm)区分空间、空间组合及地面／净高；[空间边界关系](https://standards.buildingsmart.org/IFC/RELEASE/IFC4/ADD2_TC1/HTML/schema/ifcproductextension/lexical/ifcrelspaceboundary.htm)区分物理与虚拟边界。借鉴对象与关系的分离，不把完整 IFC 数据模型或导入器作为首版前提。

## 决定

1. **一个工程可组织多个空间。** 场地内可有房间、走廊、开放区域，以及可选楼层／空间组；简单露天场地不必创建建筑和楼层。编辑层级与坐标父级分别表达，组织标签不能隐式移动几何。对象有稳定身份，改名或改轮廓不重建灯具引用。
2. **轮廓是基础，长宽是便捷输入。** 矩形是快捷创建方式，支持凹多边形表达 L 形、转折走廊等；异形空间显示边长，包围盒长宽不能冒充真实边界。内洞、弧线、斜顶和高低地面保留明确的几何扩展路径，不以一个任意网格替代所有可编辑参数。
3. **每个空间独立表达地面与顶部。** 初期平地、平顶使用地面标高与净高；两者以明确基准表示，顶部标高由其导出，不同时维护三份可冲突数值。空间级标高与变换 Z 不能重复相加。楼层是组织／标高参考，不能假定同层所有地面一样高。未来变高空间使用分段或表面表示，净高成为位置相关量，不能只存平均值。露天无顶，不以净高 0 冒充无限高。
4. **空间边界、物理构件、连接分开。** 房间可以由虚拟边界划分，墙、地面、顶面、柱子是独立物理对象。共享墙只维护一份权威几何，两侧空间引用各自边界；门洞引用所属墙及位置／尺寸，相邻关系由明确连接表达，不由房间名字或包围盒相交猜测。几何门洞不等于自动门控制器，后者仍是独立设备／机构对象。
5. **所有空间可换算到同一工程坐标。** 沿用右手系、米和度；灯位、目标点与安装构件有明确坐标归属。整组移动只带动显式附着对象；改房间轮廓不按比例缩放灯具、门洞、舞台或目标。移动与相邻房间共享的墙会影响两侧，必须展示影响并原子提交；独立移动房间涉及断开连接时不得静默拉伸邻房。跨房间共同指向保留同一世界目标，但几何求解成功不代表光束能穿墙到达。
6. **空间组织不决定控制分区。** 灯组、节目、播放设备和 DMX 输出分配独立于房间。可在同一房间内分组，也可跨房间编排；切房间、隐藏屋顶或隔离视图只改变观察和拾取，不熄灯、不暂停其他空间。隐藏的物理墙仍参与已实现的遮挡计算；可见性和物理属性分开。房间间的音视频／机构联动继续走既有设备、触发与动作契约。
7. **几何、渲染、执行分别演进。** Rust 场地领域维护有效参数、变换与引用，通用几何运算及导入优先评估成熟库并验证许可证、精度与跨端构建；不自建完整 CAD／BIM。轻量视图和 UE 使用派生几何与稳定身份，几何重建不进入实时输出线程。完整房间模型不下发 ESP32；编译器按执行能力保留必要的指向／校准数据。

## 契约实施前须解决

- 轮廓、上下界、物理构件与连接的权威来源；编辑共享边时的依赖更新、容差和错误恢复；一个修改一次撤销。
- 坐标附着与空间归属分离；改变归属默认保持世界位置，移动几何需显式命令；校准失效、引用删除与重新附着的规则。
- 同平面轮廓相交不等于空间体积冲突；上下层、挑空、夹层不能按二维交叠误判。逻辑功能分区允许交叠，实体房间重叠需诊断。
- 修订、缓存生成版本与旧工程迁移；旧 `StageNode` 不自动推断出房间、墙厚或净高，原对象身份及世界位置须保留。不往无约束扩展字段临时塞整套正式空间语义。
