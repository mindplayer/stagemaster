# PRODUCT-ADR-018：本机预演桥与渲染投影

2026-09-27；PREVIS-001；基线 `ba0cc2f`，主工作区。状态：当前会话审查通过，分步实施；真实 UE 验收未通过前不宣称完成。

独立 `stagemaster-previs` 负责从已校验工程生成中立几何和固定灯表现，不依赖 Tauri、网络或 UE。工程格式保留语义几何；派生三角网格不写回文件。首期通用调光／RGB 调光没有真实光学档案，使用明确的通用视效参数，不能报告真实照度、认证覆盖或摇头灯支持。安装变换／最终射线由 Rust 提供，UE 仅做右手米制到左手厘米的坐标适配。

首期围护墙按空间轮廓线居中分段拉伸，墙角允许实体相交；地板向标高以下、屋顶向净高以上拉伸。该投影用于视觉遮挡，不承诺建筑实体布尔合并／工程量计算，门洞及共享墙另行扩展。原轮廓及厚度始终保留，不将派生网格反写成权威尺寸。

桌面进程持有独立预演状态，使用成熟 HTTP 实现建立回环连接：只监听 127.0.0.1 随机端口，临时随机凭据通过启动环境交给本机 UE；不写入工程、不开放远程控制。拒绝浏览器 Origin 请求，无 CORS 开放。禁用状态不监听；重启／重新连接更换会话身份，旧编辑请求失效。

接口分开：`GET /v1/scene` 读取同一版本的静态几何与灯位；`GET /v1/frame` 读取当前已提交场景或独立播放器状态，帧带场地版本及来源；`POST /v1/placement` 只提交单个灯位安装修改，校验会话／工程 generation，再复用 StageEdit 和一次历史事务。网络端不能执行节目、写磁盘、删对象或获取任意文件。选择与相机只作查看状态。未来移动／远程控制要有独立身份／权限服务，不能直接暴露本桥。

场地版本使用十进制字符串，避免跨语言整数精度差异；保存只更新 generation，不无故使播放失效。三维修改要求既有灯位、同一空间归属，只允许安装位置／底座旋转，不借此创建灯具或变更编排。界面待应用草稿与跨窗口修改不能互相覆盖；桌面接入时显式处理草稿保护和刷新冲突。每次断开立即撤销凭据，即使尚有 HTTP 保活连接也不得再编辑。

UE 原生 HTTP 异步拉取，至多一个在途帧请求、目标约 30 Hz，慢帧直接略过，不积累播放历史。静态数据按版本获取，完整校验后交换；切工程先清空旧几何，不把旧场地与新灯值拼接。协议版本未知、载荷越界或请求失败保持可辨识的断线／过期状态，禁止拖动提交；不伪报已连接或已经到达实灯。

桌面共享会话锁只保护快照／编辑事务，传输和渲染不得持锁；会话忙返回可恢复状态，不把 UI 文件对话框变成网络线程阻塞。播放器保留原 Instant 单调时间；UE 不负责场景推进或渐变。播放计划过期时保持明确版本状态，不将当前场地叠到旧计划上。渲染器关闭、卡顿或崩溃不改变当前工程／保存／编排。

复用依据：[axum](https://docs.rs/axum/0.8.9/axum/)、[UE HTTP 模块](https://dev.epicgames.com/documentation/unreal-engine/API/Runtime/HTTP/FHttpModule)，并核对本机 UE 5.8.3 官方头文件。先完成同版本场地／灯值、权限拒绝、尺寸界限和故障隔离测试，再做实际 UE 画面、灯光响应、镜头／拾取与拖动的原生验收。
