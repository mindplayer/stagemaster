# PRODUCT-ADR-164：根级功能通道的受控选择

状态：2026-10-05 当前实施会话审定，先记录再实现；依据用户“声控这种影响表演效果的通道值，都要屏蔽掉”。

## 证据与复用

根级功能表沿 ADR-060 接受任意功能键，旧 `fixture_unmodeled_axes` 直接输出 30W 自动换色 140／255；ADR-159 和 ADR-161 的保护分别只覆盖内置程序和独立光源。用户政策需要跨入口一致，不能只隐藏一个菜单。参考机制沿用 [ADR-161](PRODUCT-ADR-161-independent-emitter-functions.md) 的功能身份／固定档／受控区间分类和原核心整数映射；不新增另一播放器、厂家识别器或频率推断。

## 决定

- 原生表和禁用区间可完整保留，结构校验仍执行；新增按准确属性和功能键／控制方式判断的选择安全规则，不根据中文名称。默认、场景、预设、读入、编译、手动写入／记录均拒绝禁止选择。
- 根级色盘只执行固定档；图案盘执行固定档或明确 `shake`／`shake-<身份>` 受控区间。固定轮盘保留旧 white／red／dots 等稳定自定义键，但键任一分段为 sound／soundcontrol／soundactivated／auto／automatic／random／reset／macro／program 时禁用；保留资料不等于可执行。
- 根级快门只执行 `open`／`closed` 固定档和 `strobe`／`strobe-<身份>` 受控区间；棱镜只执行 `off`／`on` 固定档。其他未知种类暂禁用，不能通过改名或改为固定档冒充控制宏。需要新受控种类时以具体资料另行扩展，不开放原始值旁路。独立光源更严格的既有键规则和 fixture-program external/0 保持。
- UI 新建根级功能用既有有限种类机制，原生范围留空必须按资料填写；固定轮盘的身份仍可批量生成。旧禁用行标明禁用、不能作为默认／场景／手动候选；非法草稿准确定位、取消不写历史。
- 无新结构、格式能力／封装／执行版本：这是当前安全政策的拒绝修复，不扩展可执行语义。已合法的固定档／频闪保持；旧禁止选择的工程／模式默认明确拒绝，不静默迁移。旧软件不会自动获得本保护，历史裸包也无法逆推出功能，不能宣称已安全审查。
- 有限种类只能限制被诚实分类的资料，不能鉴定厂家原生区间或把伪装声控命名为红色后识别出来。完整档案仍需可信资料／实灯确认；不把软件验证写成光学或物理通过。

## 验证

先用旧根级 automatic 表证明场景和手动绕过，再加端点、默认／预设／禁止读入、整批原子拒绝；固定档及受控频闪／抖动、非零地址、8／16 位、模式交换／包往返保持。更新历史自动通过测试为当前禁止政策测试，保留历史提交与红灯证据，不削弱其余映射断言。UI／离线格式同规则，真实组件与正式包验证文件拒绝、合法编辑／撤销／保存重开。
