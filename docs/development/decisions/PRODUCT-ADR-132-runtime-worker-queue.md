# PRODUCT-ADR-132：设备运行队列与独立有效性发布

状态：accepted，本增量已实现并验证。2026-10-03；基线 `9f63a80`，main；DEVICE-003 第六增量，当前会话单写者。上一回合为用户要求的进度核对，没有产品变更；本回合接续实际接线，不重开 FRAMEWORK-001。

## 决定与范围

沿用原安装队列的单写者、有界槽和独立撤销机制，复用原 Noise Session、SMRT v1 与 operations::Connection；不把慢存储操作放进通信回调，不新建播放器。参考依据为 ADR-128～131 已验证的原工作器、请求回执与承载机制，本增量不改变网络字节、工程文件或播放许可。

1. 通信侧拥有真实 Session 和运行 Gateway；工作侧拥有唯一 ManagedWorker 和运行 Endpoint。外部适配只需各一格命令／完成队列，Command 是已校验的 Offer 或 Request，不携带可反序列化的授权对象。每个命令绑定本地 epoch、单调票号和固定截止时间。
2. Session 公开只读的当前有效截止时间，取固定应用权限和已认证接收保活期限的较早值。查询和发送不延期；通信任务通过 Gateway 发布私有构造的 Live 到独立同步槽，接收／发送／轮询后更新，关闭、错误、取消和 Drop 时清空。工作器每次检查重新读取该槽，不缓存入队权限；检查本地时间、epoch、精确截止点和原 Grant。该槽是可信适配职责，不能来自网络或用户输入。
3. 协商等待／回复发送期限 5 秒，普通工作期限 30 秒，独立保活回复期限 5 秒；重复请求和心跳不能延长工作期限。Gateway 最多一个待处理命令、一个完整回复、一份不可变在途密文和一个保活标记；同一未完成请求的精确重试不再次入队，完成后重试由原 Connection 返回历史结果。
4. Endpoint 在命令前后检查实时有效性并调用原 Connection。空闲 tick 独立推进原 Runtime；撤销仅释放本连接输入权，不能停止自主节目。旧代次命令／完成不能影响新连接；新连接不自动取得控制权。已执行后失联可丢弃回复，不能假称执行回滚。
5. 本增量限定共享运行 Gateway／Endpoint、最小有效期读取 API、真实会话和工作器验收；随后接固件 GATT 与持续调度、桌面操作和物理输出。此软件层不能公告当前板卡已有运行能力。

## 验证出口

真实安全会话到有界队列、原安装包与原播放器的全操作；工作留置时继续保活；精确期限／固定权限／发送不可变；重复与错序；入队后撤销／慢操作后失效；旧完成与新所有者隔离；断线自主推进与真实完整软件帧。相关回归、全工作区严格检查与 Xtensa 编译验证。所有实际证据写入 DEVICE-003，不用测试数量代替物理输出证明。

最终 221 项相关回归（20 项新增）、全工作区严格 Clippy 与 Xtensa application-gatt 检查通过。补充并发约束：Live 时间下界取本连接准入时刻，不能取每次心跳发布时刻，以避免采样与读取之间的新发布误撤销；精确截止仍来自当前真实 Session 和网关期限。实际 TCP／GATT 软件分片已经过真实单格队列和独立线程，证据与未完成项见 [DEVICE-003](../tasks/DEVICE-003-remote-runtime.md#第六增量运行队列与独立有效性)。
