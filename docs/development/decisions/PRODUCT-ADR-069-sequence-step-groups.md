# ADR-069：场景列表的步骤成组整理

状态：采纳；2026-10-01；SEQUENCE-003；基线 `aa37d6e`；当前会话评估。

依据 [M08](../../console-research/M08-cues-tracking.md)、[MA 复制内容与状态](https://help.malighting.com/grandMA3/2.5/HTML/cue_copy.html) 和 [Titan 成组编辑步骤](https://manual.avolites.com/docs/cue-lists/editing-cue-lists/)：吸收范围选择、整体复制／移动、删除确认和内容与最终状态的区分。StageMaster 已把执行顺序与展示编号分开，继续保留这个规则；不照搬以重新编号决定排序，也不新增多个复制模式冒充已实现的跟踪保护。

`SequenceEdit::EditSteps { id, step_ids, operation }` 由独立 sequence_groups 模块执行；操作 copy／move 的 beforeId 为目标步骤 UUID，null 表示列表末尾；remove 不带目标。选中身份非空、唯一、全部属于同一列表，最多 1024 个；核心按原执行顺序归一化，调用方输入顺序不改变相对次序。移动不能以所选步骤为目标；复制生成独立步骤 UUID 与未占用整数编号，不改其他编号。复制后列表最多 1024 步，删除至少保留一步。未知目标、超限、重复身份、失效场景／文字预算等原子拒绝。旧单步接口保持兼容，持久格式无新增字段。

复制保留场景引用、延时／渐变／推进方式、幕场／台词／备注，不复制场景实体、不展开最终灯光。复制／移动／删除会按原有 inherited／isolated 重新编译；继承模式下后续结果可能改变，界面显式提醒。旧运行计划和提示不变，编辑后标为待重新载入，继续既有控制保护。统一文档历史一次撤销整个组。

界面是步骤编排内的“批量整理”模式，保留舞台和执行监看。勾选、可见范围选择、全选筛选结果／清空、隐藏选择数量、可搜索目标、复制／移动／删除确认及返回单步编辑分别明确；选择不执行、不修改。切页保留上下文，换列表清除旧组；成功复制选中新身份；撤销后失效身份剔除，不自动执行步骤。整理不在现场执行视图中出现。复用 ResourcePicker 的搜索和键盘能力，不再制造巨大的原生下拉。

本增量只做结构整理。成组修改时间／脚本、跨列表复制、保持最终效果的复制与跟踪保护、幕场折叠／完整剧本锚点后续；不改变播放器或现场输出。
