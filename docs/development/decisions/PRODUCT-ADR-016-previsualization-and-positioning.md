## 六层边界

1. **用户意图**：直接轴角，或具有坐标系／稳定身份的空间目标。共同指向共享目标，各灯单独求解，不能把相同水平／垂直角复制给全组。目标只定义射线上的一点，不自动决定调焦／变焦／光斑大小。
2. **安装与校准**：工程实例保存底座世界位置、完整三维朝向、关联空间，以及该实例的轴零偏／校准修订。挂装、地装、侧装不是一项水平反向开关。组织归属不等于父子变换；重挂、设备菜单反向／行程更改或换档案使原校准待复核。
3. **运动学**：档案描述底座→水平轴→垂直轴→出光口的局部变换、轴范围、光轴方向。两轴参数独立，但求解必须考虑层级耦合。有限行程保留展开角，不将 540° 灯的角度简单取模 360°。未知／连续旋转／非标准多轴单独声明能力，不能冒充常规两轴。
4. **路径与时间**：空间直线在目标空间插值后逐时求解；轴角渐变在角空间插值。选择可达分支并保持连续，显式翻转、轴锁定、速度／加速度和奇点分别处理。求解失败报告灯号和原因；绝不夹紧后谎称“已指向”。普通拖动只改目的位置，不自动录制路径。
5. **编码与输出**：校验后的标准属性经档案映射至物理角范围和 DMX 功能段／粗细字节。反向只能在定义好的映射层应用一次。编码器操作反向仅改变用户输入增量。复位／归零动作、速度模式、旋转模式有独立契约；不混入轴角渐变。
6. **预演**：消费同一组已求解的关节姿态、出光射线与灯光状态；不自己计算另一套 `lookAt`。UE 坐标／单位转换只在适配器发生。发送设定值与实测反馈分开；未接反馈时不声称灯头已经到位。

## “默认位置”必须拆开

| 中文含义 | 归属／语义 |
| --- | --- |
| 档案默认值 | 未被编排层控制时的属性基础值；不必为 0，也不必为行程中点 |
| 定位位置／定位点亮 | 编程辅助状态，可按属性掩码应用；工程覆盖可逐灯保存，不偷偷改共享档案 |
| 机械零位 | 设备标定的物理基准；不从 DMX 0 或 50% 猜测 |
| 单灯校准偏移 | 实例误差修正，带来源／修订／验证状态；不用于改变节目目标 |
| 停放位置 | 显式收尾行为；黑场不自动移动灯头，也不把全零称为安全位置 |
| 设备复位 | 明确动作，可能有时间要求和灯体自检运动；与回定位位置分开 |

## 位置求解与扩展规则

先支持经过声明的相交正交两轴模型，用成熟向量／四元数库；其正向求解和逆向分支验收作为后续 UE 共享基础。通用几何链与非相交轴不降级为同一解析模型。求解器返回候选、选中展开角、残差和状态，上一时刻角度作为连续性输入，不能在函数内用隐藏全局“上一次”。目标与轴心重合、垂直奇点、行程不可达及参数非法分开处理。

首个解析实现只保证静态几何解；不把“更近的分支”称为已验证的无碰撞／限速轨迹。完整位置编译须另接路径检查；未完成前不允许据此向真实摇头灯输出。未来机构电机复用坐标与时间基础，但其限位、急停、反馈和驱动责任独立，不把摇头灯求解器视作工业运动控制器。
