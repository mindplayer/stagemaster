# PRODUCT-ADR-081：场景列表节目单导出

状态：接受；2026-10-01；当前 Astra 评估实施，REPORT-002。延续 ADR-078 的只读交接责任，补 AUDIT-001 U07／CAP-20 剧本编排交接。

成熟经验：[Titan 19 报表](https://manual.avolites.com/docs/titan-basics/creating-reports/) 将灯具、场景列表、预设等作为可独立输出的交接资料。吸收按资源选择生成节目单；本项目复用既有 Rust csv、文件基线与原子写入、宿主代次和界面草稿队列，不重造 CSV／文件锁，也不把报表当执行格式。

新增 `Document::sequence_report(sequence_id) -> Result<SequenceReport, String>`，对精确文档快照只读生成一个场景列表，按保存的步骤顺序逐行输出。保留步骤号文字（不按号排序）、稳定身份、名称、幕场／触发提示／备注、场景身份／名称、延时、渐变、推进方式和自动等待；还包括工程名称／身份／保存修订／SHA256，列表名称／身份、继承方式与循环设置。脚本是文字提示，不能从台词计算自动启动时间；不伪造一场包含人工等待的总时长或绝对时刻。

固定 22 列格式为 `StageMaster 节目单/1`，中文表头，UTF-8 BOM／逗号／CRLF。时间以秒表示，三位小数精确保留整数毫秒；手动等待为空，自动零等待写 0.000，明确等待从渐变完成后开始。步骤按序号 1…N 输出，不按自定义步骤号排序；缺失脚本文字为空。可变文本沿用公式前缀保护，CSV 字段处理使用现有 csv 库。总量最多 8 MiB，超限拒绝，不写半份资料。未知／已删除列表在打开保存窗前报错。

公共宿主新增 `sequence_report_export(generation, sequenceId)`，TS `ApplicationHost.exportSequenceReport(generation, sequenceId)`；返回 generation、sequenceId、sequenceName、stepCount、path/null、warning/null，名称与数量必须来自 Rust 捕获快照。取消 path=null。新路由与配灯表共用一个报表单请求门及既有工程操作门；捕获时核对 generation、取文档和源路径，再释放会话锁。编码／原生保存窗／写入均不长期持有 Session 锁，不触发预演、不修改历史、保存修订或输出控制权。

存储新增类型化 `SequenceReportFile`，内部提取两类报表共用的路径／基线保护：只允许 .csv，拒绝工程自身、链接、非普通文件、无关文件或其他类型报表；已存在目标必须识别为本类型本版本资料。延续外部更改检测、单写者锁和原子提交。配灯表公开 API、既有内容格式不改。

界面在工程交接资料区增加独立节目单，使用统一可搜索列表选择器；无列表禁用。导出前沿既有 capture 收集有效草稿；无效输入保持原字段定位。复用导出请求／取消／失败／代次过期提示，保持跨页结果，换工程重建；回执显示实际导出的列表，不能随当前选择变成另一个来源。音乐时间线、多轨表单和 PDF／打印版另属后续，不在此伪称完成。

验证：原顺序和文本／毫秒边界、手动／自动零等待、继承／循环、快照一致性／只读；公式／换行、容量、识别与不同报表互不覆盖；目的基线／锁／链接；宿主代次、取消、草稿、跨页与回执来源；原生实际导出并独立用 CSV 解析核对。执行 Rust 全量、fmt／严格检查、UI／类型／桌面及相关格式检查。不操作真实设备。
