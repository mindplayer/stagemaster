# ADR-070：成组修改步骤时间

状态：采纳；2026-10-01；SEQUENCE-004；基线 `75ecd5e`；当前会话评估。

参考 [Titan 19 列表时间编辑](https://manual.avolites.com/docs/cue-lists/cue-list-timing/) 的多项时间选择与明确编辑属性，复用已有延时／渐变／结束后等待机制；本增量不复制分属性时间、出场时间、与上一步同时执行或时间码语义。

在 ADR-069 的 `editSteps` 内新增 operation `timing { patch }`。patch 可选 delayMs、fadeMs、advance；advance 为 `{kind:"manual"}` 或 `{kind:"after",waitMs}`。未给出的字段保持每步原值，空 patch 拒绝；每项时间 0—86400000 整数毫秒。至少一项显式目标，未知／重复步骤或无效时间在改动前拒绝；最后仍通过完整文档校验。一条命令一次历史，不重写名称、编号、场景、提示或顺序。没有新增持久字段／能力，既有运行计划保持独立。

UI 在批量整理属性中增加折叠的“统一时间”。每项独立勾选是否修改，显示共同值或多个值；只有勾选字段被提交，零与不修改必须区分。秒数最多三位小数；自动等待从本步渐变结束计时，手动推进不带等待值。采用单一草稿，冻结原选择身份，接入现有 collect／accept 和原子文档事务，保存、切页、改选及结构操作前统一校验。无效草稿展开并定位字段，取消／Esc 清除；播放停止与预演熄灯保持原独立入口。

此决定只扩展命令，不改变播放器。比例缩放／错峰、分属性时序、现场临时时间覆盖与跨列表时间编辑后续。

验证中确认 serde 对内部标签的无字段单元变体会忽略额外字段；新的手动推进与既有 remove 改用空结构变体，保持正常 JSON 不变并落实未知字段拒绝。非法请求不再靠“字段未使用”而静默成功。
