# ADR-093：片段分割与内部截取保留进入渐变

状态：采纳；2026-10-02；AUDIO-018；基线 `2aba0fd`；当前会话直接审查。

参考 [OpenTimelineIO 时间范围](https://opentimelineio.readthedocs.io/en/latest/tutorials/time-ranges.html) 的素材时间／轨道时间分离。沿用已有整数效果起点、Rust Player、一次编辑事务和主机音频时钟。现有进入渐变是边界静态快照到持续求值的新场景，不是两个动态场景交叉播放；此次不改变这个定义。

单纯把右段剩余渐变时长改短、并从分割处重做插值，会改变动态目标的混合权重及整数取整，不能保证原输出。因此新增可选 `entryFade {durationMs, offsetMs, from:[{fixtureId, attribute, value}]}`。durationMs 为原渐变总长（1–3600000），offsetMs 为当前片段起点在原渐变中的位置（0–3600000）；from 为原边界连续属性的归一化 u16 值，按稳定灯具身份和属性键绑定，绝不保存 DMX 地址／通道值。离散功能仍立即切换，不写进此快照。

该数据表示剪辑时保留的历史起始值，不随前一片段或场景的后续修改重算；当前目标场景和动效继续实时引用。增加灯具时未记录属性使用其档案默认值；删除快照引用的灯具／属性将原子拒绝并给出片段名，须先重新设置此片段渐变。配适改地址／数组重排不影响身份映射。每片段最多 512 项、整轨最多 32768 项；仍受工程 8 MiB／历史预算约束，超限不部分提交。空快照允许全离散灯具。

持久能力 `media.audio-clip-fade@1` 必须显式声明；无字段时旧格式和输出不变，旧版本拒绝新能力。片段 fadeMs 是当前可见的渐变长度，必须等于 min(max(durationMs-offsetMs,0),片段长度)。offsetMs 可超过 durationMs，以便向左恢复历史范围；offsetMs 加片段长度不超过一小时。结构、引用、重复属性、时间、资源预算由 Rust 与独立格式审核共同校验。

Player 的单场景计划增加独立 entry_fade_offset_ms，限定无延时／无自动推进／单步骤，与效果时钟独立。混合仍使用原总长和原起始值；渐变时间为 elapsed + entry offset（饱和处理），效果时间沿用已有 effect offset。设备编码显式拒绝非零渐变偏移，普通包保持字节兼容；本功能仍属于主机音乐编排。

分割：任何内部毫秒均可分割，锁与容量保护不变。在进入渐变内分割时为两段保存同一历史起始快照和原总长；左段原身份，右段新身份，累加效果及渐变偏移，重新计算两段可见 fadeMs。已有快照继续切片，不重复采样；渐变外的旧片段维持旧分割结果。紧邻后段的渐变采样必须读取前段真实末端（前段可能在历史渐变中结束），不能只采样前段目标场景。求值最多当前场景＋前段场景，无递归历史链。

裁切：旧普通片段的 trimLightingClip 继续遵循 ADR-077；已有历史渐变的片段裁切同时调整两种源时间。新增 sliceLightingClip 用于首次完整保留历史过渡的内部截取，先捕获原起始快照再调整范围。向左不能越过任一源零点。普通 put 不允许注入／修改快照；调整 fadeMs 或目标场景意味着显式重新设置渐变，移除历史快照。批量设置渐变和专用 resetLightingClipEntryFade 同样释放快照；复制／移动／启停保留快照；重置效果起点只重置效果，不暗改渐变。

实施先交核心及保护测试，再接正式界面：分割可选全内部范围；属性区展示“保留原渐变”及原总长／已进行时间；完整内部截取与既有边界渐变裁切清晰区分，可显式重新计算渐变。操作仍支持取消、锁定、精确输入、一次撤销、任意定位、保存重开；界面接通前不得宣布用户工作流完成。

验证必须比较原片段与分割／截取后完整逻辑值和 DMX 帧，包括非整周期、多种曲线、渐变首毫秒／末毫秒、重复剪辑、离散属性、后继渐变、移动复制、前段编辑、配适重排、非法格式、总预算及未支持设备包拒绝。主机编译通过不代表硬件支持。
