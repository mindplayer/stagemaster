# PRODUCT-ADR-078：工程快照配灯表导出

状态：接受；2026-10-01；当前 Astra 自行评估。接续 AUDIT-001 工程交接与 CAP-20，由 REPORT-001 实施。

参考 [Titan 报表](https://manual.avolites.com/docs/titan-basics/creating-reports/)：配灯资料面向搭建与交接，独立于节目执行。采用通用 CSV 便于表格软件打开；复用 [Rust csv 1.4.0](https://docs.rs/csv/1.4.0/csv/) 的成熟引号／换行处理，不自写通用 CSV 编码器。完整 MVR／用户灯库交换仍是不同契约，不用报表代替工程文件。

边界：Rust Document 的只读投影生成有界配灯表；桌面宿主捕获工程 generation、提供原生保存选择器；project-store 复用原子提交、文件基线与写锁；TS 仅发起与展示结果。新增 `patch_report_export(generation)` 和 `ApplicationHost.exportPatchReport(generation)`，返回 generation、path/null、fixtureCount、warning/null；取消 path=null。新工程格式、时钟、现场输出、设备与云端均不变。

CSV 首行是固定中文列头，第一列“资料格式”的值固定 StageMaster 配灯表/1。每灯一行，全部灯具按输出域／线路／地址／稳定身份排序；包括工程名称／身份、来源保存修订、精确文档快照 SHA256、灯具身份／名称、厂家／型号／模式／档案修订、输出域／线路／起止地址／通道数、配适状态、空间／桁架归属及世界位置／安装旋转。未配适与未布置灯具保留并显示状态；缺失坐标为空，真实零坐标保留为 0。安装旋转不冒充编排中的摇头轴角。

UTF-8 BOM、逗号、CRLF；可变文本在可能被表格软件识别为公式时前置单引号，数值列保持数值。精确规范由生成器固定列头维护，CSV 为人类交接表，不支持导入回写。载荷总量最多 8 MiB，构建超限返回中文错误，不能部分导出。

原子捕获／并发：导出持有自己的单请求门与既有工程操作门，捕获 generation 后释放 Session 锁，再生成及等待文件选择／写入。工程编辑操作在门后排队，预演取样不长期持有门。过期 generation 在打开选择器前拒绝；不更新文档、历史、保存修订或播放版本。UI 先沿原队列收集有效草稿，无效输入定位原字段，不弹保存窗。取消、失败、成功均释放门。

目的路径只允许 .csv，不得等于当前工程、符号链接或非普通文件；已有文件必须能识别为本版本配灯表，其他 CSV 也拒绝覆盖，防误选资料。复用既有临时文件、基线冲突和同步写入，导出本身不创建工程修订。

验收要求：内容和排序、空值／零值、中文／逗号／引号／换行／公式文本、边界、只读与快照来源；文件类型／链接／源路径／并发变化／原子保存；宿主 generation 与历史；真实原生取消、草稿错误、有效未保存改动、输出可解析及再次打开工程。没有测试表格应用兼容的部分明确保留，不凭扩展名宣称全平台验收。
