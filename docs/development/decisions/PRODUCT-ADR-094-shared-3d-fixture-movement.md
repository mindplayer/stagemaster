# ADR-094：三维共享选灯与原子整组移动

状态：采纳；2026-10-02；STAGE-005；基线 `b9275f8`，当前会话直接审查。

参考 [UE Actor 选择](https://dev.epicgames.com/documentation/unreal-engine/selecting-actors-in-unreal-engine) 的多选／整组变换、[Blender 选择](https://docs.blender.org/manual/en/5.0/scene_layout/object/selecting.html) 的活动对象与选择集合分离。复用既有 Pixel Streaming、场地选择、Rust 编辑队列、世界灯位、锁定和撤销；不引入第二份场地或执行时钟。

平面／目录／三维共用有序灯具身份集合，末项为活动灯；查看模式点击替换，Shift／Command／Ctrl 点击增减，空白普通点击清空。移动模式拖动组内成员保留整组选灯，拖动组外灯改为该灯；加选手势只改选择。聚焦所选覆盖整组包围范围。单灯兼容同一流程。舞台布置之外只允许选灯／查看，不授予安装位置写入权。

三维仅发位移提案 `{generation,version,fixtureIds,deltaMeters}`；1–256 个唯一已布置灯具，XYZ 十进制、有限值、位移绝对值不超过 200000 米，结果仍在原世界范围。Rust 新增 `translatePlacements` 原子命令，以当时已校验世界坐标计算整组位置；空间归属、底座朝向、挂接、灯光参数及场景保持。任一锁定、缺失、超限或过期版本则整组拒绝；零位移不创建内容变化。XYZ 中未移动的轴保持原字符串，移动轴最多六位小数，与既有布置精度一致。挂灯可独立微调，保留既有挂接规则。

选择属于界面，不持久化；提案集合必须与收到提案时的当前布置选择一致，延迟应用仍检查上下文作用域、连接轮次和 2.5 秒时效。Rust 宿主再次检查工程代次／内容版本／预演来源及单次历史。通过只表示工程修改，不触发实际输出。

渲染交互升级为显式 `interactionVersion:2`；状态携带版本，界面只对兼容渲染器开放整组移动，旧渲染器仍可查看但提示需更新。场地／帧协议 2 不变；旧单灯 HTTP 编辑接口保留既有验证，新入口走桌面有序队列。新消息／身份数组有界，不因增加多选接受无限消息。重连、跨页、锁状态／选择变化取消未完成拖动。渲染器同时恢复全部临时灯位，包括拒绝、失焦、Esc、断开、超时及场地版本改变。

原有水平平面拖动扩展到整组；另提供明确的升降模式，保留每灯相对位置与高差。拖动仅是未提交视觉反馈，松手一次事务；不以 TS／UE 计算替代 Rust 坐标变换。完整旋转／缩放、混合构件组、三维框选与持久组属于后续独立能力。

验收必须覆盖实际二维选组到三维、高度不同的多灯同步移动、单灯、加选／减选、整组聚焦、水平／升降、取消与错误恢复、组内任一锁定拒绝、过时提案、一次撤销重做和保存重开。核心测试／UI 消息与作用域／UE 自动化／真实内嵌画面分别验证，不把组件绿灯当三维验收。
