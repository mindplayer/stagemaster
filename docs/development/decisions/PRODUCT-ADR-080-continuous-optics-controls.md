# PRODUCT-ADR-080：连续镜头与光圈控制

状态：接受。当前会话评估实施；基线 `5d80c07`，任务 FIXTURE-005。

## 依据与取舍

[MA3 摇头灯控制](https://help.malighting.com/grandMA3/2.4/HTML/qsg_control_moving.html) 将调焦、变焦、光圈作为独立属性；[GDTF 属性定义](https://gdtf-development.com/help/developers/gdtf_1_2/annex/index.html) 将物理单位与控制属性区分。复用本项目已有 normalized 整数值／粗细通道、场景、预设和连续渐变机制，不为镜头再建一个播放器。

本次支持 `zoom` 变焦、`focus` 调焦、`iris` 光圈：每种最多一组 8／16 位全范围线性控制通道，允许粗细任意顺序，默认值明确填写。控制百分比表示说明书通道范围内的控制位置，**不是**光束角、焦距或光圈开度的物理百分比；不能假定 0 为关闭或窄束。带保留段／宏／反向非线性或关联通道的档案仍需后续映射模型，不由本项自动推断。

## 契约与兼容

- ProfileDefinition 原有 String attribute 支持集合扩展；新增属性是 normalized／LTP，要求无 functions 表。仍须已有调光或完整 RGB 基础组合，位置轴成对规则不变。原位修改使用中模式仍拒绝。
- JSON 当前 lighting.basic 已支持任意完整映射的 normalized 属性，核心执行与包为有界通用值数组；本次不改变持久结构、值类型、执行语义、包版本或授予新输出权限。旧工程保持逐值一致；旧程序可执行已有 normalized 数据但其模式编辑器可能拒绝编辑，旧模式文件读取会明确拒绝新组合。
- 静态场景、释放、预设、列表渐变、音频段落渐变、总控隔离及模式文件往返贯通；动态效果属性白名单保持已有亮度／RGB／物理双轴，镜头动态曲线另行评估后扩展。
- 同属性换模式沿用准确属性集合与值类型、轴模型比较；跨物理标定的等效换灯没有保证，现有控制百分比不当作物理量。
- 三维仅知道通道值，没有厂商物理光学模型。保留灯位／姿态，隐藏相关光束；投影可选说明字段 `lightSimulation` 增加 `unmodeled-optics`，UE 既有解析器忽略说明字段，真实强度仍由 Rust frame=0 阻止错误效果。旧 `unmodeled-functions` 保留；桌面说明涵盖新属性。无新增协议版本、三维光学真实性或实灯验证声明。

## 实施与出口

Rust 独立 fixture_optics 模块维护支持集合／全范围校验及中文名称；UI 独立属性目录／建档区共用线性字段，保持草稿取消和错误定位，不堆入入口。核心新增验证须证明默认、场景／预设／释放、编码与渐变／总控、文件复制、非法功能表和通道冲突的原子拒绝。预演证明整个场地仍能投影且不错误亮灯，真实桌面验证建档／配灯／参数／取消／历史／保存重开。完成后依据测量决定物理模型扩展，未前置完整 GDTF。
