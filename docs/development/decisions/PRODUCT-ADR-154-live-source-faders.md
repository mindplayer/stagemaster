# ADR-154：连续电平手势与权威执行回执

状态：采纳；2026-10-04；EXEC-010，基线 `01659c0`。当前会话评估后实施，无新工程格式、传输协议或 Rust 播放语义。

## 依据与范围

复用 [M09](../../console-research/M09-playback-mixing.md)、[M19](../../console-research/M19-live-show.md) 的控制范围与启停／释放分离。核对 [Avolites Titan 19 播放控制](https://manual.avolites.com/docs/running-the-show/playback-controls/)：推子、精确调整及零值指示各有职责。本项目只操作既有来源亮度 Level，不改变位置／颜色，不自动启停，不把零值当归还属性。音频的定位／音量不是灯光电平。

## 调度与生命周期

一个后台面板同一时间只接受一项连续电平手势。手势冻结 host、layout、session、source 身份，保留一个最新目标，最多一个在途请求；控制命令间隔至少 50 ms，不为每个指针事件排队。指针／键盘立即显示目标值；实际电平仅来自后台观察。

复用原 ExecutionPort／控制权／修订／操作序号。每次发送前读取当前快照，等待维护类待确认操作结束；发送后匹配同一显式回执与实际电平，才可继续最新目标。松手提交最终目标，最终确认后释放手势。拒绝／未知结果／5 秒确认期限结束均停止继续发送，不自动重试控制命令。单次传输等待仍受原宿主期限管理。

Esc、指针取消、窗口失焦、页面隐藏、来源被筛选隐藏、失联、控制权或后台身份变化，丢弃未发送目标。已经进入后台的值不回滚；提示核对实际电平。旧在途返回只能完成自己的清理，不能启动下一命令或更新另一手势。未结束的传输期间不启动新手势。

手势期间锁住其他控制操作及手动录入场景，当前推子仍能合并输入。精确输入独立保存草稿；有该来源数值草稿时先应用或取消再拖动，避免无提示丢失。手势不写工程、不加入编辑撤销；电平归零仍保持节目状态和手动属性。

同一推子可在最终回执确认中继续接纳新位置；旧请求仍完整确认，再发送合并后的最新值，不形成第二手势。键盘／指针输入适配与控制器分离：保留浏览器原生 range 拖动，不在外层抢占内部指针捕获；松手在窗口范围收尾，随后设置键盘焦点。取消后的本次按住输入不自动重新开始。操作提示保持固定占位，避免反馈使滑轨移动。

## 审查与验收

控制器不依赖 DOM／React，生命周期 Hook 不承担协议解释，组件只处理输入和展示。复用现有后端，不新增 UI 播放器。单飞／最新值／零值、晚到回复、所有失效边界及实际后台回执均验证；组件和原生结果记入 EXEC-010。物理设备时延、多指同时操作、硬件推子软接管不在本次验证范围。

结果：368 UI、类型／格式／桌面打包通过；原生滑轨内外拖动、键盘、手动零值保留、编辑器退出重开只读恢复通过。首次原生暴露的焦点取消与外层捕获阻止拖动均在原程序复验修正。见 [EXEC-010](../tasks/EXEC-010-live-source-faders.md)。
