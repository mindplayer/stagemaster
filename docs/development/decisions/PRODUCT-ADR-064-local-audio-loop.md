# ADR-064：局部循环试听的原生时钟与有界缓存

状态：接受，已实施并验证；AUDIO-005，基线 `c996b77`。

参考 [QLab Audio Cues](https://qlab.app/docs/v5/audio/audio-cues/) 的区段循环和 [Devamp](https://qlab.app/docs/v5/other-cues/devamp-cues/) 的边界退出；当前实现只针对本机排练循环，不增加正式演出循环／自动退出指令。复用现有 Rodio 解码、音频输出和软件消费游标。已检查所用 Rodio 0.22.2 的 repeat_infinite 会缓存输入，不能直接对整曲无限缓存。

循环状态属于原生试听会话，不进工程 JSON、撤销栈或设备包。界面指定裁切后相对起止 [startMs,endMs)，100 ms–60 秒，最多 64 MiB float PCM，单／双声道；提前解码整个限定区间并明确拒绝超过预算、数据不完整及格式异常。循环源仅重复共享不可变样本，无每圈磁盘 I/O／解码／增长缓存。更换循环的短时峰值包括旧、新两份预算，不称全进程 64 MiB。

配置只允许暂停时；预解码在工程锁外进行，采集代次＋传输修订，回写前再次检查，过时结果不覆盖新的播放意图或工程。准备失败不改变旧范围或位置。设置范围保留范围内位置，否则置到起点；播放从当前位置连续循环；暂停保留游标；停止回到循环起点；定位到范围外自动退出循环并执行定位。切工程／音乐／裁切／原生播放所有权清空时释放循环；编辑灯光卡点保留。

Position 返回实际 loopRange；播放位置从 Player 的消费时长按实际样本帧数取模，既有灯光编译按此原生位置确定性求值，页面定时器不触发循环。音频回环的非零波形切口可能产生点击声，不自动淡化改变作品；仍是未校准 DAC／蓝牙延迟的本机排练，不宣称跨设备同步或采样级舞台同步。

UI：时间线工具区独立可折叠循环区，精确起止、用当前播放头、用所选灯光段落；明确临时性质、范围、播放时禁改与外部定位退出。波形显示同一范围，三维共享控制显示循环状态。错误字段定位、Esc 取消、跨页保持必须验证。

验证：490 Rust、151 UI、类型／fmt／严格检查／桌面，原生精确选段／回环／暂停停止／取消／跨页／重启及内嵌三维通过，详见 [AUDIO-005](../tasks/AUDIO-005-local-loop-preview.md)。
