# PRODUCT-ADR-050：应用会话准入与安装工作器

日期：2026-09-29；DEVICE-002；基线 `9fd381a`，主工作区，当前 Astra 单一负责人。
状态：接受以下边界，实施与验收结果另记；不改变父任务范围。

## 判断与依据

云端保存设备身份、归属及权限，GATT 负责本地字节连接。采用 [Noise 的应用责任与通道绑定](https://noiseprotocol.org/noise.html#application-responsibilities)及 [RFC 8747 的密钥持有证明](https://www.rfc-editor.org/rfc/rfc8747.html)分层原则：认证公钥与授予权限是两件事，凭据必须绑定实际证明持有的公钥，不能把可复制的身份字段当授权。本增量不实现 CWT／云端签名格式，不把开发准入宣传为云端认领。

## 契约

- `device-auth::application` 与旧系统绑定 Authority 独立，以可选特性启用。开发许可来自受控本地配置，绑定设备编号、控制端公钥、主体编号、非零修订号及固定有效时长；只允许安装，不赋予播放、物理输出、设备认领或所有权转移。没有公共网络解码器，也没有全机通用密钥。
- 许可最多覆盖本次连接的 10 分钟，从准入计时；期限不因保活、请求或重试延长。它是开发连接权限，不是用户文件的 24 小时离线播放许可。未来云端验证器必须核验签发者、受众、持有者、范围、期限与撤销状态后再进入同一业务边界；不能仅换一个来源标签。
- 授权会话拥有已相互确认的 Noise Channel，每次收发、权限查询和轮询重新核对安全租约及许可期限；错误／撤销永久关闭。旧证明副本无法替代当前状态。上下文绑定设备、启动与本次连接，主体编号独立于 MAC、Apple peer UUID、公钥轮换和系统配对记录。
- `install-worker` 的可选安全适配将授权会话连接到现有 Endpoint。只在准入成功后产生 Open；只有工作器成功打开后，才通过加密 Message 发布新版本就绪回执。请求、完成和发送均重检期限，物理适配仍须同步 LIVE_EPOCH，断开／取消清除它，工作器在 I/O 前后独立检查。
- 加密 Message 承载一条完整 SMP 安装消息（最多 1280 B）；MTU 分片由现有安全记录层承担。控制保活与业务响应共用同一顺序发送者，发送中的密文固定、不得重复加密推进 nonce；额外保活只容许一个待回复位置。失败不可降级到公开诊断。
- 新就绪回执 `SMAP` v1 与旧 `SMAS` LESC 回执严格区分，包含本次设备／启动／诊断／加密会话、主体／权限修订、安装范围和真实通信预算。它只有在当前已验证的加密通道中才有意义，解码本身不产生设备权限；不得作为安装提交成功回执。

## 交付边界

先用真实 Noise 双端和现有安装器组合检查未经授权、错误设备／公钥／上下文、过期、撤销、旧完成、保活与回执时序，再接固件及桌面。开发凭据生产配置、正式云端签发、防回退和 24 小时文件许可保持独立任务。实际板卡、NOR 并发和原生桌面未验收前不得宣称无线安装完成；不新增 RS485 输出。
