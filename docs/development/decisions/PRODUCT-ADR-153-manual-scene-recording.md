# ADR-153：从后台手动层录入场景

2026-10-04；EXEC-009；批准实施。沿用 M06／M08 中 MA 的记录来源与范围、Titan 按通道记录机制。只持有的属性可录入，选择不等于持有，零值不等于释放。当前来源为电平前手动层；完整输出记录、更新既有场景的合并／替换策略另行实现，不假装已经提供。

由共享 Rust 工程模块从一份权威手动观察生成不可变记录，按原灯具定义把功能原始值还原为可精确重编码的语义选择。新场景仅含记录中的属性，不借用 AddScene 自动填充全部默认值。全部持有／所选灯具范围明确，空记录拒绝，最大 512 项。原节目、动态效果、其他来源、电平和未应用输入不混入。

桌面宿主刷新真实执行客户端，拒绝错误后台／故障／未确认操作；读取后台固定工程并核对完整内容摘要与执行布局身份。记录绑定来源工程 ID、所涉灯具定义／校准／配适及编辑代次。后台观察只读即可记录，无须抢占控制权。当前工程可已有新的场景或元数据，但所涉灯具语义变化须拒绝。

宿主仅保存一份有时限、不持久化的记录，以随机票据供界面审阅。界面展示采集范围及冻结值，确认时通过原工程操作队列提交名称和票据；不接受界面自己构造的“真实后台值”。捕获后现场继续变化不改记录；取消、隐藏和旧异步结果清理票据，工程代次变化禁止提交。提交失败保留记录供改名重试，成功消费票据并以一次历史修改创建新场景。原手动层保持，清除仍由独立操作决定。

不新增工程持久化字段、实时命令或设备接口。测试须覆盖功能量化精确往返、零／稀疏记录、错误目标／重复／超限、原工程及灯具身份、票据替换／取消／重复提交、失败原子性与撤销重做，以及正式组件和原生保存重开。

原生验收补充：发现客户端自动续约可能在手动操作完成后的观察中覆盖其回执，界面因此一直等待旧序号。批准在原客户端分离协议当前回执与最近显式操作回执；自动续约仍使用同一序号流、未决门与校验，不新增重试或第二控制会话。界面 `View.record` 稳定代表最近显式操作，直到下一次显式操作或重新连接；观察状态仍取最新权威状态。以真实后台跨续约验收及原手动／媒体回归验证。
