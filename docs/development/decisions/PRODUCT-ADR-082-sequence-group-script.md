# ADR-082：成组修改剧本提示

状态：采纳；2026-10-01；SEQUENCE-005；基线 `dfaa86d`；当前会话评估。

沿用 [ADR-062](PRODUCT-ADR-062-sequence-script-prompts.md) 的成熟步骤备注／待执行提示机制和 [ADR-070](PRODUCT-ADR-070-sequence-group-timing.md) 的成组稀疏修改，提供整幕排练整理，不新增调度或剧本解释器。

在 `editSteps` operation 增加 `script { patch }`，patch 三个可选纯文本字段 section／trigger／notes。省略保留每一步原值，空字符串明确清除该字段，null、未知字段、空 patch 拒绝。仍以稳定步骤身份选择，重复／未知／空选择拒绝；每字段复用既有字符数／控制字符规则，每列表 UTF-8 总量最多 64 KiB。整个编辑原子提交／撤销，最终所有字段全空时移除 script 并同步能力声明。既有 JSON 格式及能力版本不变，因为仅新增宿主编辑命令。

UI 在步骤批量整理中增加“统一剧本提示”，字段分别选择“保留原值／统一填写／清空”。共同值和多个值区分，统一填写不能以未填写混合值意外清空，清空必须显式选模式；保留项不提交，台词默认保留。时间与剧本共用批量属性收集／接受边界，待修改状态取两者并集，不允许取消其中一项掩盖另一项；应用按钮明确作用于当前批量修改，保存／切页／改变选择前统一收集。选中身份在草稿建立时固定，过滤隐藏选择仍计入，错误展开并聚焦、失败保留、取消／一次历史和保存重开必须验证。

运行提示仍来自载入版本，编辑不会替换已运行快照；DMX／设备包不含文本。完整剧本文档锚点、幕场调度、备注追加或复杂文本替换不在此次范围。
