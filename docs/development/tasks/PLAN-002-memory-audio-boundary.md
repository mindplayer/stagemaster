# PLAN-002：板载内存利用与宿主音频边界

日期：2026-09-29；基线 `5e7f204`；主工作区；当前 Astra 单一负责人。
状态：本轮方向审查／文档更新完成；下面的硬件和媒体实施增量尚未开始。

## 本轮结果

- 按用户新需求记录 [ADR-052](../decisions/PRODUCT-ADR-052-memory-and-host-audio-sync.md)：近期电脑／手机基础放音，未来有存储与输出能力的盒子本地放音；音频执行端可选、资源按目标部署、独立 ESP32 灯光、分层内存、可观测时钟同步与路由延迟。K11 具体能力未核验。
- 更新产品入口、媒体边界、能力表、板卡资料与执行顺序；复用现有媒体时间／播放代次草案，未修改公共协议、JSON 或目标包限额。
- 核对当前代码仅建立 128 KiB 内部堆，未启用 PSRAM；默认板卡资料对应 512 KB SRAM＋8 MB PSRAM＋16 MB Flash。PSRAM 实物容量／性能尚未验证，安装峰值 48,592 B 沿用 DEVICE-002 实测，不当作播放组合负载证据。
- 未启动硬件连接、刷机、音箱放音或真实 DMX；现有工程、应用与 UE 保持。
