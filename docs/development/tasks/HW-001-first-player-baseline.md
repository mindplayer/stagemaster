把“首版交付一个软件和一个硬件”落实为当前产品任务，核对已有板卡的 RS485／USB／隔离接口，记录模块边界和实现顺序。保留此前无电脑本地选场景的要求，修正 README 与执行计划中“盒子全部留到后续”的过时优先级。

## 验收与完成记录

- 核对官方产品资料，并渲染阅读原理图：确认 TX／RX／EN 为 GPIO17／18／21、USB GPIO19／20、隔离收发路径；发现外部 RS485 端子没有引出隔离侧公共地。
