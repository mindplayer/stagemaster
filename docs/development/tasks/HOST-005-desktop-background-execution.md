# HOST-005：桌面后台执行入口

软件增量完成。基线 `142ae02`，结果为本次 `feat(desktop): control independent background execution` 提交；main 主工作区，当前会话单写者。依据 [ADR-109](../decisions/PRODUCT-ADR-109-desktop-background-execution.md) 和[实际契约](../../module-api/desktop-background-execution.md)，持续目标保持 active。

## 实现与审查

独立 Rust 客户端接 v2 目录、控制会话和回执；Tauri 管理不可变快照、随包后台程序及运行记录；执行区提供明确的编辑预演／后台执行入口。多来源载入不自动播放，重开只读观察，取得控制权后独立执行／暂停／继续／下一步／停止及精确电平。控制与进程生命周期分离，桌面退出不停止后台。未更改工程／设备包格式，无第三方依赖升级。

响应丢失只查询原回执，不自动重发；确认状态不能被较旧观察覆盖。进程结束必须有 Child 终态或实际取得生命周期锁，HTTP 失联不推断退出。原生验收修复新增组件包装破坏旧网格的问题，后台使用完整执行区，编辑预演保留原位置；只读／故障／待确认时禁止修改。启动服务、文件、进程、客户端协议及界面按职责拆分；本次新增手写文件均低于 400 行，修改的 SequenceWorkspace 为既有工作区且仍低于 500 行，未扩充为通用后台服务。

- 全工作区严格 Clippy、最终 fmt 检查通过，分别见 `logs/host-005-clippy-verified.log`、`logs/host-005-fmt-final.log`。早先误与测试重叠启动的 Clippy 已中断，不计通过；随后串行修复并重新取得完整成功结果。
- 界面原有 307 项测试、最终 TypeScript 检查通过，见 `logs/host-005-ui-tests.log`、`logs/host-005-ui-check-final.log`。隔离组件验证检索／选择载入、首次只读、显式控制、精确电平、越界禁用、重执行取消和重连不自动播放。
- 原生隔离实例使用项目内测试工程；第一次退出前后启动身份相同，循环计数从 2263 增至 3032，场景列表仍运行。退出再打开回到只读，明确取得控制权后可暂停原列表并启动另一场景；再次打开仍显示原列表暂停与另一场景运行。证据为 `logs/host-005-native-before-exit.json`、`logs/host-005-native-after-exit.json` 和 `logs/host-005-native-reconnect.png`。
- 最后从原生界面明确关闭测试后台，界面回到尚未载入；核对原后台 PID 已结束、当前运行指针已移除，再正常退出验收应用。仅使用隔离调试实例，未操作用户已有工程、窗口、`output/` 或真实设备。
- 独立验收应用及默认名称桌面包构建通过；最终标准构建日志为 `logs/host-005-desktop-build-final.log`。随包后台与本次构建二进制一致，未开启用户常用应用。

## 未完成与接续

目前单域、单路软件输出；物理驱动、多时钟、后台只读专业预演与云端／U 盘交付尚未接通。完整手动编程器、后台总控和进度显示另行迭代；编辑预演保留既有音频／草稿语义，不宣称桌面全部迁移。

创建当前记录与 OS 启动之间若异常退出，且后台还未留下生命周期证据，当前保守保留记录并拒绝自动重启；专门恢复工具后续补充。已结束运行资料目前保留作诊断，自动数量上限后续安排。客户端遇到始终无法确认的请求会阻止后续修改，用户可显式重连，再单独取得控制权。

下一框架增量先把后台权威观察接到既有预演投影，验证渲染关闭／重开不改变执行和控制权；随后推进两个独立时间域的协调与云端／U 盘共用交付路径。物理输出按独立实测和授权处理，不回到局部 UI 全面细化，也不把本工单完成当整轮目标结束。
