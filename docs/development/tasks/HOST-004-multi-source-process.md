# HOST-004：多来源独立执行进程

软件增量完成；结果为本次 `feat(runtime): serve prepared source groups in local process` 提交；基线 `536f0be`，main，当前会话单写者；上一轮 HOST-003 已提交，分类为进展。依据 [ADR-108](../decisions/PRODUCT-ADR-108-multi-source-process-entry.md)，泛化已有应用适配，接入真实固定来源组。

范围：`apps/execution-host` 的准备／应用映射／命令及状态投影、复用会话与服务；工程输出的手动语义转换；对应测试、契约与状态。保留原程序调用与接入保护，不新增第三方依赖，不操作用户 `output/`、工程、窗口或设备。按模块职责拆小文件，以实际独立进程验收，不以线程测试代替进程隔离。

审查补充涉及 `stagemaster-runtime-host` 的接纳期限：保留 Duration 调用，同时接受同进程原始 Instant，避免应用映射与调度之间重新开始期限；见 ADR-108 的实施审查决定。

## 已实现

- 同一个独立程序通过启动档位选用单节目 v1 或多来源 v2；Application 只做准备上下文、操作和投影，原会话注册表、命令工作器、服务和后台调度继续复用。参考既有 [M09](../../console-research/M09-playback-mixing.md) 的多来源控制与 [M18](../../console-research/M18-sessions-backup.md) 的执行连续性边界，本项不照搬专有网络协议。
- 有界来源清单、唯一来源身份、真实场景／列表／手动层、准备目录及步骤 ID 映射；运行不依赖源文件。明确发布协议、能力、启动和布局身份。
- 场景／列表独立操作、普通亮度电平、灯具属性及功能语义手动修改；整批校验后才进入后台，错误不部分生效。复用原 FunctionTable 和已准备输出绑定，未在服务内重写灯具通道规则。
- Deadline 兼容旧 Duration，并支持直接转发进程内原始 Instant；原接纳预算和派发前过期判断保持。无新第三方依赖、设备格式或工程持久格式变化。

## 验证记录

已完成真实独立执行服务＋独立控制客户端验证：两个来源同时运行，客户端被杀、准备文件删除后同一启动身份／布局／修订下效果继续；明确接管后旧会话拒绝，暂停／停止只影响目标来源。其他用例覆盖手动色盘覆盖／归还、槽位和 16 位精度、重复回执、丢失 HTTP 回应、非法来源／步骤／类型／功能／重复批量的原子拒绝、来源清单版本／数量／唯一性／容量和接入权限。保留旧单节目回归。

新增 7 项测试（含 1 个独立控制客户端测试入口）。初次专项 277 项通过，全工作区 848 项通过、0 失败、1 项原有忽略，2 个文档示例通过。审查随后补绝对期限转发，最终宿主／独立程序 33 项专项及 2 个文档示例通过；此最后增量未重复全工作区测试，不把早先 848 项报告当成包含新增期限用例。

## 剩余边界与接续

当前仅 Mac 软件进程，单个逻辑输出域；不是物理输出或生产商业安全验收。桌面尚未迁移，下一项接入已准备目录、控制会话与回执，明确临时编辑预演和后台现场节目的生命周期；不会因关闭编辑窗口隐式停止后台。多时钟、专业渲染隔离、云端／U 盘统一交付仍按框架主线推进。
