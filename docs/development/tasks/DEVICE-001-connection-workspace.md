## 目标

把已通过实板验证的诊断 GATT 协议接入正式应用，提供搜索、选择、连接、取消、断开、保活和真实状态。设备会话独立于工程和页面，保留编辑内容，不把诊断会话当设备授权或播放控制。继承用户持续 goal 授权；本轮仅诊断 BLE，不刷机、不写设备节目存储、不输出 DMX。原桌面 PID 14610 与 UE PID 14928 保持。

## 实施与验收

1. 按 ADR-034 独立主机协议、原生 BLE 适配和应用连接服务；时间、取消、陈旧操作与资源清理有明确归属。
2. 正式中文组件：无需工程也能打开；搜索／筛选、精确状态、空结果、错误恢复、取消、重新搜索／连接和跨页面保持。
3. 不仅接受 ATT 写成功：验证对应应用回执和有效诊断，心跳失败不得继续显示在线；暂停／唤醒过期重新连接。
4. 有界列表、超时、单连接、旧操作隔离、协议坏包与设备错误、取消与清理测试；Mac 原生真实 GATT 与 UI 验收。

6. Rust／UI 相关测试、类型／格式／严格 Clippy、真实桌面构建、记录证据与未完成边界后提交。
