# MEMORY-001：分层内存与存储读取保护

日期：2026-09-29；基线 `cebf87f`；主工作区；Astra 单一负责人；本增量完成，结果为本次 `feat(memory): isolate PSRAM cache and validate board storage` 提交。

用户要求先优化存储／内存，随后实现类似剪映的音频波形卡点编排（不是设备页占位）。本任务先完成设备部分，音频另按工程领域／宿主媒体／界面组件实施。

## 边界与决定

依 ADR-052，复用已锁定 esp-hal 1.2.2 的 PSRAM 初始化及 esp-rtos 栈保护；启用独立的 PSRAM 只读缓存，不把外部内存加入默认动态堆，不迁移蓝牙、原子变量或栈。缓存封装既有 NOR 接口、无动态分配、所有权归存储工作器；Flash 操作只接收内部临时缓冲。所有擦写先使缓存失效，写后核验必须实际读取 Flash。包／分区格式、参考容量和安装维护门保持兼容。

PSRAM 按实际探测初始化并自检，缺失或失败回退到既有无缓存路径；启动与周期资源报告区分容量、缓存占用与内部堆。已有栈采样仍如实标注，启用成熟 RTOS 的软件栈哨兵，不伪造完整高水位。界面总量从真实诊断求得，不写死 128 KiB。

## 写入范围与验收

- `crates/stagemaster-nor-store`：独立缓存适配及覆盖跨块、冲突、错误／部分写、擦除失效、越界／无缓存的测试。
- `apps/esp32-player`：板级内存初始化／自检、工作器接线、诊断；`tools/hardware` 按需补测量。
- `apps/ui-prototype`：修正真实内存显示。
- 构建／严格检查／工作区测试；受控实板 PSRAM 容量／启动／内存、既有节目读取与 GATT 安装／取消／重连测试。输出保持禁用，不改用户工程／UE、密钥／授权或节目分区。

尚无“永不耗尽内存”的保证；长期组合压力、完整栈高水位与未来播放器负载分别记录，不能以启用 PSRAM 自动宣告完成。

## 实际验收

- 425 项 Rust 工作区测试（含安装 application 特性）、全工作区严格 Clippy 通过；NOR 定向 17 项含新增 4 项缓存故障测试通过。固件严格检查、格式化和完整 release 构建通过；镜像 699,712 B，已有 RWX 链接告警保留。
- 已刷入当前板卡，PSRAM 实测 8,388,608 B，整区两种地址相关位型读写自检通过。专用缓存预留 2,097,152 B，其余 6,291,456 B 未纳入动态堆。内部堆总量仍为 128 KiB；空闲稳定占用 41,132 B，本轮峰值 48,548 B。工作器栈单点采样最高 16,045 / 32,768 B，不是完整高水位。
- 原生应用凭据／加密 GATT 的取消、断线恢复、完整安装和损坏包拒绝全部通过；最后 B 第 18 代 28 场景／110,772 B，A 第 17 代保留。缓存失效单测验证失败的部分写／擦也不能读到旧缓存。真实写入校验通过；没有物理断电测试。GPIO21 禁用、没有真实 DMX 输出。
- 日志：`logs/memory-001-{nor-tests,nor-clippy,workspace-tests,workspace-clippy,firmware-check-final,firmware-build-final,flash,board,cancel,resume,install,corrupt}.log`。首次默认 Cargo 缓存缺少 axum，改用项目既定缓存后通过；首次直接执行非可执行脚本被拒绝，改用 bash；首次固件 Clippy 发现无 Drop 类型的 forget，移除后原检查通过，没有屏蔽告警。
- 用户正在使用连接验收窗口且有未保存场地编辑，未关闭、重载或覆盖该窗口；原正式应用与 UE 未动。128 KiB 只是内部默认堆，不能等同板卡总运行内存；本轮不提高节目上限，不声称全局永不 OOM、长时间压力或完整播放器实板验收完成。

成熟实现依据：锁定的 esp-hal 1.2.2 `Psram`、esp-rtos 的软件栈哨兵／硬件栈保护和 embedded-storage NOR 契约；自研部分仅为项目需要的有界缓存及失效策略。音频卡点另立 AUDIO-001，明确区别于硬件音频输出或 ESP32 存音频。
