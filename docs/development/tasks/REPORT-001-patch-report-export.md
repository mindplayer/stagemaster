# REPORT-001：配灯表导出

状态：完成；基线 `469dd1e`；结果为本次 `feat(reports): export versioned fixture patch handoffs` 提交；当前主工作区单一写入，用户 output 不动。依据 [ADR-078](../decisions/PRODUCT-ADR-078-patch-report-export.md)。

目标：工程页提供真实“导出配灯表（CSV）”，把全工程灯具模式／地址／世界安装位置与来源快照交接给搭建人员，保留未配适／未布置灯具。先复用 Titan 的报告职责与 Rust csv 库，再实现本项目字段，不扩张到 MVR 导入或设备控制。

写入范围：project 只读报表与测试、project-store 独立报表保存适配与测试、desktop 宿主服务／命令注册、UI host／独立交接组件、工单／模块契约／能力导航。Workbench 已超过 500 行，本次抽出涉及的工程资料区域，保持现有播放包／检查生命周期与公共行为不变，不继续内联 UI。

出口：格式／内容／边界、保存保护、generation／草稿、取消错误／无历史污染／原生实际导出；Rust 全量／fmt／严格检查，UI／类型／桌面，必要文档检查。按 ADR 记录验证边界，不操作 UE、声卡或设备。


实现：Rust 只读配灯投影拆为报表入口（63 行）、关联行（135 行）、有界 CSV 编码（90 行内），采用 csv 1.4.0；store 类型化保存、桌面单请求门／快照、独立 TS 导出区及工程资料组合组件。Workbench 由 1492 降至 1470 行，本次只抽所涉资料职责，其他工作台协调职责留后续，未增加内联业务。公共契约见[配灯表接口](../../module-api/patch-report.md)。

验证：最终全工作区 582 Rust、227 UI、类型、fmt、严格 Clippy、相关 Prettier、桌面打包均通过。新增核心 5＋有界缓冲 1、store 3、桌面快照 1；验证空工程／未配适／缺坐标与真实零值、地址数值排序、世界空间／支撑体、中文逗号引号换行／公式文本、8 MiB 拒绝且不部分追加、目的链接／源文档／其他 CSV／并发更改／写锁以及 generation、工程／已载入预演不变。日志在 `logs/REPORT-001/`。
