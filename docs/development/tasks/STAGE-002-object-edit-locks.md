## 实现与审查

Rust 独立 `stage_locks`、可选工程数据／能力、原子命令／每个子操作保护；灯位还保护挂接，围护还保护依赖几何。界面目录和单／多选属性、二维手势／微调、三维移动限制共用锁状态；过时提案在换选／锁定后失效。锁不改变灯光语义，复制身份独立，显式解锁事务可正常编辑。

创建／复制／删除及对话框、挂灯流程、安装位置字段和高级轮廓分别抽取；StageWorkspace 711→469 行，StageInspector 544→431 行。StageCanvas 488 行保留协调镜头及手势，坐标微调和锁判断已独立；评估后未按行数机械拆分。新模块最长 225 行。额外修复窄目录锁图标与文字溢出，面积摘要按最多三位小数显示，精确编辑值不截断。
