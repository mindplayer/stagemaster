# EFFECT-003：相对位置动态效果

状态：完成。基线 `f7f24ec`；主工作区／当前会话；接续 AUDIT-001 摇头动态效果缺口。

按 ADR-058，增加水平摆动、垂直摆动、双轴圆形运动。每台灯以执行步骤解析后的静态位置为中心；两轴幅度、中心偏移和相位独立，灯间展开沿用保存的有序灯具。Rust 编译为已有有界关键帧计划，界面只维护编辑参数。界面共用非模态效果属性、草稿事务、应用／预演、复制、撤销和搜索灯序。

文件范围：工程效果／位置适配与编译、工程 JSON schema／契约、独立运动效果编辑组件及模板，相关测试。不改硬件固件、播放包协议或 UE 时间权威，不连接真实灯具。新增职责拆到独立文件，原有效果编译从编辑模块抽离；不扩展 Workbench。

验证：物理角度与反向轴、8／16 位编码、相对不同基值、预设／跟踪／释放、灯序相位、禁用／冲突／错误原子性、机械行程、能力声明和预算、包与主机逐帧一致；UI 参数／草稿／取消、应用撤销、保存重开、唯一三维实际播放。全量 Rust／UI、严格检查、桌面构建和格式验证后记录实测。

范围：关节角度空间中的循环运动，圆形投到舞台上未必为圆；不承诺世界坐标轨迹、机械速度／加速度限制或碰撞保护。现有单场景／列表阶段时间语义沿用。

## 结果与验证

- 443 项 Rust 全量、125 UI、87 格式、fmt／严格 Clippy 与桌面构建通过；日志 `logs/EFFECT-003/`。6 项新增核心测试覆盖一整圈逐毫秒角度误差、8／16 位反向映射、主机／包逐帧一致、预设中心、静态跟踪／释放、暂停、顺序、机械边界及 682／683 步关键帧预算。首轮跟踪测试构造了格式不允许的空赋值并误写枚举，修正测试数据后通过，没有放松验收规则。
- 原生打开独立 `data/EFFECT-003/摇头运动验收.project.json`。给 24 台光束摇头添加双轴效果，负幅度定位输入框并阻止提交；`12.500000` 规范为 `12.5`。应用增加一项，撤销回到四项，重做恢复五项；静态赋值与来源逐场景独立比对无变化，未自动点亮任何灯。
- 原工程部分灯位水平角度约 258°，12.5° 幅度确会超出 270° 上限。实际预演准确返回场景、效果、灯具 12、水平轴与机械范围；改为两轴各 10°、灯间展开 360° 后运行。不是通过裁剪或忽略单灯达成通过。
- 验收发现底部预演面板保留另一个操作入口已恢复的旧编译错误；修复共享 `usePreviewController`，普通轮询保持命令错误，新播放 epoch 清除旧错误，轮询瞬时故障在成功读取后恢复。新版以 100° 再现失败，从效果属性改回 10°并成功预演，旧错误消失，正常运行。布局同时修复轴勾选纵排并将幅度／偏移并列。
- 保存退出重开，双轴 10°、8 秒周期、90°轴相位差、360°灯间展开保持。UE 在应用内连接同一离线播放器，暂停于 34.191 秒，选灯和相机操作后仍为 34.191 秒，继续后正常推进。原生文件选择和数字替换存在自动输入焦点兼容问题，通过刷新主窗口焦点和实际可见输入框完成操作；未将工具输入失败误记为产品参数错误。

- 进一步取消验收：关闭垂直轴后字段消失，点击取消并重新编辑，垂直轴仍启用、幅度仍 10°，暂停保持 83.964 秒。截图 `data/EFFECT-003/01-双轴运动与属性.jpg`、`02-运动暂停与取消恢复.jpg`；辅助树 `logs/EFFECT-003/native-final-ax.txt`。当前已保存验收副本，唯一 UE 连接、播放器暂停，设备未连接；原 Volare 摘要仍为 `20f5858d5ac07bf6ee699aba5672320483b33daa5aa63de2ec82d6d3fcb09706`。
