# UX-027：可搜索的灯组与预设选择

状态：完成；基线 `1db2f22`；主工作区／当前会话。接续 AUDIT-001 U02／U10 和 UX-026 原生快捷选择验收缺口。

## 设计与边界

参考 W3C WAI-ARIA [对话框](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)与[组合框](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)（2026-10-01）：搜索不提交值、显式选取、Esc 取消和焦点返回。复用浏览器原生 dialog 的顶层绘制／焦点约束与现有按钮输入，不引入第二套选择状态、重型 UI 框架或自制平台菜单。

灯组与预设长列表使用轻量资源选择面板，显示名称、数量／使用范围，支持中文搜索、键盘、空结果、取消；选择资源只影响现有选择或预设引用对象，引用仍需要显式按钮。召回方式继续沿用替换／追加／扣除。原生快捷灯组选项未选中的原因尚未证明，不将测试工具限制直接宣布为产品缺陷；改造的独立价值是长列表可检索与统一跨端操作。

选择面板关闭并恢复焦点之后才调用原事务，错误草稿需回到原字段；检索或取消不修改工程。原生验证需覆盖搜索、键盘、追加／扣除、错误草稿、预设仅选不应用、实际应用撤销、播放轮询期间选择。共享组件、过滤与呈现分离，不改 Rust／工程格式，不连接设备。

## 实现与验收

结果为本次 `feat(ui): add searchable group and preset selection` 提交。共享资源组件采用短时原生对话框；每页最多 50 项、多词／大小写／全角归一化搜索，选取／当前状态分开，方向键与 Home／End 导航，Enter 确认，Esc／取消／外部点击退出。选择之后先卸载对话框再执行原事务，保证错误字段可以聚焦。修复 WebKit 鼠标点按钮默认不获得焦点的差异：打开前显式聚焦触发按钮，取消正确返回。

- 123 项现有 UI 保护、类型与桌面构建通过。新增独立 `resource-picker.html` 验收界面（不接设备或文件）；1000 项仅渲染 50 项、第二页首项 0051，持续 60 ms 重绘仍可用全角 `ＲＧＢ 0999` 找到并提交 998，空结果 Esc 不新增提交。
- 真实组件浏览器：无效亮度保留 12 台与空草稿、对话框关闭、焦点回亮度错误字段；有效输入后方向键／Enter 召回 24 台。检索输入边界测量 440 像素对话框内左右各 15 像素。
- 原生测试副本：搜索光束并键盘召回 24 台；追加染色为 40 台、扣除光束余 16 台；空亮度阻止扣除并聚焦原字段，还原后恢复已保存。选择预设不标脏，16 台不匹配时引用禁用；24 台光束显示匹配 12 台／72 项，应用再撤销回已保存。
