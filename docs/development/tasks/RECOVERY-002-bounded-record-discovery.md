- 只修改 project-store 私有恢复枚举及其测试；保留最多 64 个字典序最小候选、准确 omitted、随后按时间排列的既有行为。复用 Rust 标准库 BinaryHeap 的有界 Top-K，不加依赖、数据库、后台或时钟。

- 扫描／候选选择独立小文件；原 recovery/mod.rs 为 447 行，抽取本次涉及的枚举职责，其他持久化／认领／清理接口不做机械大重构。新增手写文件保持易读，公共 API／封装版本／产品容量及控制语义不变，因此沿用 [ADR-027](../decisions/PRODUCT-ADR-027-project-recovery.md) 与[恢复契约](../../module-api/project-recovery.md)，不另立语义 ADR。
