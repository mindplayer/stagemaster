# AUDIO-010：保持动态效果进度的片段分割

状态：完成；基线 `12ec189`；结果为本次 `feat(audio): preserve effect progress across clip splits` 提交；当前主工作区唯一写入。依据 ADR-073，接续 AUDIT-001 U06，不操作实灯、固件或 output。

范围：单场景 Plan 效果时钟偏移、音乐片段偏移能力与分割／重置原子命令；旧包保护拒绝、兼容格式审计；精确分割输入、播放头填入、锁定／边界／渐变错误与取消，固定属性区读出偏移；撤销／保存／重开／试听定位。复用 Rust 调度／宿主音频／已有组件，不能只切界面图形或让右段效果重启。

实施前审查：采纳 [ADR-073](../decisions/PRODUCT-ADR-073-audio-clip-effect-offset.md)。分割限于进入渐变结束后；内部源偏移与片段放置分开，完整保相位裁切及渐变内分割不在本增量冒充实现。核心／编辑／契约／组件／测试分别小模块，不继续堆积 AudioWorkspace 或 audio.rs。

验证计划：多种动态曲线与不同周期逐采样等价、分割点及紧邻后段渐变、静态与离散属性、重复分割／复制／移动／停用／重置；边界与容量拒绝的原子性、一次历史和暂停音乐游标；旧文件、非法能力／类型／未知命令字段独立检查；Rust 工作区、严格检查、格式、UI／类型、桌面及原生副本验收。包编码拒绝非零偏移，旧字节不变，元数据预算保护。

实现：Rust 单场景效果时钟与本地渐变分离，独立源偏移的严格能力、原子分割／重置、右段新 ID 与一次历史；包显式拒绝不能表示的非零偏移。界面精确输入／已确认播放头、可分割范围、局部错误焦点／Enter／Esc／取消与锁定保护；分割成功选择右段。复用已有宿主、编辑历史和组件，无第二套时间语义。

验证：546 项 Rust 工作区测试、调整清除函数及测试助手后的 150 项工程测试、185 UI、112 格式、类型／fmt／工作区严格 Clippy、桌面构建、Xtensa runtime-readiness 严格检查通过。多曲线／周期与边界逐采样相等，后继渐变快照、重复分割、复制移动停用、未知字段／孤立能力、设备编码拒绝和 512 字节元数据预算均有保护。日志在 `logs/AUDIO-010/`。

原生独立副本 `data/AUDIO-010/Volare-连续分割验收.project.json`：蓝色起势在 11.000 秒进入渐变中分割被拒，焦点留输入框，Esc 取消；蓝色回应从此预演后暂停在 18.235 秒，使用播放头填入同值，分割 22→23 段，右段起点 0.975 秒／渐变 0，一次撤销回 22 且游标保持，再重做；重置效果起点为 0 再撤销恢复 0.975；继续在 18.800 秒分割成 24 段，右段偏移累加为 1.540 秒，暂停游标仍 18.235。保存／严格检查、重启最近工程恢复偏移通过。逐值比较证明其他片段、音乐／32 卡点、灯光、场地未变，AUDIO-009 源文件哈希未变。预演操作实际启动内嵌 UE 且连接有画面，退出后重开音乐 0／平面场地／UE 未启动，设备始终断开。

隔离实际组件浏览器验收：渐变内错误焦点、Esc 与取消、播放头填入 2.333、Enter 仅发分割命令不提交外层表单、宿主分割与游标失败后恢复输入焦点、锁定禁用、全段渐变无可分割位置；控制台零警告／错误。截图见 `data/AUDIO-010/`，测试夹具只在 tests，无正式演示入口。

过程修复：首次 Clippy 指出分发函数 104 行与末语句分号，抽取已有清除职责后通过；测试助手 json 宏借用导致无谓按值警告，改为显式消费 EditCommand，期间一次类型名误写已修复。独立格式审查发现孤立偏移能力条件曾被其他能力测试遮蔽，已修正并补仅该能力的空工程保护。保留失败日志，不放宽检查。

模块审查：新增职责各在小模块；AudioWorkspace 397 行，仅增加宿主快照与动作接线，本次不把算法放入容器；audio.rs 295 行。完整保相位裁切、进入渐变内分割与双源持续交叉仍后续；无实灯／刷机，不据此声称硬件已支持音频片段包。持续 goal 接续时间线整组直接移动。
