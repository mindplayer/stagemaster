# DEVICE-002B：真实 Flash 绑定与认证恢复

日期：2026-09-29；基线 `400d071`，主工作区 `main`，当前会话单一写入负责人。结果为本次 `feat(device): persist authenticated BLE bindings on shared flash` 提交。此处是 B 的板级增量，完整 DEVICE-002 继续。

## 交付与审查

- 按 [ADR-044](../decisions/PRODUCT-ADR-044-board-binding-storage.md) 增加 132 KiB 绑定分区，既有节目区原址不动；一个官方 Flash 驱动由第二核串行管理。分区句柄复用 SDK 边界和属性检查，附加整数溢出检查，不跨核共享 Rc。
- 内部单容量请求／回复队列带单调请求号和 10 秒期限；迟到回复不能对应另一操作。初始化／提交必须通过既有 Runtime 维护许可，时钟／维护错误不执行闭包并撤销旧安装工作连接；只读恢复不自动格式化。
- 从真实存储恢复静态身份、IRK 和最多 4 个绑定，使用官方隐私和安全栈。首次配对产生提案、撤回权限、物理断开，再提交回读；只有之后的新连接通过已认证 LESC 恢复才能获得核心 Grant。测试值默认清空，普通诊断和声明不构成安装权限。
- 普通 `binding-readiness` 不初始化、不自动开放配对；本地测试镜像额外开启有界准入。两个镜像均禁止真实输出和无线节目写入。普通版本暂未提供实体按键入口，这项不能算成用户绑定流程完成。
- 新增产品文件最大 202 行；广播配置、单连接 GATT、凭据队列、存储执行、密钥转换、权限管理分别成文件。维护测试约 380 行，继续复用同一维护夹具且未加入硬件逻辑，不拆散同一状态边界的断言。

## 实板证据与失败记录

当前 Mac／当前 ESP32 的配对和受控刷机沿用用户明确授权。GPIO21 始终低，无 DMX、真实灯具或 eFuse 操作。

1. 首次受控镜像 774,704 B：恢复全空白区返回格式未就绪，显式本地测试初始化成功，约 45.6 ms；绑定档案第 1 代／0 主体。A 第 9 代 106,825 B 和 B 第 8 代 110,772 B 均恢复正常。
2. 首次配对探针失败：已展示随机码，但串口未出现配对成功；主机读取结束后未等到期望的设备主动断开，最终客户端清理连接。日志保留。系统输入耗时是怀疑因素，未证明为唯一根因；不能把随后成功覆盖成首轮通过。测试工具补记原始读取异常，避免超时等待遮蔽它。
3. 重启重试：实际 macOS 原生码配对报告 `EncryptedAuthenticated`，绑定在约 16.0 ms 内写成第 2 代／1 主体并回读成功。首次连接未返回认证试验值；其后两次重连恢复认证，各 5 次有效保活通过。临时码落盘脱敏，密钥不记录。
4. 恢复普通镜像后，启动只读恢复第 2 代／1 主体，不再弹配对输入；100 秒／50 次保活及第二次 5 次保活通过，最大往返 159.456 ms。随后独立 reset，再次两连接／10 次保活通过，重复序号不续期，6.033 秒断开。三次启动的 boot 不同、稳定设备标识和 macOS 连接标识一致；每条会话标识不同。这里的重启不是物理拔电。
5. 自审补齐维护异常的旧工作连接撤销后，最终镜像重新构建、刷入并做恢复／超时回归。该最终构建又完成两次重连／10 次有效保活和 6.063 秒超时断开；总计四次启动、八条持续认证连接／85 次有效保活，另两条认证超时连接。最终 ELF SHA-256 `6e92314319e1bed57dcbcce876f6746f8d9e5ff74f9220e5476b316b2b149aab`，应用 766,384 B。普通版本保留在板上，受控配对窗口关闭。

最终构建启动只读恢复约 4.6 ms，VaultStore 1,408 B；稳定堆 41,132 B 已用／89,940 B 空闲，分配器已观测峰值 48,468 B。存储调用前栈采样 12,109 B／预留 32 KiB，不包含底层 ROM 最深调用，不能当作高水位。节目 NOR 写入／擦除计数均为零；当前 A、B 摘要和基线一致。

证据：`logs/device-002b-binding-*-{probe,serial,flash}.log`，软件 `*-workspace-final.log`／`*-workspace-clippy-final.log`／`*-auth-tests.log`，`data/DEVICE-002/binding-acceptance.json` 和分区表往返文件。实物绿灯常亮已由用户在 HW-003 确认，本轮另有各连接 GPIO17／GPIO21 亮灭日志，不声称测得 DMX 波形。

原生主程序 PID 44624 已搜索到稳定标识 `acf4425a-7e30-542b-2f99-860e355bc234`，重新选择并连接；自检／56 次保活通过（超过 90 秒），最近往返 157 ms。圆弧剧场仍“已保存”，未重建工程或重启三维；灯光输出仍为禁止。当前应用只做诊断连接，不能将它计作正式认证／安装界面验收。
