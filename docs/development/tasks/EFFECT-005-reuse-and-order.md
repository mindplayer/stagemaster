# EFFECT-005：效果复用与灯序整理

状态：完成。基线 `f1af06f`，结果为本次 `feat(effects): clarify reuse targets and add batch fixture ordering` 提交，主工作区单一写入；用户 output 不动。接续审核 U02／U03 的换组复用与操作细节。

参考 [Titan 19 效果发生器](https://manual.avolites.com/docs/effects/shape-generator/)：可用效果取决于灯具属性，效果按选择顺序展开，同一效果可分别应用至不同灯组。吸收属性预检、有序目标与独立副本，复用本项目已有效果复制、资源搜索及草稿／事务；不声称跨型号光学完全相同或具备 Titan 全部二维分布。

设计审查：只改善既有 effect.put 的界面适配，不改变核心、持久化格式、执行与时间语义。独立的目标兼容报告由命令转换、复用和灯序编辑共用；Rust 保持最终校验。复用先说明来源和实际目标，不静默剔除不兼容灯，名称／幕场搜索后明确保留所选项并可清除筛选，最多显示 50 项一页；复用始终新身份、默认停用，进入现有编辑器后确认。

灯序编辑增加按名称／配适排序、反转与奇数位在前，并显示明确序号；操作只改当前效果草稿中的有序身份，不改全场选灯、灯位或反向相位标志。兼容性按所需属性与运动模型判断，全部目标合格才能采用当前选灯。任意排序后仍可逐台调整，取消无工程修改，应用只有一次历史。

验收包括混合灯型、缺失／重复目标、名称自然排序、地址与未配适稳定顺序、空／单目标、来源副本独立、搜索隐藏选择、键盘／分页及取消；真实桌面验证复用、排序草稿、撤销／保存重开和现有资源选择回归。只控制离线预演，不操作设备。


实施与验证：独立 effect-targets 提供统一目标问题和纯灯序变换；两类效果编辑器共用现有灯序组件，复用面板沿用资源词项搜索并加 50 项分页、方向键、来源和隐藏选择提示。提交仍走原 effect.put 与事务。按名称采用中文数字自然排序；按配适按域／路／地址排列，未配适和缺失项目稳定置后，不丢目标。选择器唯一键由场景和效果共同组成，避免不同来源同身份误选。

209 项 UI 测试、TypeScript、格式检查、桌面构建通过。新测试覆盖空／单灯、四种排序／稳定同键／未配适／缺失、混合属性与运动模型／重复目标，以及副本身份、源曲线与反向标志不变。Rust 和持久化格式未改，不重复全工作区测试。

浏览器真实组件：104 项按 50／50／4 分页，首尾禁用正确；选择色彩到仅调光灯时显示缺少红绿蓝，禁止继续；换页保留来源提示。`第二幕 呼吸` 联合搜索、方向键＋Enter 选择正确源，即使其 effect.id 与第一幕相同；选择成功后结果为第二幕呼吸／dim。全角数字搜索匹配色彩 103，取消“改用当前选灯”后原全彩灯可用，取消不替换上一结果。

原生：独立 80 灯无音乐副本有 52 个效果，灯组选 24 台光束摇头，复用首场六灯渐入到当前选择，进入草稿时停用。反转后取消不留下效果、仍已保存且撤销禁用。再次复用，奇数位在前得到 01/03/…/23/02/04/…/24；应用仅增加一个停用副本。原生尝试粘贴名称没有改变字段，核验以实际保留的“渐入 副本”为准。搜索待添加灯具 RGB 并回车，应用仍禁用、无新草稿。关闭后一次撤销恢复四效果／已保存，重做恢复五效果；保存并重开后奇偶顺序、停用与曲线保留。名称／配适排序及逐台下移均正确，取消恢复已保存副本。
