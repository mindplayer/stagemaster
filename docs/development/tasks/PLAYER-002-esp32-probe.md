## 本轮验收

1. 实板芯片／闪存／安全状态，锁定工具链及依赖，交叉编译与资源报告。
2. 同一播放内核在芯片执行手算渐变、暂停／继续、跳转／停止／循环测试；不将主机测试冒充实板证据。
3. 传输无关会话／心跳测试：无效输入、重复、乱序、错误会话、到期、断开／重连。
4. GATT 服务发现、握手、有效心跳、故意停止心跳及重连；主机受系统权限阻挡时如实记录，不能据串口输出声称 BLE 直连已通过。
5. fmt、相关测试与静态检查、桌面共享内核回归。实际输出／512 槽／差分波形、灯具、本地面板和 8 小时压力仍为父任务后续。

本轮在真实 GATT 客户端发现两个适配风险：`ReadEvent::accept_unprocessed` 返回空值，改为更新属性表后正常读取；第三方 `validate` 只验证容量，适配器补足恰好 20 字节限制。修复后的完整 BLE 验收通过；未修改第三方缓存源码或放宽断言。

## 审查与剩余范围

- 分层通过：共享播放器只有 alloc；会话 crate 无分配、无 I/O／播放依赖；板卡引脚只在 board 模块；GATT 只转消息并接收诊断快照回调，不构造或推进播放器；独立 diagnostics 模块维护测试负载；Python 仅验收脚本，没有新增产品语言。
- 诊断固件保留在开发板上。GPIO21 固定低电平，未实现 UART DMX；软件配置不代替线路实测。没有操作真实灯具，也没有声称读取芯片等于 DMX 合规。
- `esp-radio 1.0.0-beta.1`、部分 HAL API 及随 espflash 的引导程序版本尚非生产稳定性保证；固定版本后再对压力／升级／恢复验收。
- 链接器保留 RWX 段告警：`readelf` 显示 `.rotext_dummy/.text/.init/.fini` 共 RWE 段；未隐藏告警，也未宣称内存执行权限已经隔离。生产保护另行审查。
- ELF `size` 的 bss 总数包含保留栈和虚拟填充，不直接当成运行已用 RAM；没有开启／实测 PSRAM，计划容量还需专门预算与拒绝机制。
- GATT 广播地址为启动期随机地址，nonce 不是身份验证。正式设备发现／绑定、控制权、24 小时授权、文件分块和原子安装、桌面连接 UI、本地面板均未实施。
- USB 提供电源；本轮只切断 BLE 控制连接。没有物理拔 USB／独立供电、手机后台、射频距离、并发传文件与 DMX、8 小时压力验收。
- 后续 PLAYER-002B 补 UART／完整帧交接及波形测量、隔离公共地／连接器；PLAYER-003 补执行包／安装，GATT 优先承接业务，USB 保留恢复。
