## 结果与审查

结果为本次 `docs(spaces): plan irregular multi-room venues` 提交。核对 Vectorworks 空间设置与 buildingSMART IFC4 空间／边界机制，形成 [ADR-010](../decisions/PRODUCT-ADR-010-composable-spaces.md)。把“全局矩形场地”修正为可组合空间方向，区分地面标高／净高、物理构件／逻辑空间、共享墙／门洞连接、坐标附着／组织分组、视图可见性／输出。

更新 [场地创建方法](../../ui-design/venue-layout-design.md)：画多个房间轮廓、各自设高度、相邻连接、当前房间／整场查看及后续剖切。第一阶段可仍使用矩形快捷工具，但领域契约与验收从开始覆盖凹轮廓和多空间，不能保存为工程级单个宽深高。既有舞台、观众区和过道设计继续复用。

审查结论：当前 `StageNode` 坐标约定可沿用，语义不足以宣称已有房间建模；新契约需覆盖依赖更新、迁移和保存，不在 UI 增建第二套业务。独立组件稿仍为单空间投影；本次不声称已验证多房间交互或光学遮挡。
