# UX-018：编排常用操作与预演衔接

## 范围和依据

本轮落实 AUDIT-001 的 U01、U02、U04 首批改进：灯光／位置／场景上下文属性，亮度和颜色优先，摇头逐灯明细按需展开；灯组召回与有序选择常驻场景工具区；显式一键载入并播放当前场景、切至唯一三维的播放来源，清楚区分正在编辑和已载入内容。资源记录、引用、复制和撤销继续复用既有实现。

依据报告已经核对的 CapCut 上下文属性、MA/Titan 分组与预设、独立播放状态机制。借鉴操作组织，不复制其界面或另写灯光计算。效果图形编辑、完整灯具语义、现场执行面、混合时间编排及真实 DMX 不在本次出口中。

## 边界与设计审查

- 不改 Rust、工程格式、公共宿主 API 或时间／控制权语义。预演组合现有 loadScene、execute 与三维 source 命令；用户显式发起，沿用载入操作会替换当前离线播放并释放音乐会话的行为。普通选灯和切换属性不触发播放。
- 标签切换先经过工作台统一草稿验证，使用既有 WorkspaceSurface 保留组件状态；无效输入阻止离开并定位，停止／暂停保持可用。
- 有序选择由工作台持有，灯组召回模式在场景工具容器内共享；资源池与快捷选择不维护两份业务选择。
- 从 Workbench 抽出场景工具组合，从 ResourcePool 抽出资源管理对话框；新组件按选择、属性容器、颜色输入、预览明细及动作分别内聚。既有大文件仅保留成熟事务协调，不扩大领域责任。

## 实现与模块审查

- SceneInspector 按灯光／位置／场景组织属性；亮度前置、颜色随后，名称单行显示并保留完整提示，逐灯角度折叠。属性面板仍持有各自草稿，切换使用工作台统一验证与事务。
- SceneSelectionBar 在选择灯具、效果、资源三个工具页常驻；原有奇偶位／反序／反选移至此处，新增清空；灯组替换／追加／扣除复用 recallGroup，并与资源池共享同一召回模式。效果模板压缩为常用操作条，已有效果更早可见。
- 一键场景预演组合既有命令；先提交草稿、读取当前版本、载入、按回执纪元／序号执行，再开启唯一三维的播放来源。切换目标或卸载后不得继续执行迟到载入；编译失败不执行旧内容，旧纪元拒绝不自动覆盖新播放。列表的人工推进仍保留原控制方式。
- 显示正在编辑／播放内容及版本是否与已应用工程一致，不向用户暴露内部修订 UUID。停止后明确显示灯具默认值，普通选择不隐式播放。
- Workbench 从 1538 行降至1485 行，保留现有文件／历史／各编辑器事务协调，本次已抽出场景工具组合，不同时重写高风险队列。ResourcePool 从 530 行降至 398 行，抽出管理对话框和共享类型；ParameterPanel 373 行，PreviewPanel 338 行。新增职责文件均小于 200 行，CSS 随对应组件加载，无运行时循环依赖。
