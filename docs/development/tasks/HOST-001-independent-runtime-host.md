# HOST-001：独立执行宿主

状态：独立宿主库增量完成，应用／进程集成仍待接续；基线 `4a3f7c1`；main 主工作区；当前 Astra 单写者；保留用户 `output/`。上一轮 PLAN-003 属于已提交的架构收敛进展；本轮接续其第一项运行边界验证。

依 [ADR-098](../decisions/PRODUCT-ADR-098-independent-runtime-host.md) 新增可复用宿主库，复用现有运行核心，不更改工程、包格式、固件或现有桌面行为。范围为工作区注册、独立宿主 crate、契约和有证据的状态维护。

实现按职责分开：入口／类型、可信连接、受限客户端及回执、线程调度、只读观察、独立测试。先准备再运行；有界队列、操作截止时间、客户端和 Host 生命周期分开；不新增外部库、不开放未认证端口或真实物理输出。

完整验收按 ADR-098 五组用例；再执行 Rust 格式、工作区测试和严格 Clippy。当前不能声称已有独立执行进程或桌面闭环；后续须完成宿主集成和跨端应用适配，不以本库增量结束长期框架目标。

## 已实现与验证证据

独立宿主复用 `stagemaster-runtime` 的控制权、幂等回执和 Player，无新增外部运行依赖。输入／回执、观察、生命周期与调度分文件；当前手写文件均小于 300 行。Host 只接纳已准备、无控制者的待执行节目；Client 不持有 Runtime 或维护入口。队列 32 项，每周期最多 8 项，TTL 最多 5 秒；观察采用单个复制快照，慢读取不积累帧。复用 Rust 标准库有界通道、Instant、线程及 OnceLock，不自写并发队列。

新增 15 项测试与 1 项可编译调用示例，覆盖 ADR-098 五组门槛：

- 真实线程中的控制客户端消失／到期／重新取得控制权，原实例继续；采样时间和逻辑帧与独立 Player 参考核对。
- 旧连接停止／续期／释放拒绝；相同开始请求返回历史回执；暂停位置保持、恢复不创建新实例。
- 队列满、未读回执、过期未执行请求不耗业务序号；等待超时后读取同一 Ticket；关闭绕过满队列，超时后等待同一线程。
- 准备完成后把存储读源设置为不可访问，运行／控制阶段读取次数始终为零；人为持有观察发布槽时核心继续、跳过发布计数增加。
- 控制权取得结果自带历史权威状态，即使观察发布受阻，也能正确提交首条命令。空／运行中／已有控制者与非法周期拒绝；非零时基保持、时钟耗尽、许可拒绝和意外 panic 分别核对；关闭／故障撤销有效帧。
- 固定刷新相位、迟醒跳过与长延迟不突发补帧用独立时刻表验证；采样指标记录迟到和错过的时隙，不将软件周期当实物时序认证。

全工作区测试通过 753 项、0 失败、既有 1 项忽略，24 个 crate 文档测试运行通过（新增 1 项调用示例）。补终态故障原因及其一致观察后，最终宿主 15 项与 1 文档测试再次通过；最终严格全工作区 Clippy、fmt／diff 检查通过。正常依赖树只含既有运行／安装／包／播放模块和它们已有的编码／摘要依赖，不含 Tauri、媒体库、BLE、UI、UE 或云端；Cargo.lock 仅注册新宿主包，无依赖升级。日志：`logs/host-001-workspace-tests.log`、`logs/host-001-final-host-tests.log`、`logs/host-001-workspace-clippy.log`、`logs/host-001-dependencies.log`。

检查过程中修正了初次测试文件路径、所有权表达、时间减法和条件组织，未削弱 lint 或测试。错误路径已移回项目并移除本轮误建空目录；最终产物全部在项目内。审查另外补齐取得控制权回执，避免首命令依赖迟到快照。没有版本升级或替换现有播放器；测试许可仅用于软件验收。

## 尚未完成的框架边界

本增量尚未接实际桌面、独立常驻进程、认证 IPC／网络入口、物理输出或音视频同步。不能据此宣称 UI 进程崩溃不影响演出，也不能将观察快照当作可靠物理端口。后续先贯通可信应用入口、进程生命周期及实际工程准备链，再开展第二种软件传输承载；多执行器和跨设备同步继续保留，不让当前单节目档位成为专业产品上限。

集成结果为本次 `feat(runtime): add independently scheduled bounded host` 提交。持续目标保持 active；未修改／打开用户工程与现有窗口、未连接设备或输出真实灯光。UI／UE 源码未变，未重复无关前端构建或原生交互验收。
