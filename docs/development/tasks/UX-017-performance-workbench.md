# UX-017：正式演出工作台重构

基线 `28f16c8`，主工作区，当前 Astra 单一负责人；已完成。结果为本次 `feat(ui): rebuild performance editing workbench` 提交。用户明确要求按 UX-016 重构真实 UI，保留现有用户 `output/`。

范围：固定左资源／中央舞台／右属性／底部编排布局，场景编辑、执行步骤、音乐时间线均接既有命令；场地中央切换平面／三维，灯具及工程管理使用完整工作面。分隔条、侧栏折叠、恢复布局与窄窗适配属于本机 UI 偏好，不写工程。先接真实已有功能，不增加剧本文档解析、混合调度或假轨道。

布局边界：新增独立区域宿主与停靠适配，沿用 React 固定 portal 容器的挂接／停放机制，工作区切换保留各模块草稿及控件；唯一 PrevisPanel 与音频会话不随布局或视图切换重建。业务模块提供资源、编排和属性区域，布局不解释播放命令；Rust、工程格式及输出契约不改。切换需先经过既有草稿验证，选择不触发执行。

文件规模：Workbench、StageWorkspace、SequenceWorkspace 为既有大文件；本轮优先抽取导航、布局、区域组件及步骤展示，不向入口堆入新领域逻辑；验收记录具体规模及保留理由。

验收：MacBook 正式应用真实 Volare 与无音乐列表；唯一三维、音频不重置，人工执行／下一步、选择／搜索／复制排序、无效草稿／取消、撤销保存、尺寸调整／恢复、侧栏返回、窄窗与键盘。类型、相关 UI 测试、桌面构建及原生验证；不操作真实 DMX、固件或云端。

## 实现与审查

- 参考 UX-016 已核对的 CapCut 资源／预览／属性／编排分区；保留 QLab 类人工推进思路，使用既有 Rust 列表语义，没有在 UI 另造调度器。
- 新增 PerformanceLayout、DockPane、PanelDivider、本机偏好与独立导航；抽取场景工具页、音乐卡点列表、步骤列表和平面相机适配。参数草稿仍属各模块，编辑／历史／保存仍走现有队列。
- 场景、执行步骤、音乐、布置共用唯一三维；音乐复用原生会话和 WaveSurfer，紧凑双声道高度不随分隔条拖动重新初始化。
- 原生发现视频从 document 移出再挂回会出现空白。中央直播视频改为保持挂接，隐藏使用 visibility／inert，普通面板继续停放以保护 macOS 辅助树；增加可见时恢复浏览器暂停的适配。实际 UE 的平面往返及管理页返回均有画面，未保留诊断画布或第二视窗。
- 草稿无效时不折叠属性；分隔条支持鼠标／键盘、Esc 还原，存储解析有限值保护和恢复默认；平面首次显示按真实内容适配，80 灯工程默认关闭重叠名称，可手动显示。
- 现有大文件：Workbench 1538 行（基线 1502）保留事务／引用协调，重排 JSX 导致较大文本差异；StageWorkspace 783 行保留成熟空间、桁架和手势事务，创建弹窗留在区域宿主外；StageCanvas 742 行（基线 767）本轮已抽出相机，既有手势状态机不同时重写；SequenceWorkspace 497 行已抽出步骤展示。新职责文件均小于 400 行。后续可继续按编辑器模块分解，未通过压缩行数规避审查。
