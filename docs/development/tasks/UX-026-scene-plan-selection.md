# UX-026：场景中央平面选灯

状态：完成；基线 `96f1038`；主工作区／当前会话。接续 AUDIT-001 U02／U09。

## 决策

参考 [grandMA3 2.4 Layout View Settings](https://help.malighting.com/grandMA3/2.4/HTML/layout_view_settings.html)（2026-10-01 官方资料）：灯具框选、明确选择状态、锁定布局与聚焦。本项目使用现有真实灯位生成平面选择画布；不引入独立可编辑布局格式，不复制 MA 的窗口管理。原有有序选择、灯组、属性区和事务队列继续唯一持有编排选择。

场景页默认平面选灯；允许切到同一个 UE 视窗，显式预演自动切到三维。按灯位点击、修饰键增减、框选、全选结果、搜索、聚焦；未布置灯具可独立选择；重叠灯位明确列出候选，避免误选顶层对象。这里只选灯，不移动安装位置、不计算实时灯光或输出状态；真正布置仍在场地页。

沿用画布几何／摄像机和现有选择函数，独立拆分选择模型、手势、画布呈现和视窗切换，抽离 Workbench 相关职责。验收须覆盖与灯组／属性双向同步、草稿保护、无三维场景、选择取消、重叠／未布置灯具、唯一 UE 切换保持和视图操作不标脏。设备断开。

## 实现与验证

结果为本次 `feat(ui): add shared scene fixture plan selection` 提交。中央平面选灯、未布置列表、重叠候选、搜索／仅已选／聚焦／全选、选择顺序标签均共用场景选择。已选灯位最后绘制，避免同位置未选灯遮住高亮。视图状态跨页保持，工程重开重置；只有选择，不改安装位置。显式预演自动切到唯一三维，手动切回平面不释放该连接或重设播放时间。
