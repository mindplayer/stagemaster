# UX-037：共享快捷属性范围

状态：完成，结果为本次 `feat(presets): share attribute scopes across editing tools` 提交。基线 `6bba45a`；主工作区单写者，output 不动，持续 goal active。接续 U02。

依据：UX-035 属性组、UX-036 显式掩码连续性。实际缺口是快捷预设与各记录窗口各自写属性清单，颜色只覆盖 RGB，色盘无法用“仅颜色”召回；图案／棱镜和快门没有快捷范围。

取舍：复用已有 UI 分类的颜色／图案／镜头键目录；预设动作范围独立表达。尤其“仅亮度”保持只控制 dimmer，绝不随显示分类扩大到快门，频闪单列。位置仍为 pan／tilt。快捷栏与复用的 AttributeMask 使用同一范围目录／匹配规则，窗口提供清空，保留逐项勾选。没有可用属性的范围禁用，显式空选不自动扩大。范围选择按当前可用属性取交集，切换灯具后不自动添加新属性；未限定全部保持既有 null 意义。

不变更工程格式、公共 IPC 或运行语义；现有 mask 字符串键与核心验证不变。UI 纯函数／目录和共用选择控件分别组织，避免重复硬编码；原记录／更新／复制窗口复用同一掩码组件。

出口：色盘单灯与 RGB 混合、仅亮度隔离快门、图案／棱镜／镜头、无匹配／空范围／未知属性、乱序重复键、取消与局部更新；组件实际命令内容及原生已有工程操作。UI／类型／格式／桌面、文档与状态维护，完成继续。

实现：范围目录复用 parameter-categories 键目录，独立集合匹配与选择组件；AttributeMask 和 QuickPresets 共用，删除重复列表／JSON 顺序比较。样式局部限定，不增加大型页面职责。仅 TypeScript／CSS 与测试变更。

验证：239 UI、类型、桌面构建通过；共享范围纯测试涵盖色盘／RGB、亮度隔离快门、各组、未知／空／缺失／重复／乱序，以及切换能力不扩大。实际 ResourcePool／PresetEditor／QuickPresets 组件提交命令验证：混合颜色 4 键，单色盘 1 键，亮度 1 键、图案 2 键、快门 1 键、镜头 3 键、位置 2 键；从单色盘增选 RGB 保持色盘自选，不添 RGB。记录窗口改范围后取消，重开仍原颜色 4 项；空范围拒绝记录；复制窗口仅亮度命令不含快门。仅 RGB 灯的其他范围禁用，无灯具全部禁用；无控制台警告／错误。组件使用命令捕获，不将其当 Rust 写入证明。

原生：独立 UX-036 副本选择镜头快捷范围，池／记录窗口同步三项；其他能力禁用。清空后记录拒绝，取消重开恢复三项。新增“共享镜头范围验收”只含变焦 44%、调焦 62%、光圈 80%；一次撤销回到已保存两预设，重做三预设。保存退出、最近工程重开仍三预设和正确内容；无撤销历史、音乐 0、UE 关闭、设备未连接。JSON 独立核对旧预设／场景不变，来源 SHA256 仍 c7b7ae977ab3b134fb9533d9d95c2ebca4a4b18d4f096a6944b6a995f5535f57；结果 data/UX-037/共享范围验收.project.json 为 3a9c9a5da86067222b43d616ed4cfd76f6e216bbd8ed43f7566b273a45452530。截图 01–03，日志 logs/UX-037/。
