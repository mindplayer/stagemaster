## 实现与问题修正

新增独立 `execution-level-context`／`execution-level-gesture`、React 生命周期 Hook、原生输入 Hook 和电平组件；原卡片只接线，精确输入从 SourceControls 抽出，没有新增播放算法或传输。一个后台一个在途控制请求、一个最新目标；发送前重新读取修订，发送后匹配递增序号、同一已应用回执及实际电平。自动续约等待使用原回执路径；同一推子最终值待确认时可以继续合并输入，其他来源仍互斥。取消只丢弃未发送目标，不回滚现场已应用的值。

原生验收发现两处 WebKit 交互问题：按下时强制焦点随后被原生鼠标默认行为清除，误触发取消；在 range 外层设置指针捕获会阻止内部滑块拖动。最终保留原生 range 的滑轨／键盘／无障碍行为，不争夺内部拖动；窗口级松手处理覆盖轨道外释放，松手后设置键盘焦点，窗口失焦／隐藏和键盘失焦继续取消。取消后保留本次输入的取消标记，按住继续移动不能重新开始发送。实际组件按住、Esc、继续移动、松手及下一手势验证通过。

回执和手势提示使用固定 36 px 占位、超长内容内部滚动，消除确认／提示切换时滑轨跳动。复验同一手势前后滚动位置和滑轨坐标保持。拒绝消息去重；窄栏保留 32 px 命中区与精确输入。最初 serial 帮助函数不能替代 TypeScript 对空 record 的收窄，已改显式空值分支；失败日志 `exec-010-ui-check-serial-null.log` 保留。
