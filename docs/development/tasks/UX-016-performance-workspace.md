# UX-016：演出工作台布局与剧本编排

基线 `a14411a`，主工作区，当前 Astra 单一负责人。用户要求整体参考剪映，随后明确日常也按剧本／演出脚本编排。需求与布局方向审查完成，结果为本次 `docs(ui): center workspace on script and timed performance` 提交；正式布局重构和剧本能力尚待实施。

## 本轮结果

更新既有 [工作区框架](../../ui-design/workspace-framework.md)，保留组件、资源、工程和唯一三维边界。采用左资源、中央预览、右属性、底部编排的稳定骨架；执行步骤与定时段落并列，音乐可选。混合流程以人工入口／自动段落／继续等待组织，不强迫绝对时间。持久偏好写入 UI 开发规则，旧组件稿增加现行约束链接。

核对现有 `Sequence`／`waitMs`、Rust 预览命令和音频契约：已有人工推进及完成渐变后等待，已有音乐卡点；完整剧本文本、文档锚点、无音乐通用时间线和混合段落调度仍缺失，未伪装为本次已实现。没有修改格式、API、产品代码、用户工程或执行状态。
