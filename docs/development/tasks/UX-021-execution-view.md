## 设计审查

沿用 AUDIT-001 已核验的 MA/Titan 当前／下一步骤和 QLab 人工推进原则。执行步骤提供编排／执行视图切换：编排保留三维、步骤属性；执行把空间交给完整步骤队列与固定运行台，明确当前、下一步、所选、人工等待、延时／渐变、旧版本。选中不等于执行，跳到所选须显式点击；运行中的跳转需就地确认并可取消。搜索与定位当前步骤不发播放指令。

显示信息来自同一 Rust PreviewSnapshot；下一步按载入快照及 canNext 推导，不能用编辑列表错误解释旧版本。播放进度只代表当前步骤，不伪造无音乐演出的总进度。暂停／停止在无效编辑草稿时仍可用。切视图前收集草稿，切视图和折叠预演不重置播放器或创建第二个渲染端。

本次不改工程格式、核心推进或输出协议；是单列表离线执行面，不冒充多执行器现场输出。共享播放操作先抽取独立 hook，运行展示、步骤状态和布局分别组织；现有 SequenceWorkspace 超过 500 行，本次抽取步骤编排工具栏职责，避免继续堆入口。
