# AUDIO-002：专业波形编辑

基线 `dda2052`；主工作区；Astra 单一负责人；完成。本次结果为 `feat(audio): integrate professional stereo waveform editing` 提交。依据 [ADR-054](../decisions/PRODUCT-ADR-054-professional-waveform.md)。

范围：独立波形数据适配、WaveSurfer 宿主、卡点交互与外观组件，Rust 有界双声道包络、模块契约、依赖声明与测试。工程持久格式、播放权威时间和设备协议保持原契约；自动节拍按用户要求暂缓。

## 实现及审查

复用 WaveSurfer.js 7.12.12、Timeline 和 Minimap；许可证随前端资源分发，不调用外部音乐服务。原生 Rust 保留播放／解码／灯光时间，组件只使用预计算数据。左右声道各有真实有符号最小／最大包络，10 ms 一桶。全曲导航、鼠标位置缩放、平移、显示幅度、播放跟随、卡点拖动、吸附和键盘定位分开维护；组件卸载销毁渲染器。产品 TS 模块最大 228 行，样式独立 268 行。

完成自审：包络不进入 JSON／历史／ESP32；音量与显示幅度、导航与播放位置分离。裁切边缘按包络桶近似，不声称逐采样编辑。单份 Rust 包络最多 5,760,000 B；IPC 和前端副本、解码器及图形缓存另计，不声称永不溢出。

## 验证

- `cargo test --workspace --locked --offline`：425 项通过（默认工作区特性），`logs/audio-002-rust-tests-final.log`。媒体 5 项包括 1 小时双声道上限／超限、完整帧声道分离、22.05 kHz 的非整数桶和末尾空桶保护、原有取消／无效媒体／归档恢复。定向容量测试 7.03 秒，见 `audio-002-bounds-tests.log`。
- `cargo fmt --all -- --check`、工作区严格 Clippy、TypeScript 检查、83 项 UI 测试、桌面最终构建通过。日志位于 `logs/audio-002-*`；检查新增裁切包络、无效／过大输入和缩放锚点计算。持久格式没有变更，未重复格式测试。
- 浏览器隔离验收：标记从 2.000 拖到 5.481 秒，一次撤销恢复 2.000；视窗放大／概览键盘平移保持音乐位置为 0；幅度 ×4 保持已有缩放；移除后波形组件消失、撤销后恢复。该页不输出声音、不进产品入口。
- 一小时双声道隔离页在 400 px/s 最大缩放、约 616 CSS px 视窗下，24 张画布，单张最大物理宽 1,232 px，RGBA 像素约 21.51 MB；视窗约 29:59.197–30:00.800。这是当前浏览器采样，不等于整个进程／GPU 总占用，不是跨端压力认证。
- Rust 真实解码《Volare》30 秒官方试听得到每声道 6,000 个包络值。原生新版打开 `data/AUDIO-002/Volare-波形验收.project.json`，显示真实左右声道／全曲概览和既有场景卡点；放大、播放、12.495 秒暂停、停止归零及全曲恢复通过。截图 `data/AUDIO-002/新版波形.png`。工程使用独立 ID 和随附音乐资源，音乐不入 Git／不随产品分发。
- 前端主包由 516.08 kB／gzip 155.19 kB 增至 616.27 kB／gzip 183.40 kB，新增约 28.21 kB gzip。既有大于 500 kB 的 Vite 警告仍存在；没有加入新的产品语言／外部运行时。BSD 许可证在构建输出中确认存在。

保留失败与限制：初次布局被全局表单样式覆盖，刻度与波形叠放、概览双声道超高，已修复并在原生截图确认。解码末尾非整数桶曾可能附加空极值，已加保护与回归测试。开发热更新出现重复 createRoot 警告，独立页面重新导航后恢复，产品原生入口未出现。原生路径选择的键盘自动化不可靠，最终通过路径／目录列表与文件的“打开”动作完成；没有改产品或系统绕开选择器。自动化未能派发按住拖动同时 Esc 的组合事件，取消代码保留，不能将该组合宣称为本轮实测通过。
