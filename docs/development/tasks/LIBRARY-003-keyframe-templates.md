# LIBRARY-003：已有关键帧灯效跨工程复用

状态：完成；基线 `9eacc42`，main，当前会话单写者。用户 `output/` 保留。依据 [ADR-092](../decisions/PRODUCT-ADR-092-keyframe-effect-templates.md)。以下保留实施过程，最终出口见文末。

范围：关键帧亮度模板格式 2、严格版本／能力检查，共用既有关键帧语义和 Schema；Rust 配方转换独立模块，桌面沿用文件审阅流程并展示实际曲线。核心／格式保护、UI 检查、正式应用跨场景导入和保存重开必须全部验证，不能只扩展导出按钮。

边界：不导出多属性 RGB、位置或控制宏，不新增求值器、设备协议、云服务或真实设备输出。原生验收使用独立副本。新格式与持久化能力先由 ADR-092 记录，再实现。

实现：文件 recipe 独立转换模块，格式号／配方一一对应；关键帧结构抽为共用 Schema 定义，Rust 顺序检查供场景／模板复用，来源额外能力随当前参数编辑保持。界面复用现有曲线路径计算绘制只读图及可展开精确数值；文件列表增加序号、灯具数和周期，避免真实工程里多个同名“渐入”无法区分。通用对话框只增加可选标题初始焦点，本次模板审阅使用，其他编辑器默认焦点保持。

初步验证：11 项模板 Rust 专项（原 7＋新 4）、287 UI、146 格式、类型／严格检查通过，全工作区／桌面构建继续。首次专项对 20% 时刻的预期忽略原编译器向上取整的固定点相位边界，已核对既有规则：原输出与复用输出逐值相同；改用可精确表达的四分周期验证端点，并新增非精确 20% 保持边沿不得提前的专门保护。未修改求值器或放宽输出断言。AJV 首次报告条件 Schema 的嵌套对象缺显式类型，已修正，严格模式全部通过。

浏览器组件验收：三种过渡曲线、展开精确值、标题初始焦点及取消后焦点恢复通过；截图 `data/LIBRARY-003/01-关键帧模板审阅组件.png`、`02-关键帧审阅初始焦点.png`。正式原生关键帧文件工作流尚未验收，不能作为完成出口。
