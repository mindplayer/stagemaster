# DEVICE-002：免配对加密 GATT 实板验收

日期：2026-09-29；基线 `5493c5a`；主工作区、当前 Astra 单一写入负责人。结果为本次 `feat(device): validate direct encrypted GATT and bounded flow control` 提交。上一轮为实质进展；本轮继续完整安装目标，未缩小出口。

## 本轮完成

按 [ADR-049](../decisions/PRODUCT-ADR-049-direct-gatt-session-validation.md)，将已有 Noise／有界分片核心接到实际 ESP32 和原生 btleplug。固件加密与 GATT 适配分别拆分；主机工具按发现、通知、收发、协议流程拆分，新文件均小于 300 行。没有往桌面页面加入试验入口，正常产品能力仍只声明诊断。

测试固件仅回送调用方刚发送的有界数据、回复加密保活；没有安装授权、节目读取、Flash 写入或输出。设备私钥每启动随机生成、只留 RAM；USB 公钥及启动身份固定本次无线对端，不信任无线自报公钥。它不是产品认领方式或云端授权。新固件不启用系统绑定，无配对窗口／系统设置操作；以前的系统记录未删除。

## 发现与修复

首轮 585,936 B 固件的原生握手失败，设备报告接收分片拒绝。修复后的明确日志显示：接收连接时 MTU 23，首次安全写入时已为 247，首包 104 B；此前用连接创建时的 20 B 预算拒绝了有效握手。现改为首次安全写入前读取实际 MTU，再冻结当前方向预算。未改变 5 秒分片、10 秒握手、6 秒加密租约。

使用逐片 write-with-response，20 B 发送预算的最大消息往返实测最慢 4970 ms，现场余量不足。核对 [Zephyr SMP BLE](https://docs.zephyrproject.org/latest/services/device_mgmt/smp_transport.html) 和锁定 btleplug 的原生队列／ready 回调后，增加显式 write-without-response 实验模式；要求特征声明支持，逐次 await 平台背压，每条完整消息仍等加密回复后再发送下一条。片段序号、认证、期限和失败断开不变。本机写成功绝不当设备完成。

## 实板结果

修复后 24 个验收连接通过（包含预期故障拒绝），覆盖三个成功批次和一轮连续传输；最初失败另保留。实际协商 MTU 247；20 B 是主机主动压小发送片段，不是 MTU 23 全双向实测。

| 路径／用例 | 实际证据 |
| --- | --- |
| 初次修复后确认写 | 握手／确认 331 ms；16 轮 1280 B 往返最慢 452 ms |
| 确认写完整批次 | 11 个连接；常规最大消息最慢 583 ms，小发送片段最慢 4970 ms |
| 连续发送完整批次 | 11 个连接；握手／确认 329～360 ms；常规最大消息最慢 254 ms，小发送片段最慢 251 ms |
| 连续传输 | 单连接 128 轮不同内容的 1280 B 消息＋回送，单方向 163,840 B；最慢 152 ms；之后 5 次加密保活通过 |
| 错误身份／上下文 | 错设备公钥、错连接上下文均在有界时间内拒绝、连接断开 |
| 消息故障 | 标签篡改、旧密文重放、缺第二片、重复第一片均拒绝／断开；连续发送路径约 90～124 ms |
| 半包 | 首片后停止，约 5215～5217 ms 物理断开（包含轮询／链路关闭延迟） |
| 公开心跳不续权 | 六次有效诊断心跳仍约 6101～6117 ms 断开，不能刷新加密租约 |
| 取消与恢复 | 半包取消后重连，新 Noise 上下文确认、最大消息／保活再通过 |
| 输出与内核 | 每轮读取确认输出禁止、自检通过；长连接期间播放内核计数持续增加 |

上述为受控台架样本，不宣称量产、长时稳定、手机后台或实际无线安装完成。163,840 B 是加密数据往返，没有调用 NOR 安装，不能把它写成“节目已安装”。旧 LESC 路线 27,648 B 后断开的根因尚未由本轮证明消除。

## 资源与保留项

确认写每轮空闲堆回到 41,044 B。连续发送开始为 41,044 B，在小片段试验后空闲稳定于 41,076 B；该 **32 B 残留变化的来源尚未定位**，不能宣称完全无残留。后续多次错误重连、长连接以及 128 轮传输未继续增长，当前通道前后均为 41,140 B；断开后 41,076 B 保持至日志约 256 秒。批次累计堆峰值 42,536 B，观察过程中仍有约 89 KiB 空闲。没有测量核心 0 任务栈高水位，也未与 Flash 擦写并行；正式安装集成时继续检查这些门槛。

代码核心的明文／密钥保护边界沿 ADR-047；本实验没有持久设备身份、可信时间、离线凭证或 24 小时文件播放许可。不能把每启动 USB 公钥固定用于产品日常连接。后续需独立可信开发准入，再对接云端生产凭据。
