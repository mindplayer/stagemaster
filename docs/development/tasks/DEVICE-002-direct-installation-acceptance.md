# DEVICE-002：免系统配对的实际节目安装验收

日期：2026-09-29；主工作区；本增量基线 `d2890d4`，结果为本次 `feat(device): deliver authenticated direct GATT installation` 提交。完整父目标仍以 `0a0b7e7` 为起点，未缩为连接或回送实验。当前 Astra 单一实现／审查负责人。

## 改动与复用

依 [ADR-051](../decisions/PRODUCT-ADR-051-development-gatt-installation.md) 将专用、随机、分角色开发凭据接到 Snow Noise IK、既有安全记录、权限 Gateway、Endpoint、ManagedWorker、双槽 NOR 和桌面任务服务。没有新增密码算法或重写安装／取消／恢复状态机；沿 ADR-049 的成熟 SMP 分组及平台背压经验。有线仅刷机／观察，无线通过新 eda0 服务完成全部节目字节传输。

本轮新增配置生成／解析、原生有界通知接收和加密通信、固件连接协议适配、受控桌面凭据注入。默认主机无配置时只诊断；旧 LESC 适配需显式实验特性，不会在正常连接时触发系统配对。修正工程检查区“安装尚未接入”的过期文案，改为在节目安装中独立核验权限和结果。

参考和边界沿 ADR-046～051：CoreBluetooth 的定位 UUID 不等于云端身份；Noise 身份证明不自动授予业务权限；云端将拥有设备公钥、归属和权限修订，当前开发配置不是云端签名凭证。具体调用见[接口](../../module-api/development-gatt-configuration.md)。

## 保留的失败与后续门槛

首次固件 `--locked` 报本地特性依赖需更新锁文件，单独离线 metadata 后再按原命令构建；早期主机 String／字符串类型错误、Clippy 长函数／分支／默认特性 Result 提示，以及故障工具初稿使用未开启 alloc 的 Zeroizing Vec／访问私有字段等编译错误均保留日志，最终修正通过。USB 观察命令曾请求超过工具 600 秒上限，解析器拒绝且未打开串口，后按有界 600 秒执行。没有放宽测试断言或隐藏失败。

此出口覆盖 DEVICE-002 的**专用开发身份下，电脑到本台 ESP32 的节目安装闭环**。云端认领／签发／转移／撤销、24 小时当前文件许可及断电可信计时、生产密钥保护／固件签名、安全启动、其他平台、真实物理断电及长期压力、硬件任务看门狗和完整栈高水位，仍是后续商业／输出接入门槛。此前回送实验出现的 32 B 占用差异没有根因结论；本轮实板基线恢复不能推导所有构建无泄漏。不得把开发编译入镜像的私钥作为量产方案或宣称代码不可逆向。
