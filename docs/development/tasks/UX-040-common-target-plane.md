# UX-040：共同指向的平面选点

状态：完成，结果为本次 `feat(position): add shared target plane picking` 提交。基线 `615f68f`；主工作区单写者，output 不动，持续 goal active。

问题：现有共同指向只能输入 X／Y／高度，用户需要对照舞台猜坐标；与场地空间的关系不可见。依据 POSITION-001／[位置契约](../../module-api/positioning.md) 及 AUDIT-001 U01／U03，增强静态位置编辑操作。

成熟参考：[grandMA3 XYZ 官方说明](https://help.malighting.com/grandMA3/2.5/HTML/xyz.html)（本次正文标 Version 2.4）使用世界位置的米制输入，分清 XYZ 和轴角；吸收空间目标比逐灯轴值直观的方式。复用已有 StagePlanObjects、相机与平移／缩放组件，不新增绘图引擎。边界：本次画面是选点平面、标高独立，应用后通过现有 Rust aim 原子求解／记录；不等同连续 XYZ 跟随、光束预演或物理输出。

实施：从 PositionPanel 抽取独立读数／共同目标编辑职责；独立点选手势与有限米值工具，复用共享场地绘制。左键选点／拖动目标，抬手才更新同一草稿；手势 Esc／失焦／捕获丢失／尺寸变化取消，保留原草稿；明确平移模式、缩放、全场与定位目标。方向键 0.1 米、Shift 0.01 米，既有 X／Y／高度精确输入保持可用；越界不产生无效坐标。切模式／选灯仍走已有草稿队列，未知／未布置灯保持 Rust 错误拒绝，选点不自动发送命令。

无公共契约、存储格式、播放时间或控制权改变，不需新增 ADR。验收包括坐标方向／相机比例／边界精度、点选与拖动／取消、焦点／键盘、平移缩放与输入不互相覆盖、混合和未布置提示、真实多灯原子求解／撤销重做／保存重开；未授权真实输出保持不触碰。新增模块保持内聚，原 360 余行 PositionPanel 本次抽取明确职责。
