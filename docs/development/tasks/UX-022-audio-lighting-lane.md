# UX-022：音乐灯光段落与切换边界

状态：完成；基线 `dbcd2f5`；结果为本次 `feat(ui): edit lighting segments beneath the audio waveform` 提交；当前会话、主工作区。接续 AUDIT-001 U06，不结束持续 goal。

## 审查与边界

借鉴 AUDIT-001 已核验的剪映多条内容轨、选中属性及直接边界编辑，复用 WaveSurfer 的时间视窗和唯一原生音频／灯光会话。在波形下显示已有绑定场景卡点的持续区间；仅节奏标记不切断场景，首个绑定之前为灯具默认值，最后一个场景延续至音乐结束，与 Rust AudioTimeline::scene_at 一致。

选择段落只选择对应卡点；双击定位不自动播放；拖动边界修改已有卡点时间、一次手势一次工程事务，Esc／指针取消恢复；键盘微调及右侧精确时间复用现有编辑。段落以相邻绑定点为边界，不提供会误导为独立时长的整段平移／叠层／渐变手柄。界面明确现有硬切，完整多轨片段与跨场景渐变需之后独立核心设计。

不改公开 JSON、音频或播放协议，不另建灯光求值器。时间区间投影、边界约束、片段显示和手势集成分别组织。投影只用于编辑显示，Rust 保持实际播放来源。边界拖动保持绑定场景顺序，排除占用的毫秒时间；波形播放头与段落使用同一视窗与宿主样本。

## 验收

区间投影：无绑定、首段默认值、混合纯标记、末段、裁切相对时间；边界不可跨邻段、不与其他标记重合，毫秒精度。真实音乐和 UE 查看当前场景、定位、调整边界、取消、单次撤销／重做、保存重开，缩放／平移与短段落可达性。类型／回归／桌面构建与视觉检查。测试仅副本，设备断开。
