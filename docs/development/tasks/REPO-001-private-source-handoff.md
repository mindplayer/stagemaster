## 构建入口调整

旧 `package-renderer.mjs` 将 UAT 构建与 Game 资源报告验收绑定；已有原始 Game 由于报告目录沙盒权限失败，不能把该命令直接当作同事仅构建入口。增加显式 `--build-only`：仍实际构建并检查包内静态依赖，记录 `component-built`，不启动验收或登记 `component-verified`。无参数保持原先严格报告要求；后续整包仍使用已有目录映射和签名流程。报告阶段抽成职责独立的小模块，无 Rust、UI、播放语义、设备或持久工程格式变化。
