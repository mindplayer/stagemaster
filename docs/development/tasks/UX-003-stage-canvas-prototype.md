## 视觉与行为

视觉基准：`data/ui-design/2026-09-21/01-stage-canvas-timeline.png`，延续用户选中的第一版。基础资产为 Image Gen 独立生成的舞台场景插图；不把整张 UI 图片当成应用。

核心体验：灯组／预设选择、灯光片段的选择／移动／长度修改、属性与渐变数值编辑、预览定位／播放、保存 Cue、Cue 列表、独立模拟 GO。编辑草稿、已保存 Cue 和正在运行的模拟快照分离。切换 Cue 不丢未保存草稿；撤销编辑不倒退模拟现场运行。

演示数据仅存内存，刷新重置；所有输出明确为模拟。舞台插图用于交互反馈，不声称真实光学预演。音乐只作为参考监看，不建设媒体制作引擎。

## 验收

1. 初始 Cue 12 播放、13 待执行、14 编辑，三个状态同时可辨。
2. 编辑、预览、保存 Cue 14 不改变当前模拟运行的 Cue 12；GO 才推进现场模拟状态。
3. 拖动／数值编辑结果一致，时间范围合法；多次编辑能撤销／重做。
4. 灯组、片段和属性同步；未选择时不误改其他对象，搜索无结果有反馈。
5. 在浏览器验证核心流程与至少一个较小桌面尺寸，不遮挡固定 GO 控件。
6. TypeScript 检查、生产构建、模拟状态隔离与编辑边界的针对性测试通过；视觉 QA 与浏览器错误检查有实际记录。

本轮不验收真实灯具、精确时钟、光学仿真、完整时间线执行语义或商业交付条件。
