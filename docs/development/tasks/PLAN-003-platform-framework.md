## 当前判断

- Rust 无界面播放／设备运行、音频适配和中立预演已有基础，适合继续演进，无证据要求重选主技术栈。
- 桌面仍以 Tauri 的 Session 组装编辑／音频／预演，不能据此宣称 UI 崩溃后专业主机仍独立演出。跨端应用服务与执行生命周期需要可运行验证。
- 设备核心已分离传输，但主机 Transport 仍带首版诊断／扫描形状、桌面固定 BLE。第二种承载必须先证明会话、安装和业务控制没有隐含 BLE 依赖。
- 单列表／单控制者不足以证明专业多执行器、面板接管和多时钟同步；本机音乐及 UE 闭环也不能替代跨设备测试。
- 云端分发、生产身份和授权仍有未实现环节；工程保存、包安装、激活和播放许可必须保持独立可对账。

证据及待验收场景已合并到 ADR-097 的“代码基线与优先验证”，不再建立重复功能清单。
