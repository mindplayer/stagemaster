# AUDIO-020：演出循环区段

状态：实施中；基线 `c8df526`；main 主工作区；当前会话单写者；保留用户 `output/`。接续 AUDIO-019 与 AUDIT-001 U06，依据 [ADR-096](../decisions/PRODUCT-ADR-096-performance-loop-sections.md)。

完整目标：多个可保存区段、固定次数／持续循环、精确编辑／锁定／启用、运行圈数、本圈结束后继续与取消退出、暂停定位停止、音频灯光共同游标、一次历史／保存重开。核心阶段不算本任务交付，不以单个临时循环替代正式编排。

实施次序：独立整数调度核心及逐刻度参考验证；工程格式／命令／预算；有界原生音频适配与会话版本；组件编辑／时间线显示／运行控制；完整回归、实际音乐／UE、取消历史与保存重开。与本任务无关的真实设备、刷机、网络部署不操作。

验收要点：半开端点、相邻和空隙、次数 1、多段有限与无限混合、边界退出／取消／旧区段请求拒绝、暂停后续接、定位重置圈数、超大增量不逐圈循环、非法输入原子、容量与数值极限；后续宿主样本输出和位置一致，内存有界，失败不覆盖当前可用状态。
