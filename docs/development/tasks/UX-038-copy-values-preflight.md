# UX-038：复制属性的写入预览与目标检查

状态：完成，结果为本次 `feat(library): preview copied values and validate destinations` 提交。基线 `eecab5f`；主工作区单写者，output 不动，持续 goal active，接续 U02。

实际缺口：复制窗口只能选择来源／属性，目标为其余全部已选灯具；既不显示本次源内容，也不指出哪台缺少属性，导致只能提交后才知道不兼容并退出窗口重选。切换来源还自动全选所有属性，扩大已明确范围。

依据：沿用灯光预设的按属性复用、EFFECT-005 的来源／目标预检、UX-027 的检索组件和现有 Rust copyValues 原子写入。复用资源搜索和 ValueTable，不新建核心求值器。TS 只做当前投影可见的缺项／功能选择提示，Rust 仍承担完整合法性、版本冲突及事务验证。范围交集不作跨灯型语义转换；同名键不代表实际光学一致。

范围：从 PresetEditor 独立 CopyValuesEditor；源搜索、当前记录值／释放或未记录跳过摘要，目标名单可勾选／搜索／分页，明确全目标操作与筛选隐藏计数，逐目标属性／功能值检查，显式只选可写入目标。源切换保留范围交集，空选不扩大；目标选择在窗口内独立保存，来源排除在实际写入外。显示写入量和无有效源／无目标／超限问题；失败保留输入，取消不改工程。

接口评估：只在现有 copyValues 参数中缩小 fixtureIds／attributes，不改 IPC、持久格式、Rust 语义。仍只复制来源场景已记录的独立值，引用解为值、释放／缺项跳过；目标必须支持所选属性，功能按当前核心的键／位置校验，不复制原始 DMX 字节。

出口：纯函数包含混合型号、缺属性、功能缺项／离散位置、释放缺项／预设引用、空源和单纯连续值；真实组件搜索／分页／隐藏选择、源切换／嵌套取消、失败和命令内容；原生副本的实际复制、撤销重做、保存重开／源未改。UI／类型／格式／桌面、相关既有 Rust 复制回归及文档状态通过后继续。

实现：独立 89 行只读投影预检、114 行复制窗口、139 行目标列表与局部样式；PresetEditor 减至 167 行，ResourcePool 401 行仅改导入接线，已评估无需在本工单拆 无关资源池职责。目标列表复用规范化搜索、50 项分页、隐藏选择计数；来源复用 ResourcePicker。源交集／选中目标属于窗口局部草稿；复制命令只发送有效来源外的明确目标。空源时“仅选可写入”禁用；最终提交仍走 Rust 校验。

验证：242 UI、最终类型／格式／桌面通过；既有 Rust library 8 项与 fixture_function_exchange 1 项通过，覆盖事务回滚、引用解值及功能身份／物理重新编码。新增 UI 纯测试覆盖全部／缺失目标、释放／缺项跳过但目标仍需支持完整掩码、空范围／无来源／无记录、10000 项边界、功能键缺失与非零固定档位、不同物理范围允许复制、连续／功能类型不混写。
