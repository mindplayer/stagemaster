## 本轮验收

布置资源与编排资源按任务切换；选房间可编辑其名称、尺寸、形状、地面标高和净高；平面／立体投影读取同一布局，当前房间聚焦／全场与顶部隐藏独立于编辑数据。空间编辑复用已有输入草稿、错误定位、撤销与恢复机制，工作区切换不丢失片段／时间位置。

验证三空间布局、独立高度、L 形轮廓、鼠标画面选择与键盘列表选择、错误跨房间定位、取消／单次撤销、刷新恢复以及桌面与窄视口。回归颜色、目标点与灯具草稿。

本稿不实现完整房间创建／共享墙拓扑、门洞编辑、自由三维镜头、物理遮挡、正式保存或播放；不改 Rust／Schema／设备。通过此稿收敛交互，再按 ADR-010 建立正式契约和实施任务。

## 结果与验证

结果为本次 `feat(ui-design): add multi-space layout interactions` 提交。沿用既有深色界面、输入草稿和分范围历史；新增局部 `spaces` 展示组件，房间几何参数与查看状态分开。自适应空间列表、按形状展开属性、双视图、顶部隐藏、原生边界把手均接通。本地状态 v2 可恢复旧 v1；未更改项目格式。

- 三空间初始净高分别 6／3／3.8 米，展厅地面 0.6 米。修改展厅净高至 5 米、地面至 1.2 米，选择演出厅后撤销准确返回展厅并恢复地面 0.6 米，净高仍为 5 米。
- 净高 99、缺口宽 6、空名称显示字段错误；切换空间／编排后定位回展厅，几何保持有效值。刷新保留空名称草稿及原空间，恢复按钮清除错误；Esc 还原高度／缺口输入。
- 选择画布中的演出厅，切 L 形得到 87.0 平方米，撤销恢复矩形。展厅 6×6、2.5×2.5 缺口显示 29.8 平方米；宽 6.1 时修正浮点显示后为 30.4 平方米。
- 按住宽度把手移动 55 像素，数值 6→7，手柄随之移动，相机尺度保持；松手单次撤销恢复 6，无多余历史。深度 6→7 后 Esc 恢复 6，无新增历史；左右键将宽度微调到 6.1。
- 查看全场／仅当前、平面／立体、顶部显示切换有效；隔离时一个空间对象，打开顶部显示时生成对应顶面。切视图不新建撤销记录。
- 回归颜色修改、档案名称修改与独立撤销、返回原片段和时间位置；编排与布置往返保持有效。既有目标点数值编辑仍正常，未重测未改动的目标指针求解。
- 视觉对照、窗口适配和浏览器错误检查见根目录 `design-qa.md`。脚本语法、片段约束、本地文档引用及差异检查通过；未运行与设计稿无关的 Rust／产品测试。

本轮可操作设计通过自查；持续复用已有组件和交互，不新增语言或依赖。三个预置房间仅为设计验证，不能写入正式入口冒充工程数据；“连接通道”不表示已实现门洞或连通性计算。宽深调整固定空间原点，未处理邻房重叠、共享墙、灯具附着和安装冲突，这些属于正式契约及几何实施验收。
