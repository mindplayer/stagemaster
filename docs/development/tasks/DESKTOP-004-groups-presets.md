# DESKTOP-004：灯组、预设与属性复用

状态：done（本轮增量）。日期：2026-09-27；负责人：当前 Astra 会话；工作区：主工作区；基线：`8513eee`（干净）。依据 [ADR-015](../decisions/PRODUCT-ADR-015-groups-presets.md)。

## 本轮交付

- 有序灯组创建、召回、追加／扣除、成员排序、复制、改名、删除。
- 预设按所选灯具与属性记录；查内容／依赖、引用或独立值应用、三种更新策略、复制、改名、解除引用与删除保护。
- 选择顺序变换、属性复制；所有持久编辑经 Rust 原子命令，复用历史／保存及现有离线编译。
- 组件化资源池接正式工作台，检查精确输入、搜索、取消、错误、上下文与保存重开。

边界：逐灯规范化属性；无通用共享预设、嵌套预设、动态效果、现场编程器、多执行器、真实输出或硬件变更。本轮不是完整 MA3／Titan 替代品。

## 验收记录

结果版本：本次 `feat(desktop): add ordered groups and reusable preset workflows` 提交。接口见 [editing-library](../../module-api/editing-library.md)。

- 核心：新增独立 library 模块，共享单一预设解析器；8 项领域测试涵盖组顺序与往返、非法成员、掩码与释放、引用更新与不可变编译计划、三种更新模式、删除／解除、复制兼容及失败批次回滚；Session 新增整体历史／预览失效保护。
- 检查：86 项 Rust、28 项 UI、50 项格式、4 项 Sites 全部通过；cargo fmt --check、严格 Clippy、TypeScript 检查、桌面构建通过。无新运行依赖或语言。
- 原生：八灯有序记录，反序后再交换首两灯，保存顺序为 7、8、6、5、4、3、2、1；空名称拒绝且聚焦；颜色预设仅 24 项 RGB，不夹带亮度。
- 引用：场景一与二共用预设，从 #3979FF 更新为 #E94057 两者同步；场景一解除引用后再更新为 #10A0E0，场景一仍 #E94057，场景二仍引用且显示 #10A0E0。更新窗取消不改预设；依赖列表准确列出场景及“晚场灯光”。
- 恢复：被引用删除报出具体场景；勾选保留数值后删除，颜色不变；一次撤销同时恢复预设和全部引用，重做再次删除，再撤销可恢复。复制预设自动选中副本，副本无原场景依赖；撤销后工程重新回到已保存状态。
- 复制与上下文：从所选顺序首灯向另七灯只复制亮度，混合亮度统一 30%，RGB 引用保持；撤销还原。搜索一灯时仍保留八灯选择，明确显示七灯隐藏。窗口关闭请求遇到编辑窗被阻止并聚焦输入，不丢草稿。
- 持久化与预览：原生保存重开后顺序、预设、24 项引用完整；文件内容另以脚本核对。离线预览最终通道 1–4 为 204/16/160/224，符合场景二 80% 与 #10A0E0。全部仅内存 DMX 编码，无物理输出。
- 布局：约 1440×940、1100×800 窗口检查；灯卡显示选灯次序，灯具网格限高滚动，资源操作换行可达，固定属性栏保持。验收后恢复窗口并退出验收工程，重新打开欢迎页。
