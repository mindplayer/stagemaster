## 变更与复用

依 [ADR-039](../decisions/PRODUCT-ADR-039-host-install-io.md) 和[接口](../../module-api/host-installation-io.md)，保留单一 `Service` 连接任务，让保活与安装消息片段串行使用适配器。复用 Tokio 有界通道、oneshot、计时器，以及现有协议 `Assembler`、请求／响应编解码；不自建上传状态机或另一物理连接。

增加可信认证适配提供的 `InstallationPeer`，与描述核对设备／启动／认证／真实安装声明／传输版本和预算。描述不能授予权限；原生 `Ble` 默认仍返回无权限。新 Rust 方法未接成外部原始帧 IPC。完整原生认证、安全绑定、生产许可及正式 GATT 仍未完成。

一个请求预算包含排队和执行；取消尚未发送的 Future 不触发 I/O，已开始则释放连接。回执匹配完整序号（含低字节相同而高位不同的保护）、命令、会话和启动；半包、不确定写入、提前／多余回执、超时及撤销均失败关闭。上传器继续维护取消与重连对账，实际已提交时返回已安装。
