最终原生：内嵌 UE 连接／跟随音乐，工作照明关闭后实际显示循环段落的蓝色光斑与背景灯，数十秒后仍正常回环。开启后的短时工程忙提示自动恢复，未据此声称启动绝无延迟。二次收紧 CSS 特异性后工具栏单行精确起止，双声道波形同时可见；关闭循环保留 1.760 秒。截图 `data/AUDIO-005/01-循环三维初验.png` 保留初版布局，最终 `02-局部循环属性.png`、`03-收起循环工具.png`。当前已保存副本、音乐暂停 1.760、循环关闭、UE 关闭、设备断开；原 Volare 摘要未变。
