## 实施与审查

参考 MA Phaser 和 Titan Shape Generator／Key Frame Shapes 的循环属性、独立速度／相位、灯序机制，取舍与官方来源见 ADR-021。新增场景 effects 和 required capability；旧静态文件照常读取，新能力由不支持的读取器拒绝。没有新增运行依赖。

- Rust 工程模块独立维护效果命令、引用校验、复制身份与编译；纯播放模块用 Q16 整数求值。延时保持上一步可见值、渐变混合动态目标、自动衔接按精确边界求值；暂停／继续不补跑，停止回默认值。
- 编排页提供亮度呼吸、按顺序追逐、双色循环；精确周期、两端值、展开、相位、反向、灯序增删重排、启停／复制／删除，复用统一撤销和保存。复制默认停用，冲突保留草稿供修改；RGB 可明确选择同时点亮灯具。静态参数标明被效果覆盖。
- 单场景与场景列表复用唯一预览实例、代次和控制序号；编辑后重载。三维监看使用同一 Rust 输出，UE 不拥有效果时钟或求值逻辑。接口见[动态效果契约](../../module-api/lighting-effects.md)。

审查结论：在本轮亮度／RGB 绝对效果边界内通过。模块、持久身份、公共格式兼容性和时间规则均已明确；不把两端曲线模型扩称为完整专业效果系统。

## 实际验证

- Rust workspace 137 项通过：新增 8 项内核、5 项工程、2 项宿主测试。覆盖精确端点／相位／反向、迟到与逐帧一致、延时渐变、暂停重触发、停止／有限结束、计划容量、保存重开／复制身份、冲突原子拒绝、静态值恢复、场景与列表同语义、同批次撤销及三维／监看输出一致。
- UI 41 项、工程格式 63 项通过；类型检查、rustfmt、严格 Clippy、桌面构建与差异检查通过。日志在项目 `logs/EFFECT-001-*.log`；UE 源码本轮未改，未重复引擎测试或构建。
- macOS 原生独立验收工程：四灯选组、追逐灯序重排、零周期错误定位后修正、暂停 3.98 秒保持、双色添加后旧预览失效、撤销／重做、呼吸与追逐冲突后保留草稿并停用保存、启停／复制默认停用／删除，以及保存重开保持三种效果与灯序。
- 应用内三维实际运行双色与呼吸，剖视／关闭工作照明后观察到四灯光束和落点随核心输出变化。验收项目和截图在 `data/EFFECT-001/`；仅离线数值和画面，没有物理 DMX 输出。
- 最终构建补验：编辑名称后 Esc、复制后点击取消，均返回原三项效果，保持“已保存”且撤销不可用；取消没有写入工程或增加历史。
- 正式用户窗口有未保存编辑，未保存、关闭或重启该窗口；用临时独立标识的验收应用隔离测试。正式应用构建已更新，用户保存后重新打开即可加载新版。
