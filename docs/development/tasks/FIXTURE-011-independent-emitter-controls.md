## 范围和验收

1. Rust 独立单元归属、能力声明、连续属性建档／读入校验、中文投影、模式文件与换模式；复用准确属性编排、手动、预设、渐变和编译，不另写播放器。先以旧 API 复现新定义拒绝，非法输入／能力／批次均原子失败。
2. 总控分别验证有根级总调光、没有根级／有单元 dimmer、纯 RGBW 三种映射；非零起址、8／16 位任意粗细、端点、空余槽与白光输出，释放与零值分开。旧单光源行为保持。
3. 独立 UI 草稿工具／建档组件，增删、复制、精确默认／粗细、稳定标识及名称、错误定位、取消、搜索和一次历史；场景中文标签、参数分类／稀疏预设保持准确单元目标，不静默扩大为全部属性。
4. 三维只保留灯体／轴并明确未模拟，编辑与播放不伪造多光源，现有唯一视窗保持。真实组件及正式 .app 经真实 Rust 宿主保存重开、两灯配适／参数／模式交换，保护原工程、默认最近目录和 output/。无音乐、后台、UE 或设备真实输出。
5. 实际相关及全量 Rust／UI／格式、类型、严格 Clippy／fmt、正式构建和差异检查；证据 data/FIXTURE-011/，日志 logs/fixture-011-*，缓存／临时目录显式项目 tmp/。失败留证，修复后重验，不写未执行的通过。

本增量不支持单元功能频闪／轮盘或白光光学预演，不发布测试模式为实灯；声控／自走、未确认宏及复位仍屏蔽。完成后更新实际结果、自审、STATE，提交相关文件，继续下一个依赖满足的 H3 增量。完整 goal 保持 active。
