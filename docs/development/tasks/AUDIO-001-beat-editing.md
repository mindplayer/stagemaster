# AUDIO-001：音频波形与灯光卡点

基线 `79b584d`；主工作区；Astra 单一负责人；完成本机单轨卡点增量。结果为本次 `feat(audio): add native music and lighting beat editing` 提交；依据 ADR-053。

写入范围：独立 `stagemaster-audio` 媒体文件／波形／本机音频适配，`stagemaster-project` 音频编辑子模块／Schema，桌面音频桥及 Session 生命周期，界面音频组件与 host 契约，相关测试／文档。每个模块按职责拆分，不堆积单个大文件。

完成范围：真实单轨导入、波形、播放／暂停／定位／裁切、手动打点与场景引用、试听驱动已有灯光效果、撤销保存重开／媒体归档与重定位。独立于 ESP32，无物理 DMX，保留用户两个已有窗口及未保存内容。

验证：核心负面输入／引用／定位一致性，媒体流式容量和错误路径、原生音频与真实 UI、工作区测试／严格检查／类型／构建。云端同步、手机后台、自动节拍、混音、多轨和跨设备精确同步不在此增量，不能按占位实现计数。

## 实施与验证

新增独立 Rust 媒体资源／流式波形／本机试听 crate，工程音频编辑模块、宿主桥及六个界面模块；新增产品源文件最多 354 行。原工程灯具和舞台内容没有迁移或替换，音频能力有显式版本。详情见 [模块契约](../../module-api/audio-editing.md)。

- 全工作区 432 项 Rust 测试及文档测试通过（含 application feature），日志 `logs/audio-001-workspace-tests-final.log`。新增保护覆盖原子编辑、能力／引用校验、卡点边界和反向定位相位、流式波形、取消／超限／内容错配。补充同摘要归档损坏修复及缺失资源后，媒体 3 项复跑通过，日志 `audio-001-media-tests-reviewed.log`。
- 严格 Clippy 及 Rust 格式检查通过；UI 类型与 81 项测试通过，格式验证器 78 项通过；桌面构建通过。日志均在 `logs/audio-001-*`。依赖为 rodio／CPAL／Symphonia，不加入 FFmpeg 运行依赖。
- 显式本机音频输出验收 WAV／MP3／FLAC 各通过播放、暂停位置保持、定位、继续、裁切结束、结束后重播、停止；32 秒源文件 1,600 峰值（6,400 B 单份），600 ms 后软件消费位置约 593 ms。日志 `audio-001-native-{wav,mp3,flac}.log`。这不是麦克风或 DAC 到声测量。
- 原生窗口从系统文件选择器导入原创低音量测试音频，播放中打点，精确改为 2.000 秒并绑定“环绕波浪 · 01”，保存、关窗、新构建重开，波形和卡点恢复。工程位于 `data/AUDIO-001/音频卡点验收.project.json`，同名 .assets 内 SHA-256 与原音乐一致；灯光／舞台与圆弧剧场源工程逐值一致。
- 临时移开本轮自有缓存及归档文件后，原生界面明确提示缺失；重新定位原 WAV 后恢复，摘要一致；已还原归档。用户原正式窗口及连接验收窗口未关闭，后者未保存修改保留。
- 组件隔离页复测拖动 120 px／60 px 每秒，卡点从 8.000 精确移到 10.000 秒，抓取偏移不引起跳变；一次撤销回到 8.000；重复 2.000 秒拒绝且焦点回到时间输入，取消保留原值。隔离页不进产品入口。

保留的失败与修复：缺少 Waveform Debug 导致首次测试编译失败；能力键最初使用大写，现改为 `media.audio-editing`；Tauri 构建与 workspace doctest 同时写同一 target 导致一次依赖变体读取失败，顺序执行原测试命令全部通过。原生文件选择器操作最初绑定旧窗口，重新取得当前弹窗句柄解决，无需用户手动确认。三维初次启动缺 Node 构建期路径，使用既有开发脚本的 `STAGEMASTER_NODE_BINARY` 配置重建，不改变用户系统或 UE 安装。

实际内嵌 UE 已连接圆弧舞台：试听播放自动切换“跟随播放预览”，渲染状态为“正在执行”，结束为“已暂停”，舞台出现对应蓝色灯光。首次画面需点重新连接，随后成功；这是现有串流启动恢复路径，首次自动连接稳定性仍需后续专门改进。没有修改其他窗口的预演。

用户追加要求真实音乐并举例 Gipsy Kings《Volare》。已从 [Nonesuch 官方专辑页](https://www.nonesuch.com/albums/volar-very-best-gipsy-kings) 下载其公开 MP3 试听片段（30 秒、481,070 B，非完整曲目），原生导入波形并播放成功。来源摘要保存在 `data/AUDIO-001/Volare-来源说明.md`，音乐不进 Git／不随产品分发。用户随后正在操作音频验收窗口，自动化已让出；目前该窗口为 Volare／未保存，原先保存到磁盘的 32 秒测试工程仍保留，不能从外部覆盖。此事实不影响前述已完成的保存／重开验收。

## 出口与后续

接受本机单轨卡点编辑增量。尚无自动节拍识别、多轨、渐变卡点、视频或 ESP32 声光同步；当前卡点绑定场景是隔离硬切，场景内原有效果继续运行。资源缓存清理界面、音频输出延迟校准、长时压力和其他平台待后续。不要将有限测试描述成任意文件永不内存溢出，也不把音频带入现有 ESP32 灯光执行包。
