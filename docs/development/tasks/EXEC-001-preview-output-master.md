原生正式应用打开 `data/EXEC-001/Volare-预演总控验收.project.json`：

1. 精确输入 40%，工程仍已保存且无撤销项；熄灯后跨页保留。101% 显示范围错误，焦点保留，Esc 恢复 40%。音乐裁切输入错误 0 时，解除熄灯仍立即可用；取消草稿恢复 30 秒。
2. 原生发现全局输入样式使百分比框过宽；修正独立选择器和固定尺寸后重建，导航／资源／属性按钮保持可用。重开总控回到 100%／未熄灯。
3. 1% 试听音量下启动音乐与唯一内嵌 UE，设 40% 后熄灯。约 7.1 秒熄灯，15.1 秒解除，25.120 秒暂停，播放游标未重启；灯光恢复到当前片段。三维 80 灯／66 座正常。截图 `data/EXEC-001/01-播放中熄灯.jpg`、`02-解除后恢复40亮度.jpg`。
4. 鼠标拖动到 87% 后音频仍暂停 25.120 秒；键盘聚焦推杆后 Left 从 50% 到 49%，Home 到 0%，显示持续“已抑制”；End 恢复 100%。结束时熄灯解除、UE 已关闭、设备未连接；独立工程已保存且未产生工程修改。
