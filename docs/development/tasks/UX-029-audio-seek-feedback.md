# UX-029：音乐定位意图与宿主回执

状态：完成；结果为本次 `fix(audio): preserve seek intent across native replies` 提交；基线 `fb34318`，主工作区、当前会话。AUDIO-003 原生验收发现 32 次 10 ms 方向键从 1.760 最后停在 2.000，而非 2.080。继续 AUDIT-001 U06／U07，不结束 goal。

原因边界：进度条受控值直接使用宿主较旧位置，发送中的定位意图没有留存；轮询也可能在同一 epoch 的命令期间读取旧状态。保留 Rust 权威声音／灯光时钟；界面临时目标仅表示“定位中”，不会推动三维或实灯。命令回执后回归实际位置，失败／切工程／范围变化清理；按键应在最新意图上累加。

实施：独立有界用户命令队列（最多 32 个待执行批次），仅合并相邻同上下文的单条 seek／volume；暂停、停止及 seek→play 原子序列保序、不跨越。轮询在命令活动期间不采信结果，使用队列修订标记拒绝迟到读；仍复用既有 runAudioCommands 的代次检查／失败停止。宿主数据和进度呈现解耦，共享三维进度／辅助定位／试听音量控件接回执前目标。UI 内部状态变化，不改工程或设备协议。

验收范围：延迟回执／旧轮询、快速方向键、队列合并及上限、播放／暂停屏障、错误及切换取消；进度呈现变化不应写入工程历史。音频灯光编译不重复实现。
