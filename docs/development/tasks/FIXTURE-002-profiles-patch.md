## 交付与审查

[主动工作流审查](FIXTURE-002-workflow-audit.md)记录必要缺口和后续顺序；[ADR-024](../decisions/PRODUCT-ADR-024-fixture-authoring.md)先于公共 API 实施；[运行接口](../../module-api/fixture-authoring.md)区分工程档案、实例、物理映射与预演。借鉴 Titan 的工程内档案锁定／显式换灯与 GDTF 的粗细有效位顺序，复用现有线性格式、Rust 编码器、Session 历史和有序选灯组件，未引入依赖或第二套播放引擎。

- 正式“灯具 → 灯具模式库”支持搜索、创建、复制、未使用模式编辑／删除、使用列表和通道分布。支持调光、完整 RGB、调光加 RGB 的任意 8/16 位映射、非相邻／粗细反序、精确默认值及完整占用宽度。
- 使用中模式禁止原位编辑／删除；复制后明确替换，相同属性集合、数据类型和混合语义才允许。保留灯具身份及场景、效果、灯组、预设、灯位和挂接；默认值变化在确认面板提示。
- 配适表支持有序多选、筛选结果全选、隐藏选择计数、仅已选；批量配适／换灯复用选灯器，可反序和精确重排、指定线路／地址／间隔、寻找可用连续空间和预览。512 通道占用图按域和线路统计，点击定位灯具并清除阻挡筛选。
- 整批冲突和越界原子拒绝，错误包含灯名及地址；草稿保持并定位输入。模式草稿纳入保存／导航／关闭流程，取消不提交。一次撤销／重做覆盖整个事务，旧预览失效。
