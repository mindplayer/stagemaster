## 30 W 图案摇头灯：11 通道

来源：4 张照片，依次为封面、机身菜单、9／11 通道表、11 通道表续页与机身微调；以及用户“0–9 是一个颜色，以此类推”和“水平 540°、垂直 270°”的补充。行程来自用户现场说明，照片本身未写；只适配用户常用 11 通道，不把 9 通道的地址套入。

| 通道 | 功能 | 确认内容 |
| --- | --- | --- |
| 1／2 | 水平粗调／微调 | 各 0–255；用户确认总行程 540° |
| 3／4 | 垂直粗调／微调 | 各 0–255；用户确认总行程 270° |
| 5 | 色盘 | 0–139 选色，每 10 值一档（用户补充）；140–255 自动换色，由慢到快 |
| 6 | 图案盘 | 0–63 固定图案；64–127 抖动；128–255 自动换图，由慢到快；固定和抖动子区间未给 |
| 7 | 频闪 | 0–255；关闭／常亮分界与速度方向未给 |
| 8 | 调光 | 0–255；需实测方向／关光端点 |
| 9 | 两轴速度 | 0–255；速度方向未给 |
| 10 | 自动模式 | 0–59 其他通道作用；60–84／85–109／110–134／135–159 为自动模式 3／2／1／0；160–184／185–209／210–234／235–255 为声控模式 3／2／1／0 |
| 11 | 复位 | 250–255 持续 5 秒；其余数值未描述，不能推定还有其他功能 |

第 5 通道的选色档：1＝0–9，2＝10–19，3＝20–29，4＝30–39，5＝40–49，6＝50–59，7＝60–69，8＝70–79，9＝80–89，10＝90–99，11＝100–109，12＝110–119，13＝120–129，14＝130–139。档位名称暂不指派红／绿／白，也不宣称一定是 14 片实物色片（可能包含开放／半色等，待实测）。颜色步长不能外推到图案。

用户确认总行程后仍需核对通道零值对应姿态、轴方向和机身反向设置，不能直接假定中心值必定垂直向下。

机身菜单包含 11CH／9CH、控台模式 SL 1、无信号行为（归零／自走／声控／保持）、两轴反向及复位。续页提到 H／Y／C／G 的机身电机偏移与保存操作；这些是设备设置，不是可假定通过 DMX 写入的属性。断线行为需在真实链路验收时单独核对，手机／盒子保活不能替代灯具自身的失联设置。

## 软件增量与验收分层

1. FIXTURE-006 首先解除“必须猜角度才能建轴通道”的限制，保留未知状态，做离线编码检查。
2. 多发光单元的属性地址须由单元标识＋属性标识组成；总调光与单元亮度关系显式化，避免给同一灯塞两个同名快门。编排、预设和三维要共享身份。
3. 复位／机身设置须使用独立命令和受控持时，普通场景、渐变或效果不能无意穿过复位区间；混合宏通道还需明确保持／锁存及退出策略。
4. 原件核对、软件编码测试、3D 表达和真实灯具验证分别记录。尚无实灯测量，不能宣称两款灯已完整适配。参考点校准仍继续，未知行程灯具需先补物理模型。
