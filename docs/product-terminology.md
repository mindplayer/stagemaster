# 产品中文术语

日期：2026-09-21。用户明确要求统一中文；适用于交流、界面、辅助功能标签、提示信息和产品说明。短标签使用“场景”，首次解释时可以称“灯光场景”。原始概念图中的旧英文文字不再作为界面文案依据。

| 统一用语 | 含义与使用位置 |
| --- | --- |
| 场景 | 一条可保存、选择和执行的灯光编排，可包含渐变和动态内容，不等同于静态灯光截图 |
| 场景列表 | 按顺序组织的场景；界面列表入口 |
| 执行 | 开始执行待选场景；按钮同时显示目标编号，例如“执行 → 13” |
| 待选场景／当前场景 | 将要执行的目标／正在执行的场景；与正在编辑的场景分别显示 |
| 渐变、淡入、淡出 | 属性过渡、逐渐亮起、逐渐熄灭；涉及具体参数时保持语义准确 |
| 延时 | 执行动作前的等待时间 |
| 预设、编程器、配适 | 可复用参数、临时编辑区、灯具与控制地址的配置 |
| 释放、熄灯 | 撤去某播放来源／降低照明亮度；二者不等同，也不默认把所有设备通道归零 |
| 播放通道、输出域 | 参与合成的播放来源／一组最多 512 个 DMX 通道；不同概念不得混用 |
| 舞台空间／舞台画面 | 三维场地与可视化内容，避免与可执行的“场景”混淆 |
| 指向／共同指向 | 调整光束朝向／多台灯具共同瞄向同一空间目标；每台灯分别计算角度 |
| 目标点 | 光束在舞台空间中瞄向的位置，可拖动并持续跟随；不等于灯具安装位置 |
| 聚焦所选／光学调焦 | 前者为镜头观察操作，后者为灯具光学清晰度调节；不混用为光束指向 |

时间字段用“秒”，按钮和状态直接描述操作。键盘提示可使用键帽符号；设备编号、协议名、产品型号及用户文件名保留准确写法。

## 开发对应关系

内部标识符保持兼容：`Cue` 对应场景，`GO`／`go` 对应执行，`Fade` 对应渐变，`Delay` 对应延时，`Preset` 对应预设，`Programmer` 对应编程器，`Patch` 对应配适，`Playback` 对应播放通道，`Universe` 对应输出域。界面不得直接显示这些业务标识符。

源码、协议字段、文件路径、外部 API 和官方研究引用不作无差别替换；译名变化不改变其业务行为。历史截图和第三方手册可以保留原文，现行产品说明与界面以本规范为准。
